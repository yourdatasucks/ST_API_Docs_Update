Change Order Category

The Change Order Category object represents a classification or grouping for Change Orders. Categories help organize change orders by their purpose, department, impact type, or other organizational needs.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the change order category. true false
name string Name of the change order category. false true
description string Detailed description of the category and its purpose. false false
code string Unique code or shorthand identifier for the category. false false
color string Color code (hex) for visual identification of the category. false false
isActive boolean Whether this category is active and available for use. false false
defaultApprovalWorkflow string Default approval workflow ID for change orders in this category. false false
companyId integer ID of the company this category belongs to. false true
createdDate datetime Date the category was created. true false
createdBy integer ID of the user who created the category. true false
lastModifiedDate datetime Date the category was last modified. true false
lastModifiedBy integer ID of the user who last modified the category. true false

POST /changeordercategories

Creates a new change order category.

Request Body

{
    "name": "Regulatory Requirement",
    "description": "Changes required by regulatory agencies or code updates",
    "code": "RR",
    "color": "#D0021B",
    "isActive": true,
    "defaultApprovalWorkflow": "expedited",
    "companyId": 123
}

Response

Returns the newly created change order category object (HTTP 201 Created).

PUT /changeordercategories/{id}

Updates an existing change order category.

Request Body

{
    "name": "Regulatory Compliance",
    "description": "Changes required by regulatory agencies, code updates, or compliance requirements",
    "color": "#CC0000"
}

Response

Returns the updated change order category object.

DELETE /changeordercategories/{id}

Deletes a change order category. This may be disallowed if there are change orders using this category.

Response

HTTP 204 No Content on successful deletion.

GET /changeordercategories/{id}/changeorders

Retrieves all change orders associated with a specific category.

Request

GET /v1.0/changeordercategories/101/changeorders
Authorization: Bearer {access_token}

Response

Returns a collection of Change Orders in this category.
