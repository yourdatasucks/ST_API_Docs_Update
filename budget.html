Budget

The Budget object represents financial planning information for projects, accounts, or fiscal periods. Budgets typically contain multiple Budget Categories, which in turn contain Budget Line Items.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the budget. true false
referenceNumber string Reference number that this budget is known by. false false
name string Name of the budget. false true
description string Description of the budget. false false
type string Type of budget, e.g., "Project", "Annual", "Department". false true
status string Status of the budget, e.g., "Draft", "Active", "Closed". false true
sequence integer 0 for baseline, otherwise the revision number of the budget. true false
startDate date Start date of the budget period. false false
endDate date End date of the budget period. false false
totalAmount decimal Total budget amount (calculated). true false
usedAmount decimal Amount used/spent from the budget (calculated). true false
remainingAmount decimal Amount remaining in the budget (calculated). true false
entityId integer ID of the entity (e.g., Project, Company) this budget is for. false false
entityType string Type of entity this budget is for, e.g., "Project", "Company", "Department". false false
createdDate datetime Date the budget was created. true false
createdBy integer ID of the user who created the budget. true false
lastModifiedDate datetime Date the budget was last modified. true false
lastModifiedBy integer ID of the user who last modified the budget. true false

Budget

The budget resource is used to manage Budget data within ServiceTrade.

  • Resource URL: /budget
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /budget 200
GET /budget/123 200
GET /budget/123 404 budget not found
POST /budget 200 budget created
POST /budget 400 invalid data
PUT /budget/123 200 budget updated
PUT /budget/123 400 invalid data
PUT /budget/123 404 budget not found
DELETE /budget/123 204 budget deleted
DELETE /budget/123 404 budget not found

Returned Elements for /budget/[budgetId]

Name Type Value
id integer budget entity ID
uri string resource identifier for the budget
name string name of the budget
