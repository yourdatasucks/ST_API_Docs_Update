Job

The Job object represents a scheduled service visit or project in ServiceTrade. Jobs are the primary work records that track service activities, assigned technicians, schedules, and status tracking from creation through completion and billing.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the job. true false
number string Job number, typically displayed to users and customers. true false
customerId integer ID of the Customer this job is for. false true
locationId integer ID of the Location where this job is performed. false true
type string Type of job (e.g., "Inspection", "Repair", "Installation", "Maintenance"). false true
status string Current status of the job (e.g., "Created", "Scheduled", "In Progress", "Completed", "Canceled"). false false
priority string Priority level of the job (e.g., "Low", "Normal", "High", "Emergency"). false false
createdBy integer ID of the user who created the job. true false
createdDate datetime Date and time when the job was created. true false
scheduledStartDate datetime Scheduled start date and time for the job. false false
scheduledEndDate datetime Scheduled end date and time for the job. false false
actualStartDate datetime Actual start date and time when work began. false false
actualEndDate datetime Actual end date and time when work was completed. false false
description string Detailed description of the job. false false
summary string Brief summary of the job. false false
notes string Additional notes about the job. false false
customerNotes string Notes from or visible to the customer. false false
privateNotes string Internal notes not visible to customers. false false
completionNotes string Notes recorded upon job completion. false false
assignedUsers array Array of user IDs assigned to the job. false false
tags array Array of Tag objects associated with the job. false false
items array Array of Job Item objects. false false
attachments array Array of Attachment objects related to this job. false false
tasks array Array of Task objects to be completed during the job. false false
serviceLineId integer ID of the Service Line this job belongs to. false false
contractId integer ID of the Contract this job is associated with, if applicable. false false
serviceRecurrenceId integer ID of the Service Recurrence that generated this job, if applicable. true false
serviceRequestId integer ID of the Service Request that generated this job, if applicable. false false
purchaseOrderNumber string Customer's purchase order number for this job, if applicable. false false
estimatedDuration integer Estimated duration of the job in minutes. false false
actualDuration integer Actual duration of the job in minutes. true false
estimatedCost decimal Estimated cost to perform the job. false false
actualCost decimal Actual cost of performing the job. true false
estimatedRevenue decimal Estimated revenue from the job. false false
actualRevenue decimal Actual revenue from the job. true false
invoiceIds array Array of Invoice IDs associated with this job. true false
lastModifiedBy integer ID of the user who last modified the job. true false
lastModifiedDate datetime Date and time when the job was last modified. true false
completedBy integer ID of the user who completed the job. true false
completedDate datetime Date and time when the job was marked as completed. true false
canceledBy integer ID of the user who canceled the job, if applicable. true false
canceledDate datetime Date and time when the job was canceled, if applicable. true false
cancelReason string Reason the job was canceled, if applicable. false false
externalId string Reference to this job in an external system. false false
externalSyncStatus string Status of synchronization with external systems. true false
customFields object Custom fields and their values. false false

DELETE /jobs/{id}

Deletes a job. This is typically only allowed for jobs in "Created" status without any associated invoices or other dependencies.

Response

HTTP 204 No Content on successful deletion.

POST /jobs/{id}/cancel

Cancels a job.

Request Body

{
    "reason": "Customer facility closed indefinitely",
    "notify": true,
    "notifyContacts": [5001, 5002],
    "notifyMessage": "Due to your facility closure, we've canceled the scheduled service visit."
}

Response

Returns the updated job with status changed to "Canceled".

POST /jobs/{id}/start

Marks a job as started (changes status to "In Progress" and sets actualStartDate).

Request Body

{
    "startDate": "2023-08-15T09:15:00Z",
    "userId": 102,
    "notes": "Arrived on site, checked in with security"
}

Response

Returns the updated job with status changed to "In Progress".

POST /jobs/{id}/complete

Marks a job as completed (changes status to "Completed" and sets actualEndDate and completedDate).

Request Body

{
    "completionDate": "2023-08-15T11:30:00Z",
    "userId": 102,
    "completionNotes": "Completed full inspection. All devices tested and functioning properly. Customer signed off on work.",
    "actualCost": 725.50,
    "actualRevenue": 1500.00,
    "generateInvoice": true
}

Response

Returns the updated job with status changed to "Completed".

Request Body

{
    "scheduledStartDate": "2023-08-25T13:00:00Z",

    "notifyMessage": "Due to severe weather conditions, we need to reschedule your service visit."

Response

Returns the updated job with new scheduled dates.

    "reason": "Original technician on leave",
    "notifyNewUsers": true,

}

Response

Returns the updated job with new assigned users.
