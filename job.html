Job

The Job object represents a scheduled service visit or project in ServiceTrade. Jobs are the primary work records that track service activities, assigned technicians, schedules, and status tracking from creation through completion and billing.

Job

The job resource is used to manage Job data within ServiceTrade.

  • Resource URL: /job
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /job 200
GET /job/123 200
GET /job/123 404 job not found
POST /job 200 job created
POST /job 400 invalid data
PUT /job/123 200 job updated
PUT /job/123 400 invalid data
PUT /job/123 404 job not found
DELETE /job/123 204 job deleted
DELETE /job/123 404 job not found

Returned Elements for /job/[jobId]

Name Type Value
id integer job entity ID
uri string resource identifier for the job
name string name of the job
