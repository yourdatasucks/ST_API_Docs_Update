Appointment

The Appointment object represents scheduled events, meetings, or service calls. It typically includes information about the time, location, participants, and subject of the appointment.

Properties

Property Type Description Read-Only Required
Id integer Unique identifier for the appointment. true N/A (generated on create)
Subject string The title or subject of the appointment. false true
StartTime datetime The scheduled start date and time of the appointment. false true
EndTime datetime The scheduled end date and time of the appointment. false true
Location string Physical location or meeting link for the appointment. false false
Description string Additional details or notes about the appointment. false false
Attendees array (object) A list of attendees. Each attendee object might include UserId, ContactId, or Email. false false
Status string Current status of the appointment (e.g., "Scheduled", "Confirmed", "Completed", "Cancelled"). false false
RelatedEntityType string The type of entity this appointment is related to (e.g., "Deal", "Contact", "Asset"). false false
RelatedEntityId integer The ID of the specific entity instance this appointment is related to. false false
CreateDate datetime Date the appointment was created. true N/A
LastModifiedDate datetime Date the appointment was last modified. true N/A

Appointment

The appointment resource is used to manage Appointment data within ServiceTrade.

  • Resource URL: /appointment
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /appointment 200
GET /appointment/123 200
GET /appointment/123 404 appointment not found
POST /appointment 200 appointment created
POST /appointment 400 invalid data
PUT /appointment/123 200 appointment updated
PUT /appointment/123 400 invalid data
PUT /appointment/123 404 appointment not found
DELETE /appointment/123 204 appointment deleted
DELETE /appointment/123 404 appointment not found

Returned Elements for /appointment/[appointmentId]

Name Type Value
id integer appointment entity ID
uri string resource identifier for the appointment
name string name of the appointment
