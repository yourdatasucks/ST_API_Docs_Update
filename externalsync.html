ExternalSync

The ExternalSync object represents synchronization operations between ServiceTrade and external systems. It tracks the status, progress, and results of data synchronization activities, enabling integration monitoring and troubleshooting.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the synchronization operation. true false
externalSystemId integer ID of the External System involved in the sync. false true
syncType string Type of synchronization (e.g., "Full", "Incremental", "Manual", "Scheduled"). false true
entityType string Type of entity being synchronized (e.g., "Customer", "Invoice", "Job"). false true
direction string Direction of the sync (e.g., "Import", "Export", "Bidirectional"). false true
status string Current status of the sync operation (e.g., "Pending", "In Progress", "Completed", "Failed", "Cancelled"). false true
startDate datetime Date and time when the sync operation started. true false
endDate datetime Date and time when the sync operation completed or failed. true false
initiatedBy integer ID of the user who initiated the sync operation, or null if system-initiated. true false
totalRecords integer Total number of records processed in the sync operation. true false
successCount integer Number of records successfully synchronized. true false
errorCount integer Number of records that failed to synchronize. true false
warningCount integer Number of records with warnings during synchronization. true false
progressPercentage integer Current progress of the sync operation as a percentage. true false
notes string Additional notes or comments about the sync operation. false false
errorDetails object Detailed information about errors encountered during synchronization. true false
syncParameters object Parameters used for this sync operation. false false
lastCheckpointData object Data representing the last successful checkpoint in the sync process. true false
createdDate datetime Date the sync record was created. true false
lastModifiedDate datetime Date the sync record was last modified. true false

ExternalSync

The externalsync resource is used to manage ExternalSync data within ServiceTrade.

  • Resource URL: /externalsync
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /externalsync 200
GET /externalsync/123 200
GET /externalsync/123 404 externalsync not found
POST /externalsync 200 externalsync created
POST /externalsync 400 invalid data
PUT /externalsync/123 200 externalsync updated
PUT /externalsync/123 400 invalid data
PUT /externalsync/123 404 externalsync not found
DELETE /externalsync/123 204 externalsync deleted
DELETE /externalsync/123 404 externalsync not found

Returned Elements for /externalsync/[externalsyncId]

Name Type Value
id integer externalsync entity ID
uri string resource identifier for the externalsync
name string name of the externalsync
