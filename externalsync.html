ExternalSync

The ExternalSync object represents synchronization operations between ServiceTrade and external systems. It tracks the status, progress, and results of data synchronization activities, enabling integration monitoring and troubleshooting.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the synchronization operation. true false
externalSystemId integer ID of the External System involved in the sync. false true
syncType string Type of synchronization (e.g., "Full", "Incremental", "Manual", "Scheduled"). false true
entityType string Type of entity being synchronized (e.g., "Customer", "Invoice", "Job"). false true
direction string Direction of the sync (e.g., "Import", "Export", "Bidirectional"). false true
status string Current status of the sync operation (e.g., "Pending", "In Progress", "Completed", "Failed", "Cancelled"). false true
startDate datetime Date and time when the sync operation started. true false
endDate datetime Date and time when the sync operation completed or failed. true false
initiatedBy integer ID of the user who initiated the sync operation, or null if system-initiated. true false
totalRecords integer Total number of records processed in the sync operation. true false
successCount integer Number of records successfully synchronized. true false
errorCount integer Number of records that failed to synchronize. true false
warningCount integer Number of records with warnings during synchronization. true false
progressPercentage integer Current progress of the sync operation as a percentage. true false
notes string Additional notes or comments about the sync operation. false false
errorDetails object Detailed information about errors encountered during synchronization. true false
syncParameters object Parameters used for this sync operation. false false
lastCheckpointData object Data representing the last successful checkpoint in the sync process. true false
createdDate datetime Date the sync record was created. true false
lastModifiedDate datetime Date the sync record was last modified. true false

GET /externalsyncs/{id}

Retrieves a specific external sync operation by ID.

Request

GET /v1.0/externalsyncs/456
Authorization: Bearer {access_token}

Response

Returns the external sync operation with the specified ID.

POST /externalsyncs

Initiates a new external sync operation.

Request Body

{
    "externalSystemId": 123,
    "syncType": "Manual",
    "entityType": "Invoice",
    "direction": "Export",
    "notes": "Manual export of all unpaid invoices",
    "syncParameters": {
        "status": ["Sent", "Overdue"],
        "dateRange": {
            "start": "2023-01-01",
            "end": "2023-08-15"
        },
        "includeLineItems": true
    }
}

Response

Returns the created external sync operation (HTTP 201 Created).

PUT /externalsyncs/{id}

Updates an existing external sync operation. Limited to certain fields depending on sync status.

Request Body

{
    "status": "Cancelled",
    "notes": "Cancelled due to server maintenance"
}

Response

Returns the updated external sync operation.

GET /externalsyncs/{id}/details

Retrieves detailed information about a specific sync operation, including record-level details.

Request

GET /v1.0/externalsyncs/456/details
Authorization: Bearer {access_token}

Response

Returns detailed information about the sync operation, including processed records.

POST /externalsyncs/{id}/cancel

Cancels an in-progress sync operation.

Request Body

{
    "reason": "System maintenance required",
    "notifyUsers": [101, 102]
}

Response

Returns the updated external sync operation with cancelled status.

POST /externalsyncs/{id}/retry

Retries a failed sync operation.

Request Body

{
    "retryFailedOnly": true,
    "updateParameters": {
        "timeout": 600,
        "batchSize": 25
    }
}

Response

Returns the newly created external sync operation for the retry attempt.

GET /externalsystems/{id}/externalsyncs

Retrieves all sync operations for a specific external system.

Request

GET /v1.0/externalsystems/123/externalsyncs?status=Completed
Authorization: Bearer {access_token}

Response

Returns a collection of external sync operations for the specified external system.

GET /externalsyncs/status/{jobId}

Checks the status of a long-running sync operation by its job ID.

Request

GET /v1.0/externalsyncs/status/sync-job-789
Authorization: Bearer {access_token}

Response

{
    "jobId": "sync-job-789",
    "status": "In Progress",

    "currentOperation": "Importing Customers",

}

POST /externalsyncs/schedule

Schedules a recurring sync operation.

Request Body

{
    "externalSystemId": 123,
    "entityType": "Customer",
    "direction": "Import",
    "schedule": {
        "frequency": "Daily",
        "time": "03:00:00",
        "timeZone": "America/New_York",
        "daysOfWeek": [1, 2, 3, 4, 5],
        "startDate": "2023-08-16"
    },
    "syncParameters": {
        "modifiedSince": "lastSync",
        "includeInactive": false
    }
}

Response

Returns the created schedule configuration.
