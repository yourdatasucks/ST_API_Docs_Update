Company

The Company object represents a business entity within the system. Companies may be service providers, customers, vendors, partners, or other business relationships. A company can have multiple locations, contacts, and other associated data.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the company. true false
name string Legal name of the company. false true
legalName string Full legal name of the company, if different from name. false false
dba string "Doing Business As" name, if applicable. false false
type string Type of company relationship (e.g., "Customer", "Vendor", "Partner"). false true
status string Status of the company (e.g., "Active", "Inactive", "Prospect"). false false
phone string Primary phone number for the company. false false
fax string Fax number for the company. false false
email string Primary email address for the company. false false
website string Website URL for the company. false false
taxId string Tax identification number (e.g., EIN in the US). false false
billingAddress object Address object for billing address. false false
mailingAddress object Address object for mailing address. false false
notes string General notes about the company. false false
logoUrl string URL to the company's logo image. false false
industry string Primary industry classification. false false
yearFounded integer Year the company was founded. false false
numberOfEmployees integer Approximate number of employees. false false
annualRevenue string Approximate annual revenue range. false false
parentCompanyId integer ID of the parent company, if this is a subsidiary. false false
customFields object Custom field values for the company. false false
tags array Array of tags associated with the company. false false
createdDate datetime Date the company record was created. true false
createdBy integer ID of the user who created the company record. true false
lastModifiedDate datetime Date the company record was last modified. true false
lastModifiedBy integer ID of the user who last modified the company record. true false

Address Object

Property Type Description
street1 string First line of the street address.
street2 string Second line of the street address.
city string City name.
state string State or province code.
postalCode string Postal or ZIP code.
country string Country code (ISO 3166-1 alpha-2).
latitude decimal Geographic latitude coordinate.
longitude decimal Geographic longitude coordinate.

POST /companies

Creates a new company.

Request Body

{
    "name": "TechSolutions LLC",
    "legalName": "TechSolutions Limited Liability Company",
    "type": "Customer",
    "status": "Active",
    "phone": "555-987-6543",
    "email": "info@techsolutions.example.com",
    "website": "https://www.techsolutions.example.com",
    "billingAddress": {
        "street1": "456 Tech Avenue",
        "city": "Silicon Valley",
        "state": "CA",
        "postalCode": "94025",
        "country": "US"
    },
    "industry": "Information Technology",
    "tags": ["IT", "Software Development"]
}

Response

Returns the newly created company object (HTTP 201 Created).

PUT /companies/{id}

Updates an existing company.

Request Body

{
    "name": "TechSolutions Corporation",
    "legalName": "TechSolutions Corporation LLC",
    "phone": "555-987-6544",
    "numberOfEmployees": 120,
    "customFields": {
        "accountManager": "Michael Brown",
        "creditLimit": 75000
    }
}

Response

Returns the updated company object.

DELETE /companies/{id}

Deletes a company. This may be disallowed if the company has associated records (e.g., locations, contacts, jobs).

Response

HTTP 204 No Content on successful deletion.

GET /companies/{id}/locations

Retrieves all locations associated with a specific company.

Request

GET /v1.0/companies/123/locations
Authorization: Bearer {access_token}

Response

Returns a collection of Location objects for this company.

GET /companies/{id}/contacts

Retrieves all contacts associated with a specific company.

Request

GET /v1.0/companies/123/contacts
Authorization: Bearer {access_token}

Response

Returns a collection of Contact objects for this company.

POST /companies/{id}/logo

Uploads a logo image for a company.

Request

Multipart form data with an image file, or JSON with base64-encoded image data.

Response

Returns the updated company object with the new logoUrl.
