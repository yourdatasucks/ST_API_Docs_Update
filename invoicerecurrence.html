Invoice Recurrence

The Invoice Recurrence object represents a schedule for automatically generating recurring Invoices. It defines the frequency, timing, content, and recipients for regularly issued invoices, such as monthly service fees or quarterly maintenance charges. Invoice recurrences help automate billing for ongoing services with predictable schedules.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the invoice recurrence. true false
name string Name or description of the invoice recurrence. false true
customerId integer ID of the Customer to bill. false true
status string Status of the recurrence (e.g., "Active", "Paused", "Completed", "Cancelled"). false false
frequency string How often invoices are generated (e.g., "Monthly", "Quarterly", "Annually", "Weekly", "Daily", "Custom"). false true
dayOfMonth integer Day of the month to generate invoices (1-31). Used for Monthly, Quarterly, and Annual frequencies. false false
dayOfWeek integer Day of the week to generate invoices (0=Sunday, 1=Monday, etc.). Used for Weekly frequency. false false
month integer Month of the year to generate invoices (1=January, 2=February, etc.). Used for Annual frequency. false false
months array Array of months to generate invoices. Used for Quarterly frequency (e.g., [1, 4, 7, 10] for Jan/Apr/Jul/Oct). false false
customInterval integer Custom interval in days between invoices. Used for Custom frequency. false false
startDate date Date when the recurring invoices should start. false true
endDate date Date when the recurring invoices should end, if applicable. false false
occurrences integer Number of invoices to generate, as an alternative to endDate. false false
completedOccurrences integer Number of invoices already generated from this recurrence. true false
lastRunDate datetime Date and time when the last invoice was generated. true false
nextRunDate datetime Scheduled date and time for the next invoice generation. true false
invoiceTemplate object Template data for generating invoices. false true
invoiceNumberPrefix string Prefix to use for invoice numbers (e.g., "REC-"). false false
invoiceNumberSuffix string Suffix to use for invoice numbers. false false
autoSend boolean Whether to automatically send invoices to customers upon generation. false false
sendToContacts array Array of contact IDs to receive the invoice. false false
emailSubject string Subject line for invoice emails. false false
emailMessage string Email body text for invoice emails. false false
reminderDays integer Number of days after invoice generation to send payment reminders. false false
autoCharge boolean Whether to automatically charge saved payment methods. false false
paymentMethodId integer ID of the saved payment method to charge. false false
contractId integer ID of the Contract this recurrence is associated with, if applicable. false false
notes string Additional notes about this recurrence (internal use only). false false
createdBy integer ID of the user who created this recurrence. true false
createdDate datetime Date and time when this recurrence was created. true false
lastModifiedBy integer ID of the user who last modified this recurrence. true false
lastModifiedDate datetime Date and time when this recurrence was last modified. true false
externalId string Reference to this recurrence in an external system. false false
customFields object Custom fields and their values. false false

Invoice Template Object Properties

The invoiceTemplate object contains the following properties:

Property Type Description
items array Array of invoice item templates.
notes string Notes to include on the invoice.
termsAndConditions string Terms and conditions to include on the invoice.
taxRate decimal Tax rate to apply on taxable items.
taxGroupId integer ID of the Tax Group to use.
discountType string Type of discount (e.g., "Percentage", "Fixed").
discountPercentage decimal Percentage discount to apply.
discountAmount decimal Fixed discount amount to apply.
paymentTermsId integer ID of the Payment Terms to use.
dueDays integer Number of days after invoice date when payment is due.
billingAddress object Billing address to use (same structure as in Invoice).
currency string Currency code (e.g., "USD", "EUR").

Invoice Item Template Object Properties

Each item in the invoiceTemplate.items array contains the following properties:

Property Type Description
description string Description of the item.
quantity decimal Quantity of the item.
unitPrice decimal Price per unit.
unitCost decimal Cost per unit.
taxable boolean Whether this item is subject to tax.
taxRateId integer ID of the Tax Rate for this specific item.
itemType string Type of item (e.g., "Service", "Product").
serviceItemId integer ID of the Service Item.
notes string Additional notes for this item.
sequenceNumber integer Display order of this item on the invoice.

DELETE /invoicerecurrences/{id}

Deletes an invoice recurrence. This will prevent future invoices from being generated but won't affect already issued invoices.

Response

HTTP 204 No Content on successful deletion.

PUT /invoicerecurrences/{id}/status

Updates the status of an invoice recurrence.

Request Body

    "status": "Paused",

    "sendToCustomer": true,
