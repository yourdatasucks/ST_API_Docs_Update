Contact

The Contact object represents an individual person associated with a company or organization. Contacts can be customers, vendors, employees, or other stakeholders. Each contact can have roles, contact information, and preferences.

Properties

Contact

The contact resource is used to manage Contact data within ServiceTrade.

  • Resource URL: /contact
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /contact 200
GET /contact/123 200
GET /contact/123 404 contact not found
POST /contact 200 contact created
POST /contact 400 invalid data
PUT /contact/123 200 contact updated
PUT /contact/123 400 invalid data
PUT /contact/123 404 contact not found
DELETE /contact/123 204 contact deleted
DELETE /contact/123 404 contact not found

Returned Elements for /contact/[contactId]

Name Type Value
id integer contact entity ID
uri string resource identifier for the contact
name string name of the contact
