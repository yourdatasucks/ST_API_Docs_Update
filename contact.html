Contact

The Contact object represents an individual person associated with a company or organization. Contacts can be customers, vendors, employees, or other stakeholders. Each contact can have roles, contact information, and preferences.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the contact. true false
firstName string First name of the contact. false true
lastName string Last name of the contact. false true
companyId integer ID of the Company this contact is associated with. false true
title string Job title or position of the contact. false false
department string Department the contact works in. false false
email string Primary email address of the contact. false false
phone string Primary phone number of the contact. false false
mobile string Mobile phone number of the contact. false false
fax string Fax number of the contact. false false
notes string Additional notes about the contact. false false
isPrimary boolean Whether this is the primary contact for the company. false false
isActive boolean Whether this contact is active. false false
preferredContactMethod string Preferred method of communication (e.g., "Email", "Phone", "Mobile"). false false
contactTypes array Array of Contact Type IDs associated with this contact. false false
locationIds array Array of Location IDs this contact is associated with. false false
customFields object Custom field values for the contact. false false
tags array Array of tags associated with the contact. false false
portalAccess boolean Whether this contact has access to the customer portal. false false
portalUsername string Username for customer portal access. true false
lastLoginDate datetime Date and time of the contact's last portal login. true false
createdDate datetime Date the contact record was created. true false
createdBy integer ID of the user who created the contact record. true false
lastModifiedDate datetime Date the contact record was last modified. true false
lastModifiedBy integer ID of the user who last modified the contact record. true false

POST /contacts

Creates a new contact.

Request Body

{
    "firstName": "Sarah",
    "lastName": "Johnson",
    "companyId": 123,
    "title": "Chief Financial Officer",
    "department": "Finance",
    "email": "sarah.johnson@acmecorp.example.com",
    "phone": "555-123-7890",
    "mobile": "555-456-7890",
    "isPrimary": false,
    "isActive": true,
    "preferredContactMethod": "Phone",
    "contactTypes": [101, 103],
    "locationIds": [201],
    "tags": ["Finance", "Executive"]
}

Response

Returns the newly created contact object (HTTP 201 Created).

PUT /contacts/{id}

Updates an existing contact.

Request Body

{
    "title": "Senior Financial Officer",
    "email": "sarah.johnson@acmecorp.example.com",
    "notes": "Promoted to Senior Financial Officer in July 2023.",
    "portalAccess": true
}

Response

Returns the updated contact object.

DELETE /contacts/{id}

Deletes a contact.

Response

HTTP 204 No Content on successful deletion.

GET /companies/{id}/contacts

Retrieves all contacts for a specific company. See Company for details.

POST /contacts/{id}/portalAccess

Grants customer portal access to a contact and sends portal credentials.

Request Body

{
    "sendWelcomeEmail": true,
    "notificationPreferences": {
        "receiveJobUpdates": true,
        "receiveInvoices": true,
        "receiveQuotes": true
    }
}

Response

Returns the updated contact object with portal access details.

DELETE /contacts/{id}/portalAccess

Revokes portal access for a contact.

Response

Returns the updated contact object with portal access revoked.
