Account

The account resource is used to retrieve account settings.

  • Resource URL: /account
  • Available Verbs: GET
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /account 200
GET /account/123 200
GET /account 401 unauthorized
GET /account/123 401 unauthorized
POST /account 405 not allowed
POST /account/123 405 not allowed
PUT /account 405 not allowed
PUT /account/123 405 not allowed
DELETE /account 405 not allowed
DELETE /account/123 405 not allowed

Returned Elements for /account/[accountId]

Name Type Value
id integer account entity ID
uri string resource identifier for the account
name string name of account
timezone string account timezone identifier
primeCompany Company prime company for account
features object a key/value object of account features and boolean values (that indicate whether feature is turned on of `off)
