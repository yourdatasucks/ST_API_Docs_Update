Content

The Content object represents marketing, educational, or informational content that can be displayed to users within the application. This includes articles, videos, help documentation, announcements, and other content types.

Properties

Property Type Description Read-Only Required
id string Unique identifier for the content item. true false
title string Title of the content item. false true
subtitle string Subtitle or brief description of the content. false false
body string Main content body, may contain HTML formatting. false true
contentType string Type of content (e.g., "Article", "Video", "Announcement", "Help"). false true
format string Format of the content (e.g., "HTML", "Markdown", "Plain"). false false
featuredImageUrl string URL to the featured image for the content. false false
thumbnailUrl string URL to a thumbnail image for the content. false false
externalUrl string Optional URL to external content (e.g., for embedded videos). false false
categories array Array of category strings for this content. false false
tags array Array of tag strings for this content. false false
audience array Array of audience identifiers this content is targeted to (e.g., "Admin", "Technician", "Customer"). false false
authorId integer ID of the user who authored the content. false false
authorName string Name of the author. false false
publishDate datetime Date when the content was or will be published. false false
expirationDate datetime Date when the content expires or is no longer relevant. false false
isPublished boolean Whether the content is currently published and visible. false false
isFeatured boolean Whether the content is featured or highlighted. false false
priority integer Display priority (higher numbers are shown first). false false
viewCount integer Number of times the content has been viewed. true false
relatedContentIds array Array of IDs for related content items. false false
companyId integer ID of the company this content belongs to, if company-specific. false false
createdDate datetime Date the content item was created. true false
createdBy integer ID of the user who created the content item. true false
lastModifiedDate datetime Date the content item was last modified. true false
lastModifiedBy integer ID of the user who last modified the content item. true false

Content

The content resource is used to manage Content data within ServiceTrade.

  • Resource URL: /content
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /content 200
GET /content/123 200
GET /content/123 404 content not found
POST /content 200 content created
POST /content 400 invalid data
PUT /content/123 200 content updated
PUT /content/123 400 invalid data
PUT /content/123 404 content not found
DELETE /content/123 204 content deleted
DELETE /content/123 404 content not found

Returned Elements for /content/[contentId]

Name Type Value
id integer content entity ID
uri string resource identifier for the content
name string name of the content
