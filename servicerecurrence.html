Service Recurrence

The Service Recurrence object represents a recurring service schedule in ServiceTrade. It defines when services should be automatically created on a repeating basis, including the frequency (daily, weekly, monthly, yearly), specific details about the recurrence pattern, and which jobs or services should be generated. Service Recurrences help automate the scheduling of routine maintenance, inspections, and other recurring service work.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the service recurrence. true false
name string Name of the service recurrence. false true
description string Description of the service recurrence. false false
isActive boolean Whether this recurrence is active. false false
locationId integer ID of the location for which services will be created. false true
customerId integer ID of the customer associated with the location. true false
frequency string Recurrence frequency type (daily, weekly, monthly, yearly). false true
interval integer The interval between recurrences (e.g., every 2 weeks). false true
dayOfWeek integer For weekly recurrences, the day of the week (1-7, where 1 is Monday). false false
dayOfMonth integer For monthly recurrences, the day of the month (1-31). false false
weekOfMonth integer For monthly recurrences, the week of the month (1-5, where 5 represents the last week). false false
monthOfYear integer For yearly recurrences, the month of the year (1-12). false false
startDate date Date when the recurrence pattern begins. false true
endDate date Date when the recurrence pattern ends (if specified). false false
endAfterCount integer Number of occurrences after which the recurrence ends. false false
leadTimeDays integer Number of days before the service date that jobs should be created. false false
jobTypeId integer Type of job to create for each recurrence. false true
serviceTemplateId integer ID of the service template to use for creating services. false false
contractId integer ID of the contract associated with this recurrence. false false
assignedUserId integer ID of the user to whom recurring services will be assigned. false false
lastRunDate datetime Date and time when the recurrence was last processed. true false
nextRunDate datetime Date and time when the recurrence will next be processed. true false
createdBy integer ID of the user who created this service recurrence. true false
createdDate datetime Date and time when this service recurrence was created. true false
lastModifiedBy integer ID of the user who last modified this service recurrence. true false
lastModifiedDate datetime Date and time when this service recurrence was last modified. true false

Service Recurrence

The servicerecurrence resource is used to manage recurring service schedules.

  • Resource URL: /servicerecurrence
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes
