Group Label

The Group Label object represents a categorization or grouping mechanism used to organize and filter entities within ServiceTrade. Group labels allow for flexible categorization across different entity types and can support both predefined and custom groupings.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the group label. true false
name string Name of the group label. false true
description string Description of the group label's purpose. false false
type string Type of group label (e.g., "System", "Custom", "Department", "Region"). false true
entityType string Type of entity this group label can be applied to. false true
isActive boolean Whether this group label is active and available for use. false false
color string Color code (hex) for visual representation of this group label. false false
icon string Icon identifier for visual representation of this group label. false false
sortOrder integer Position in display order when listing group labels. false false
parentId integer ID of the parent group label, if this is a child in a hierarchical structure. false false
isRequired boolean Whether this label must be assigned to entities of the specified type. false false
isExclusive boolean Whether an entity can have only one label from this group. false false
isSystem boolean Whether this is a system-defined group label that cannot be modified. true false
metadata object Additional metadata for the group label. false false
usageCount integer Number of entities this label is currently applied to. true false
createdDate datetime Date the group label was created. true false
createdBy integer ID of the user who created the group label. true false
lastModifiedDate datetime Date the group label was last modified. true false
lastModifiedBy integer ID of the user who last modified the group label. true false
defaultValue boolean Whether this is the default label in its group. false false

GET /grouplabels/{id}

Retrieves a specific group label by ID.

Request

GET /v1.0/grouplabels/123
Authorization: Bearer {access_token}

Response

Returns the group label with the specified ID.

POST /grouplabels

Creates a new group label.

Request Body

{
    "name": "Industrial",
    "description": "Industrial service jobs for manufacturing clients",
    "type": "JobType",
    "entityType": "Job",
    "isActive": true,
    "color": "#FBBC05",
    "icon": "industry",
    "sortOrder": 3,
    "isRequired": true,
    "isExclusive": true,
    "metadata": {
        "billRate": 150.00,
        "targetResponseTime": "12h",
        "requiresSpecialTraining": true
    }
}

Response

Returns the newly created group label (HTTP 201 Created).

PUT /grouplabels/{id}

Updates an existing group label.

Request Body

{
    "name": "Industrial & Manufacturing",
    "color": "#EA4335",
    "metadata": {
        "billRate": 165.00,
        "targetResponseTime": "8h",
        "requiresSpecialTraining": true,
        "hasHazardousMaterials": true
    }
}

Response

Returns the updated group label.

DELETE /grouplabels/{id}

Deletes a group label. This will remove the label from all entities it was applied to.

Response

HTTP 204 No Content on successful deletion.

POST /entities/{entityType}/{id}/grouplabels

Assigns group labels to a specific entity.

Request Body

{
    "labelIds": [123, 234, 345]
}

Response

Returns a collection of the assigned group labels.

Response
