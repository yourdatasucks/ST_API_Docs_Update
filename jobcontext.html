Job Context

The Job Context object provides contextual information and relationships between a specific Job and other entities in ServiceTrade. It enables accessing related data such as customer details, location information, assigned users, related assets, and more for comprehensive job context awareness.

Properties

Property Type Description Read-Only Required
job object The Job object for which context is being provided. true false
customer object The Customer associated with the job. true false
location object The Location where the job is performed. true false
assets array Array of Asset objects at the location that may be relevant to the job. true false
assignedUsers array Array of User objects assigned to the job. true false
contacts array Array of Contact objects associated with the customer and location. true false
serviceRecurrence object The Service Recurrence that generated this job, if applicable. true false
serviceRequest object The Service Request that initiated this job, if applicable. true false
contract object The Contract associated with this job, if applicable. true false
invoices array Array of Invoice objects associated with the job. true false
relatedJobs array Array of related Job objects at the same location or for the same customer. true false
serviceLine object The Service Line this job belongs to. true false
deficiencies array Array of Deficiency objects associated with the job or location. true false
quotes array Array of Quote objects associated with the job. true false
timeCards array Array of Time Card objects logged against this job. true false
histories array Array of History objects for this job. true false
taskInstances array Array of Task Instance objects for this job. true false

Retrieves just the customer context for a job.

Request

Authorization: Bearer {access_token}

Returns just the customer object from the context.

POST /jobs/{id}/context/custom

Retrieves a custom subset of the job context.

Request Body

{
    "include": ["job", "customer", "location", "assets", "contacts"],
    "assetLimit": 10,
    "contactTypes": ["Primary", "Emergency"],
    "assetTypes": ["Fire Alarm", "Sprinkler"]
}

Response

Returns a custom context object containing only the requested components.
