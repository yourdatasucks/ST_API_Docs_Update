Invoice Item

The Invoice Item object represents a line item on an Invoice. Each invoice item details a specific product or service being billed, including its description, quantity, price, and tax information. Invoice items enable detailed billing and cost tracking for services and products provided to customers.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the invoice item. true false
invoiceId integer ID of the Invoice this item belongs to. false true
description string Description of the item, displayed on the invoice. false true
quantity decimal Quantity of the item. false true
unitPrice decimal Price per unit. false true
unitCost decimal Cost per unit (for profit calculations, not shown on invoice). false false
subtotal decimal Line item subtotal (quantity * unitPrice). true false
discountAmount decimal Discount amount applied to this line item. false false
discountType string Type of discount (e.g., "Percentage", "Fixed"). false false
discountPercentage decimal Percentage discount applied to this line item, if applicable. false false
taxable boolean Whether this item is subject to tax. false false
taxAmount decimal Tax amount for this line item. true false
taxRate decimal Tax rate applied to this line item. If not specified, the invoice's tax rate is used. false false
taxRateId integer ID of the Tax Rate applied to this item, if different from the invoice's tax rate. false false
total decimal Line item total (subtotal - discounts + tax). true false
sequenceNumber integer Display order of this item on the invoice. false false
itemType string Type of item (e.g., "Product", "Service", "Labor", "Material", "Fee"). false false
jobId integer ID of the Job this item is associated with, if applicable. false false
jobItemId integer ID of the Job Item this invoice item is associated with, if applicable. false false
serviceItemId integer ID of the Service Item this invoice item is associated with, if applicable. false false
assetId integer ID of the Asset this invoice item is associated with, if applicable. false false
notes string Additional notes about this line item (internal use, not shown on invoice). false false
createdBy integer ID of the user who created this invoice item. true false
createdDate datetime Date and time when this invoice item was created. true false
lastModifiedBy integer ID of the user who last modified this invoice item. true false
lastModifiedDate datetime Date and time when this invoice item was last modified. true false
externalId string Reference to this item in an external system. false false
customFields object Custom fields and their values. false false

POST /invoices/{invoiceId}/items

Creates a new invoice item for the specified invoice.

Request Body

{
    "description": "Emergency Service Call - Water Flow Switch Repair",
    "quantity": 1,
    "unitPrice": 450.00,
    "unitCost": 225.00,
    "taxable": true,
    "sequenceNumber": 4,
    "itemType": "Service",
    "jobId": 9012,
    "serviceItemId": 114,
    "notes": "After-hours emergency service call to repair faulty water flow switch",
    "customFields": {
        "departmentCode": "FP-02",
        "laborHours": "3.0"
    }
}

Response

Returns the newly created invoice item (HTTP 201 Created).

PUT /invoiceitems/{id}

Updates an existing invoice item.

Request Body

{
    "description": "Emergency Service Call - Water Flow Switch Repair & Testing",
    "quantity": 1.5,
    "unitPrice": 450.00,
    "taxable": true,
    "notes": "After-hours emergency service call to repair faulty water flow switch and perform flow testing",
    "customFields": {
        "departmentCode": "FP-02",
        "laborHours": "4.5"
    }
}

Response

Returns the updated invoice item.

DELETE /invoiceitems/{id}

Deletes an invoice item. This is only allowed if the parent invoice is in "Draft" status.

Response

HTTP 204 No Content on successful deletion.

PUT /invoices/{invoiceId}/items/reorder

Reorders the line items on an invoice.

Request Body

{
    "itemOrder": [67892, 67890, 67891]
}

Response

Returns success message and updates the sequenceNumber property of the affected items.

GET /jobs/{jobId}/invoiceitems

Retrieves all invoice items associated with a specific job.

Request

GET /v1.0/jobs/9012/invoiceitems
Authorization: Bearer {access_token}

Response

Returns a collection of invoice items associated with the specified job, potentially across multiple invoices.

POST /jobs/{jobId}/invoiceitems

Creates invoice items from job items.

Request Body

{
    "invoiceId": 12345,
    "jobItemIds": [226, 227, 228],
    "includeCompleted": true,
    "includePendingApproval": false
}

Response

Returns an array of the created invoice items.
