Activity

The Activity object represents actions or events that have occurred within the system, often related to users, records, or automated processes. Activities are typically used for auditing, tracking history, or feeding into activity streams.

Properties

Property Type Description Read-Only Required
Id integer Unique identifier for the activity. true N/A (generated)
Timestamp datetime When the activity occurred. true N/A (generated)
UserId integer ID of the user who performed or triggered the activity (if applicable). true N/A
ActivityType string A code or string indicating the type of activity (e.g., "NOTE_ADDED", "STATUS_CHANGED", "RECORD_CREATED"). true N/A (generated)
Description string A human-readable description of the activity. true N/A (generated)
TargetEntityType string The type of entity this activity relates to (e.g., "Contact", "Deal", "Task"). true N/A
TargetEntityId integer The ID of the specific entity instance this activity relates to. true N/A
Details object An object containing additional, activity-specific information (e.g., changed fields and their old/new values). true N/A

Endpoints

GET /activities

Retrieves a list of activities. Supports filtering by various parameters like UserId, ActivityType, TargetEntityType, TargetEntityId, and date ranges.

Request Example (Filtering by TargetEntityId)

GET /v1.0/activities?TargetEntityType=Deal&TargetEntityId=12345
Authorization: Bearer {access_token}
