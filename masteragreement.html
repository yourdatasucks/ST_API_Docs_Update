Master Agreement

The Master Agreement object represents a governing agreement between a service provider and a Customer that defines the overall business relationship, terms, and conditions. Master agreements typically serve as umbrella contracts that establish the framework for subsequent Contracts, Quotes, Jobs, and Invoices. They can include pricing structures, service level agreements, term lengths, renewal conditions, and other legal and business requirements.

Properties

notes string Internal notes about the master agreement. false false

signedBy string Name of the person who signed the master agreement on behalf of the customer. false false
signedByTitle string Title of the person who signed the master agreement. false false

executedByCompanyTitle string Title of the person who signed on behalf of the company. false false

createdDate datetime Date and time when this master agreement was created. true false

lastModifiedDate datetime Date and time when this master agreement was last modified. true false
contractRuleIds array Array of Contract Rule IDs associated with this master agreement. false false
customFields object Custom fields and their values. false false

POST /master-agreements

Creates a new master agreement.

Request Body

{
    "number": "MA-2023-003",
    "name": "National Service Provider Agreement",
    "customerId": 1002,
    "status": "Draft",
    "effectiveDate": "2023-07-01",
    "expirationDate": "2026-06-30",
    "autoRenew": true,
    "renewalTerm": 24,
    "terminationNoticeDays": 60,
    "description": "Comprehensive service agreement covering all customer locations nationwide",
    "notes": "Pricing includes volume discounts based on annual spend",
    "termsAndConditions": "Standard terms with custom SLA requirements",
    "reminderDays": 90,
    "opportunityValue": 1250000.00,
    "primaryContactId": 3015,
    "responsibleUserId": 102,
    "attachmentIds": [8010, 8011],
    "contractRuleIds": [9005, 9006],
    "customFields": {
        "approvalRequired": "VP Level",
        "pricingTier": "Platinum",
        "specialTerms": "Expedited emergency response"
    }
}

Response

Returns the newly created master agreement (HTTP 201 Created).

DELETE /master-agreements/{id}

Deletes a master agreement. This is typically only allowed for agreements in "Draft" status.

Response

HTTP 204 No Content on successful deletion.

GET /customers/{customerId}/master-agreements

Retrieves all master agreements for a specific customer.

Request

GET /v1.0/customers/1001/master-agreements
Authorization: Bearer {access_token}

Response

Returns a collection of master agreements belonging to the specified customer.

POST /master-agreements/{id}/activate

Activates a master agreement (changes status from "Draft" to "Active").

Request Body

{
    "signedDate": "2023-06-15",
    "signedBy": "Thomas Wilson",
    "signedByTitle": "Chief Operating Officer",
    "executedByCompany": "Sarah Johnson",
    "executedByCompanyTitle": "Director of Sales"
}

Response

Returns the activated master agreement.

POST /master-agreements/{id}/terminate

Terminates a master agreement before its expiration date.

Request Body

{
    "terminationDate": "2023-09-30",
    "terminationReason": "Customer consolidating vendors",
    "notes": "Early termination fee waived as a goodwill gesture"
}

Response

Returns the terminated master agreement with updated status.

POST /master-agreements/{id}/renew

Manually renews a master agreement.

Request Body

{
    "newExpirationDate": "2027-12-31",
    "renewalNotes": "Renewed with 5% price increase",
    "renewalTerm": 24
}

Response

Returns the renewed master agreement with updated expiration date.
