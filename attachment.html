Attachment

The Attachment object represents files uploaded and associated with other records in the system (e.g., attaching a PDF to a Deal, an image to a Product, or a document to a Task).

Properties

Property Type Description Read-Only Required
Id integer Unique identifier for the attachment. true N/A
FileName string The original name of the uploaded file. true (usually set on upload) N/A
FileSize integer Size of the file in bytes. true N/A
MimeType string The MIME type of the file (e.g., "application/pdf", "image/jpeg"). true N/A
Url string A URL to access/download the attachment. This URL might be temporary or require authentication. true N/A
RelatedEntityType string The type of entity this attachment is linked to (e.g., "Deal", "Task", "Contact"). true (set on upload/association) N/A
RelatedEntityId integer The ID of the specific entity instance the attachment is linked to. true (set on upload/association) N/A
Description string An optional description for the attachment. false false
UploadedBy integer ID of the user who uploaded the attachment. true N/A
UploadDate datetime Date and time the attachment was uploaded. true N/A

Endpoints

GET /attachments?RelatedEntityType={type}&RelatedEntityId={id}

Retrieves a list of attachments for a specific related entity.

Request

GET /v1.0/attachments?RelatedEntityType=Deal&RelatedEntityId=12345
Authorization: Bearer {access_token}

Response

{
    "items": [
        {
            "Id": 301,
            "FileName": "Contract_Proposal.pdf",
            "FileSize": 102400, // 100KB
            "MimeType": "application/pdf",
            "Url": "https://api.example.com/files/attachments/301/download",
            "RelatedEntityType": "Deal",
            "RelatedEntityId": 12345,
            "UploadDate": "2023-02-20T11:00:00Z"
            // ... other properties
        }
    ],
    // ... pagination info
}

POST /attachments (multipart/form-data)

Uploads a new attachment and associates it with an entity. The request must be multipart/form-data.

Request Body Parameters (form data)

  • file: The file to upload.
  • RelatedEntityType: (string) The type of entity to associate with.
  • RelatedEntityId: (integer) The ID of the entity instance.
  • Description: (string, optional) Description of the attachment.

Example (Conceptual - client library would handle multipart)

POST /v1.0/attachments
Authorization: Bearer {access_token}
Content-Type: multipart/form-data; boundary=----WebKitFormBoundary7MA4YWxkTrZu0gW

------WebKitFormBoundary7MA4YWxkTrZu0gW
Content-Disposition: form-data; name="file"; filename="Site_Photos.zip"
Content-Type: application/zip

(binary file data)
------WebKitFormBoundary7MA4YWxkTrZu0gW
Content-Disposition: form-data; name="RelatedEntityType"

Project
------WebKitFormBoundary7MA4YWxkTrZu0gW
Content-Disposition: form-data; name="RelatedEntityId"

789
------WebKitFormBoundary7MA4YWxkTrZu0gW--

Response

Returns the newly created attachment object (HTTP 201 Created).

GET /attachments/{id}

Retrieves metadata for a specific attachment by its ID.

GET /attachments/{id}/download

Provides a direct download link or streams the file content for the specified attachment. (This endpoint might vary by API design).

DELETE /attachments/{id}

Deletes an attachment.
