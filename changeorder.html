Change Order

The Change Order object represents modifications to the original scope of work for a job, project, or contract. Change Orders typically contain line items that detail specific additions, removals, or modifications to the original scope.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the change order. true false
number string Change order number/identifier (often a sequential number). true false
title string Title of the change order. false true
description string Detailed description of the change order and its purpose. false false
jobId integer ID of the associated job or project. false true
categoryId integer ID of the change order category this belongs to. false false
status string Status of the change order (e.g., "Draft", "Pending Approval", "Approved", "Rejected"). false true
totalAmount decimal Total monetary value of the change order (sum of line items). true false
taxAmount decimal Tax amount applied to the change order. true false
grandTotal decimal Total amount including taxes. true false
affectsSchedule boolean Whether this change order affects the project schedule. false false
scheduleImpactDays integer Number of days added or removed from the schedule. false false
requestedBy integer ID of the user or contact who requested the change order. false false
requestedDate date Date when the change order was requested. false false
approvedBy integer ID of the user who approved the change order. true false
approvedDate date Date when the change order was approved. true false
createdDate datetime Date the change order was created. true false
createdBy integer ID of the user who created the change order. true false
lastModifiedDate datetime Date the change order was last modified. true false
lastModifiedBy integer ID of the user who last modified the change order. true false

POST /changeorders

Creates a new change order.

Request Body

{
    "title": "Upgrade Cabinet Hardware",
    "description": "Client requested upgrade from standard cabinet hardware to premium fixtures",
    "jobId": 456,
    "categoryId": 102,
    "status": "Draft",
    "affectsSchedule": false,
    "requestedBy": 201,
    "requestedDate": "2023-07-25"
}

Response

Returns the newly created change order object (HTTP 201 Created).

PUT /changeorders/{id}

Updates an existing change order.

Request Body

{
    "title": "Upgrade Cabinet Hardware and Fixtures",
    "description": "Client requested upgrade from standard cabinet hardware to premium fixtures including handles and hinges",
    "status": "Pending Approval",
    "affectsSchedule": true,
    "scheduleImpactDays": 1
}

Response

Returns the updated change order object.

DELETE /changeorders/{id}

Deletes a change order. This may be disallowed for approved change orders or those in certain statuses.

Response

HTTP 204 No Content on successful deletion.

POST /changeorders/{id}/approve

Approves a change order, updating its status and recording approval information.

Request Body

{
    "approverNotes": "Approved as discussed with client on 7/28/2023"
}

Response

Returns the updated change order with approved status.

POST /changeorders/{id}/reject

Rejects a change order, updating its status and recording rejection information.

Request Body

{
    "rejectionReason": "Cost exceeds budget allowance",
    "additionalNotes": "Please revise with lower cost options"
}

Response

Returns the updated change order with rejected status.

GET /changeorders/{id}/lineItems

Retrieves all line items associated with a specific change order.

Request

GET /v1.0/changeorders/789/lineItems
Authorization: Bearer {access_token}

Response

Returns a collection of Change Order Line Items in this change order.
