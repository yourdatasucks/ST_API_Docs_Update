Marketing

The Marketing object represents marketing-related data and activities in ServiceTrade, including campaigns, leads, referral sources, and marketing analytics. This resource allows companies to track the effectiveness of their marketing efforts, manage marketing campaigns, and attribute new business to specific marketing channels or initiatives.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the marketing record. true false
name string Name of the marketing campaign or initiative. false true
type string Type of marketing activity (e.g., "Campaign", "Lead Source", "Referral", "Event"). false true
description string Detailed description of the marketing activity. false false
startDate datetime Start date and time of the marketing campaign or activity. false false
endDate datetime End date and time of the marketing campaign or activity. false false
status string Current status of the marketing activity (e.g., "Planned", "Active", "Completed", "Cancelled"). false false
budget decimal Budget allocated for the marketing campaign or activity. false false
cost decimal Actual cost incurred for the marketing campaign or activity. false false
roi decimal Return on investment calculation (percentage). true false
channel string Marketing channel (e.g., "Email", "Social Media", "Direct Mail", "Trade Show", "Referral"). false false
targetAudience string Description of the target audience for the marketing activity. false false
campaignCode string Unique code used to track the marketing campaign. false false
leadCount integer Number of leads generated by the marketing activity. true false
conversionRate decimal Percentage of leads that converted to customers. true false
revenue decimal Revenue attributed to this marketing activity. true false
tags array Array of tags associated with this marketing activity. false false
responsibleUserId integer ID of the User responsible for this marketing activity. false false
relatedCustomerIds array Array of Customer IDs associated with this marketing activity. false false
createdBy integer ID of the user who created this marketing record. true false
createdDate datetime Date and time when this marketing record was created. true false
lastModifiedBy integer ID of the user who last modified this marketing record. true false
lastModifiedDate datetime Date and time when this marketing record was last modified. true false
customFields object Custom fields and their values. false false

    "budget": 7500.00,
