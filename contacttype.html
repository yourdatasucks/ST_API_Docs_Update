Contact Type

The Contact Type object represents classifications or categories of contacts within the system. Examples might include "Decision Maker," "Billing Contact," "Site Manager," etc. Contact types help organize and filter Contacts based on their roles or responsibilities.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the contact type. true false
name string Name of the contact type. false true
description string Detailed description of the contact type. false false
isDefault boolean Whether this is a default contact type in the system. false false
isActive boolean Whether this contact type is active and available for use. false false
color string Color code (hex) associated with this contact type for visual identification. false false
icon string Icon identifier for this contact type. false false
order integer Display order for the contact type. false false
companyId integer ID of the company this contact type belongs to. Null for system-wide types. false false
createdDate datetime Date the contact type was created. true false
createdBy integer ID of the user who created the contact type. true false
lastModifiedDate datetime Date the contact type was last modified. true false
lastModifiedBy integer ID of the user who last modified the contact type. true false

POST /contacttypes

Creates a new contact type.

Request Body

{
    "name": "Project Coordinator",
    "description": "Contact responsible for coordinating project activities",
    "isActive": true,
    "color": "#D0021B",
    "icon": "project-diagram",
    "order": 4,
    "companyId": 123
}

Response

Returns the newly created contact type object (HTTP 201 Created).

PUT /contacttypes/{id}

Updates an existing contact type.

Request Body

{
    "name": "Project Manager",
    "description": "Contact responsible for managing project activities and resources",
    "color": "#CC0000",
    "order": 3
}

Response

Returns the updated contact type object.

DELETE /contacttypes/{id}

Deletes a contact type. This may be disallowed for default types or types that are in use.

Response

HTTP 204 No Content on successful deletion.

GET /contacttypes/{id}/contacts

Retrieves all contacts associated with a specific contact type.

Request

GET /v1.0/contacttypes/101/contacts
Authorization: Bearer {access_token}

Response

Returns a collection of Contacts with this contact type.
