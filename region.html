Region

The Region object represents a geographical area used for organizing locations, customers, and service operations. Regions can be defined based on sales territories, service coverage areas, or other business-specific divisions. They help streamline operations by allowing users to filter data by geographical boundaries and assign resources efficiently.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the region. true false
name string Name of the region. false true
description string Description of the region. false false
code string Short code or identifier for the region. false false
isActive boolean Whether the region is active in the system. false false
managerId integer User ID of the region manager. false false
parentRegionId integer ID of the parent region if this is a sub-region. false false
createdBy integer ID of the user who created this region. true false
createdDate datetime Date and time when this region was created. true false
lastModifiedBy integer ID of the user who last modified this region. true false
lastModifiedDate datetime Date and time when this region was last modified. true false
boundaries array Array of geographic coordinates defining the region boundaries. false false
customFields object Custom fields and their values for this region. false false

Region

The region resource is used to manage geographical regions within the organization.

  • Resource URL: /region
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /region 200
GET /region/123 200
GET /region/123 404 region not found
POST /region 200 region created
POST /region 400 invalid data
PUT /region/123 200 region updated
PUT /region/123 400 invalid data
PUT /region/123 404 region not found
DELETE /region/123 204 region deleted
DELETE /region/123 404 region not found
DELETE /region/123 409 region has dependent records

Returned Elements for /region/[regionId]

Name Type Value
id integer region entity ID
uri string resource identifier for the region
name string name of the region
description string description of the region
code string short code for the region
isActive boolean whether the region is active
manager object details about the region manager
parentRegion object details about the parent region if applicable
