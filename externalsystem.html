ExternalSystem

The ExternalSystem object represents an external system or application that integrates with ServiceTrade. It stores connection details, authentication credentials, and configuration settings for the integration.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the external system. true false
name string Name of the external system. false true
description string Description of the external system and its purpose. false false
type string Type of external system (e.g., "Accounting", "CRM", "ERP", "Custom"). false true
provider string Provider or vendor of the external system (e.g., "QuickBooks", "Salesforce", "SAP"). false false
version string Version of the external system. false false
status string Status of the integration (e.g., "Active", "Inactive", "Testing", "Error"). false true
connectionSettings object Connection settings for the external system (encrypted). false false
authType string Authentication type (e.g., "OAuth2", "API Key", "Basic Auth", "Custom"). false false
authSettings object Authentication settings and credentials (encrypted). false false
syncSettings object Default synchronization settings for this external system. false false
syncEntities array Array of entity types that are synchronized with this system. false false
syncSchedules array Array of scheduled synchronization configurations. false false
lastSyncDate datetime Date of the last successful synchronization. true false
lastSyncStatus string Status of the last synchronization attempt. true false
lastErrorMessage string Error message from the last failed synchronization, if applicable. true false
webhookSettings object Settings for webhooks received from the external system. false false
mappingSettings object Field mapping configurations between ServiceTrade and the external system. false false
metadata object Additional metadata about the external system. false false
createdDate datetime Date the external system record was created. true false
createdBy integer ID of the user who created the external system record. true false
lastModifiedDate datetime Date the external system record was last modified. true false
lastModifiedBy integer ID of the user who last modified the external system record. true false

ConnectionSettings Object Properties

The connectionSettings object contains connection parameters specific to the external system type.

Property Type Description
url string Base URL for the external system's API or service.
apiVersion string API version to use when connecting.
timeout integer Connection timeout in seconds.
retryAttempts integer Number of retry attempts for failed connections.
customHeaders object Custom HTTP headers to include in requests.
proxySettings object Proxy settings if required.

SyncSettings Object Properties

The syncSettings object contains default synchronization settings for the external system.

Property Type Description
batchSize integer Number of records to process in each batch.
conflictResolution string Default conflict resolution strategy (e.g., "ServiceTradeWins", "ExternalSystemWins", "MostRecent", "Manual").
errorThreshold integer Maximum number of errors before sync operation is aborted.
notificationEmails array Email addresses to notify about sync results.
logLevel string Level of detail for sync logs (e.g., "Error", "Warning", "Info", "Debug").

ExternalSystem

The externalsystem resource is used to manage ExternalSystem data within ServiceTrade.

  • Resource URL: /externalsystem
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /externalsystem 200
GET /externalsystem/123 200
GET /externalsystem/123 404 externalsystem not found
POST /externalsystem 200 externalsystem created
POST /externalsystem 400 invalid data
PUT /externalsystem/123 200 externalsystem updated
PUT /externalsystem/123 400 invalid data
PUT /externalsystem/123 404 externalsystem not found
DELETE /externalsystem/123 204 externalsystem deleted
DELETE /externalsystem/123 404 externalsystem not found

Returned Elements for /externalsystem/[externalsystemId]

Name Type Value
id integer externalsystem entity ID
uri string resource identifier for the externalsystem
name string name of the externalsystem
