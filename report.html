Report

The Report object represents customizable data analyses and visualizations within ServiceTrade. Reports allow users to extract, aggregate, and visualize data across various entities such as Jobs, Invoices, Customers, and other resources. Reports can be scheduled, exported, and shared with stakeholders to support business intelligence, operational metrics tracking, and decision-making.

Report

The report resource is used to manage Report data within ServiceTrade.

  • Resource URL: /report
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /report 200
GET /report/123 200
GET /report/123 404 report not found
POST /report 200 report created
POST /report 400 invalid data
PUT /report/123 200 report updated
PUT /report/123 400 invalid data
PUT /report/123 404 report not found
DELETE /report/123 204 report deleted
DELETE /report/123 404 report not found

Returned Elements for /report/[reportId]

Name Type Value
id integer report entity ID
uri string resource identifier for the report
name string name of the report
