Report

The Report object represents customizable data analyses and visualizations within ServiceTrade. Reports allow users to extract, aggregate, and visualize data across various entities such as Jobs, Invoices, Customers, and other resources. Reports can be scheduled, exported, and shared with stakeholders to support business intelligence, operational metrics tracking, and decision-making.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the report. true false
name string Name of the report. false true
description string Description of the report's purpose and contents. false false
type string Type of report (e.g., "Standard", "Custom", "Dashboard", "Chart"). false true
category string Category the report belongs to (e.g., "Financial", "Operational", "Customer", "Service"). false false
entityType string Primary entity type the report is based on (e.g., "Job", "Invoice", "Customer"). false true
format string Format of the report (e.g., "Table", "Chart", "Matrix", "Summary"). false true
columns array Array of column definitions for the report. false false
filters array Array of filter criteria applied to the report. false false
sortBy string Field to sort results by. false false
sortDirection string Direction of sort (e.g., "ASC", "DESC"). false false
groupBy array Array of fields to group results by. false false
aggregations array Array of aggregation functions and fields (e.g., sum, average, count). false false
chartType string Type of chart if report includes visualization (e.g., "Bar", "Line", "Pie", "Area"). false false
chartOptions object Visualization options for chart display. false false
isPublic boolean Whether the report is visible to all users. false false
isScheduled boolean Whether the report is scheduled for automatic generation. false false
schedule object Schedule configuration for report generation. false false
recipients array Array of recipients for scheduled report delivery. false false
lastRunDate datetime Date and time when the report was last generated. true false
lastRunStatus string Status of the last report generation (e.g., "Success", "Failed"). true false
lastRunDuration integer Duration in seconds of the last report generation. true false
exportFormats array Array of supported export formats (e.g., "PDF", "XLSX", "CSV"). false false
isTemplate boolean Whether this report serves as a template for other reports. false false
parentReportId integer ID of the parent report if this is a variation of another report. false false
createdBy integer ID of the user who created this report. true false
createdDate datetime Date and time when this report was created. true false
lastModifiedBy integer ID of the user who last modified this report. true false
lastModifiedDate datetime Date and time when this report was last modified. true false
customFields object Custom fields and their values. false false

POST /reports/{id}/export

Exports a report in the specified format.

Request Body

{
    "format": "PDF",
    "parameters": {
        "startDate": "2023-01-01",
        "endDate": "2023-06-30"
    },
    "options": {
        "paperSize": "Letter",
        "orientation": "Landscape",
        "includeCharts": true,
        "includeCompanyLogo": true,
        "includePageNumbers": true
    }
}

Response

Returns a download URL for the exported report.

POST /reports/{id}/clone

Creates a new report by cloning an existing report.

Request Body

{
    "name": "Technician Performance - Eastern Region",
    "description": "Technician performance analysis for the Eastern Region",
    "additionalFilters": [
        {
            "field": "region",
            "operator": "equals",
            "value": "East"
        }
    ],
    "preserveSchedule": false
}

Response

Returns the newly created report based on the cloned template.

Request Body

{
    "reportId": 1001,
    "userId": 105,
    "email": "jane.smith@example.com",
    "format": "PDF",
    "frequency": "Weekly"
}

Response

Returns the created subscription information.

Cancels a report subscription.

Response
