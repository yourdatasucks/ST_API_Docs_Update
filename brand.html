Brand

The Brand object represents the different brands or sub-brands that can be associated with companies, products, or marketing materials in the ServiceTrade system.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the brand. true false
name string Name of the brand. false true
description string Description of the brand. false false
logoUrl string URL to the brand's logo image. false false
primaryColor string Primary brand color (hex code). false false
isActive boolean Whether the brand is currently active. false false
createdAt datetime When the brand was created. true false
updatedAt datetime When the brand was last updated. true false

Endpoints

API endpoints for Brand management...

Brand

The brand resource is used to manage Brand data within ServiceTrade.

  • Resource URL: /brand
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /brand 200
GET /brand/123 200
GET /brand/123 404 brand not found
POST /brand 200 brand created
POST /brand 400 invalid data
PUT /brand/123 200 brand updated
PUT /brand/123 400 invalid data
PUT /brand/123 404 brand not found
DELETE /brand/123 204 brand deleted
DELETE /brand/123 404 brand not found

Returned Elements for /brand/[brandId]

Name Type Value
id integer brand entity ID
uri string resource identifier for the brand
name string name of the brand
