Brand

The Brand object represents the different brands or sub-brands that can be associated with companies, products, or marketing materials in the ServiceTrade system.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the brand. true false
name string Name of the brand. false true
description string Description of the brand. false false
logoUrl string URL to the brand's logo image. false false
primaryColor string Primary brand color (hex code). false false
isActive boolean Whether the brand is currently active. false false
createdAt datetime When the brand was created. true false
updatedAt datetime When the brand was last updated. true false

POST /brands

Creates a new brand.

Request Body

{
    "name": "Regional Division",
    "description": "Brand for our regional markets",
    "primaryColor": "#2D882D"
}

Response

Returns the newly created brand object (HTTP 201 Created).

PUT /brands/{id}

Updates an existing brand.

Request Body

{
    "description": "Brand for our regional markets - Updated positioning",
    "primaryColor": "#2D8855"
}

Response

Returns the updated brand object.

DELETE /brands/{id}

Deletes a brand. This may be disallowed if the brand is in use.

Response

HTTP 204 No Content on successful deletion.
