Deficiency Report

The Deficiency Report object represents a compilation of Deficiencies identified during an inspection or assessment. It serves as a container for individual deficiencies and provides context for when, where, and by whom the inspection was conducted.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the deficiency report. true false
title string Title of the deficiency report. false true

approvedDate date Date when the report was approved. false false

DeficiencyCount Object Properties

Property Type Description
total integer Total number of deficiencies in the report.
byStatus object Count grouped by status (e.g., {"Open": 10, "Resolved": 5, "Waived": 2}).
bySeverity object Count grouped by severity (e.g., {"Critical": 3, "Major": 7, "Minor": 7}).
byCategory object Count grouped by category (e.g., {"Mechanical": 8, "Electrical": 5, "Safety": 4}).

Deficiency Report

The deficiencyreport resource is used to manage Deficiency Report data within ServiceTrade.

  • Resource URL: /deficiencyreport
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /deficiencyreport 200
GET /deficiencyreport/123 200
GET /deficiencyreport/123 404 deficiencyreport not found
POST /deficiencyreport 200 deficiencyreport created
POST /deficiencyreport 400 invalid data
PUT /deficiencyreport/123 200 deficiencyreport updated
PUT /deficiencyreport/123 400 invalid data
PUT /deficiencyreport/123 404 deficiencyreport not found
DELETE /deficiencyreport/123 204 deficiencyreport deleted
DELETE /deficiencyreport/123 404 deficiencyreport not found

Returned Elements for /deficiencyreport/[deficiencyreportId]

Name Type Value
