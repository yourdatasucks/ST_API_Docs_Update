Deficiency Report

The Deficiency Report object represents a compilation of Deficiencies identified during an inspection or assessment. It serves as a container for individual deficiencies and provides context for when, where, and by whom the inspection was conducted.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the deficiency report. true false
title string Title of the deficiency report. false true
description string Detailed description of the report scope and purpose. false false
companyId integer ID of the customer Company this report is for. false true
locationIds array Array of Location IDs covered in this report. false false
reportType string Type of report (e.g., "Safety Inspection", "Preventive Maintenance", "Regulatory Compliance"). false false
status string Status of the report (e.g., "Draft", "Submitted", "In Progress", "Completed"). false true
inspectionDate date Date when the inspection or assessment was conducted. false true
inspectedBy array Array of user IDs who conducted the inspection. false false
approvedBy integer ID of the user who approved the report. false false
approvedDate date Date when the report was approved. false false
dueDate date Date by which all deficiencies should be addressed. false false
priority string Overall priority of the report (e.g., "High", "Medium", "Low"). false false
notes string Additional notes about the report. false false
reportUrl string URL to the generated PDF report document if available. true false
attachmentIds array Array of Attachment IDs related to this report. false false
jobId integer ID of the Job that initiated this report, if applicable. false false
contractId integer ID of the Contract this report is associated with, if applicable. false false
deficiencyCount object Count of deficiencies by status and severity. true false
estimatedCost decimal Total estimated cost to address all deficiencies in the report. true false
customFields object Custom field values for the report. false false
tags array Array of tags associated with the report. false false
createdDate datetime Date the report was created. true false
createdBy integer ID of the user who created the report. true false
lastModifiedDate datetime Date the report was last modified. true false
lastModifiedBy integer ID of the user who last modified the report. true false

DeficiencyCount Object Properties

Property Type Description
total integer Total number of deficiencies in the report.
byStatus object Count grouped by status (e.g., {"Open": 10, "Resolved": 5, "Waived": 2}).
bySeverity object Count grouped by severity (e.g., {"Critical": 3, "Major": 7, "Minor": 7}).
byCategory object Count grouped by category (e.g., {"Mechanical": 8, "Electrical": 5, "Safety": 4}).

POST /deficiencyreports

Creates a new deficiency report.

Request Body

{
    "title": "Quarterly Fire Safety Inspection - Building B",
    "description": "Quarterly inspection of all fire safety systems and equipment in Building B.",
    "companyId": 456,
    "locationIds": [202],
    "reportType": "Safety Inspection",
    "status": "Draft",
    "inspectionDate": "2023-07-20",
    "inspectedBy": [304],
    "dueDate": "2023-08-20",
    "priority": "High",
    "notes": "Required for compliance with local fire safety regulations.",
    "jobId": 602,
    "contractId": 701,
    "customFields": {
        "reportNumber": "FSI-2023-Q3-B",
        "inspectionType": "Quarterly",
        "complianceReference": "NFPA 25"
    },
    "tags": ["Fire Safety", "Quarterly Inspection", "Compliance"]
}

Response

Returns the newly created deficiency report object (HTTP 201 Created).

PUT /deficiencyreports/{id}

Updates an existing deficiency report.

Request Body

{
    "status": "Completed",
    "approvedBy": 401,
    "approvedDate": "2023-07-25",
    "notes": "All deficiencies have been addressed. Final approval granted after site verification."
}

Response

Returns the updated deficiency report object.

DELETE /deficiencyreports/{id}

Deletes a deficiency report. This may also delete associated deficiencies.

Response

HTTP 204 No Content on successful deletion.

GET /deficiencyreports/{id}/deficiencies

Retrieves all deficiencies associated with a specific deficiency report.

Request

GET /v1.0/deficiencyreports/123/deficiencies
Authorization: Bearer {access_token}

Response

Returns a collection of Deficiencies associated with this report.

POST /deficiencyreports/{id}/deficiencies

Adds a new deficiency to the report.

Request Body

{
    "assetId": 791,
    "locationId": 201,
    "title": "Fire Extinguisher Missing Inspection Tag",
    "description": "Fire extinguisher in south corridor is missing current inspection tag. Last inspection date is over 12 months old.",
    "severity": "Major",
    "priority": "High",
    "status": "Open",
    "category": "Safety",
    "subCategory": "Fire Protection",
    "code": "S-FP-001",
    "identifiedDate": "2023-07-15",
    "identifiedBy": 302,
    "dueDate": "2023-07-30",
    "imageUrls": [
        "https://example.com/images/deficiency/temp-fire-1.jpg"
    ],
    "tags": ["Fire Extinguisher", "Compliance", "Inspection Tag"]
}

Response

Returns the newly created Deficiency object.

POST /deficiencyreports/{id}/generate

Generates a formatted PDF report of the deficiency report and its deficiencies.

Request Body

{
    "includeImages": true,
    "includeCosts": false,
    "includeRecommendations": true,
    "format": "PDF",
    "template": "standard"
}

Response

Returns the deficiency report object with updated reportUrl property.

POST /deficiencyreports/{id}/submit

Submits the report, changing its status from Draft to Submitted.

Request Body

{
    "notes": "Completed all inspections and documented all identified issues.",
    "notifyIds": [401, 402],
    "generatePdf": true
}

Response

Returns the updated deficiency report object with Submitted status.

POST /deficiencyreports/{id}/approve

Approves the deficiency report.

Request Body

{
    "approvedBy": 401,
    "approvedDate": "2023-07-25",
    "notes": "Approved after review of all findings and recommendations.",
    "notifyIds": [302, 303, 501]
}

Response

Returns the updated deficiency report object with approved information.

GET /deficiencyreports/{id}/attachments

Retrieves attachments associated with a specific deficiency report.

Request

GET /v1.0/deficiencyreports/123/attachments
Authorization: Bearer {access_token}

Response

Returns a collection of Attachments associated with this report.

POST /deficiencyreports/{id}/attachments

Adds an attachment to a deficiency report.

Request

Multipart form data with file and metadata.

Response

Returns the created Attachment object and updates the report's attachmentIds.

POST /deficiencyreports/{id}/export

Exports the deficiency report data to an external format (CSV, Excel, etc.).

Request Body

{
    "format": "Excel",
    "includeDeficiencies": true,
    "includeResolvedDeficiencies": true,
    "includeCosts": true
}

Response

Returns a URL to download the exported file.
