User Absence

The User Absence object represents periods of time when a User is unavailable for work assignments or scheduling. This includes vacation time, sick leave, personal time off, training days, or any other planned absence. The absence information is used by the scheduling system to prevent assignment of jobs during these periods and helps in resource planning. Absences can be recurring or one-time events and may require approval from managers depending on company policies.

Properties

Property Type Description Read-Only Required

status string Status of the absence request (e.g., "Pending", "Approved", "Denied", "Canceled"). false false
approvalRequired boolean Whether the absence requires manager approval. false false

approvedDate datetime Date and time when the absence request was approved. true false
deniedReason string Reason provided if the absence request was denied. true false
isRecurring boolean Whether this is a recurring absence. false false
recurrencePattern object Pattern information for recurring absences. false false
parentAbsenceId integer For recurring instances, the ID of the parent absence pattern. false false
duration integer Duration of the absence in minutes. true false
durationDays decimal Duration of the absence in days (for PTO tracking). true false
ptoUsed decimal Amount of paid time off used for this absence. false false
color string Color code for visual representation in calendars. false false

createdDate datetime Date and time when this absence record was created. true false
lastModifiedBy integer ID of the user who last modified this absence record. true false
lastModifiedDate datetime Date and time when this absence record was last modified. true false
notes string Additional notes or instructions related to the absence. false false
customFields object Custom fields and their values. false false

POST /userabsences

Creates a new user absence record.

Request Body

{
    "userId": 101,
    "title": "Doctor's Appointment",
    "description": "Annual physical examination",
    "startDate": "2023-08-15T13:00:00Z",
    "endDate": "2023-08-15T15:00:00Z",
    "allDay": false,
    "type": "Personal",
    "approvalRequired": true,
    "isPrivate": true,
    "ptoUsed": 2.0,
    "color": "#2196F3",
    "notes": "Will check messages during waiting time and will be available by phone if needed urgently."
}

Response

Returns the newly created user absence record (HTTP 201 Created).

PUT /userabsences/{id}

Updates an existing user absence record.

Request Body

{
    "startDate": "2023-08-15T14:00:00Z",
    "endDate": "2023-08-15T16:00:00Z",
    "notes": "Appointment time changed. Will check messages during waiting time and will be available by phone if needed urgently.",
    "ptoUsed": 2.0
}

Response

Returns the updated user absence record.

DELETE /userabsences/{id}

Deletes a user absence record.

Response

HTTP 204 No Content on successful deletion.

POST /userabsences/{id}/cancel

Cancels a previously approved or pending absence without deleting the record.

Request Body

{
    "reason": "Appointment rescheduled by doctor's office",
    "notifyManager": true
}

Response

Returns the canceled user absence record with updated status.

POST /userabsences/{id}/approve

Approves a pending absence request (typically used by managers).

Request Body

{
    "comments": "Approved. Please ensure your ongoing tasks are handed over to the backup contact.",
    "notifyUser": true
}

Response

Returns the approved user absence record with updated status.

POST /userabsences/{id}/deny

}

Response

Returns the denied user absence record with updated status.
