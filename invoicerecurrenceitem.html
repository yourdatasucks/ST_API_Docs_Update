Invoice Recurrence Item

The Invoice Recurrence Item object represents a line item in an Invoice Recurrence template. Each invoice recurrence item defines a product or service that will appear as a line item on automatically generated recurring invoices, including its description, quantity, price, and tax information.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the invoice recurrence item. true false
invoiceRecurrenceId integer ID of the Invoice Recurrence this item belongs to. false true
description string Description of the item, to be displayed on generated invoices. false true
quantity decimal Quantity of the item. false true
unitPrice decimal Price per unit. false true
unitCost decimal Cost per unit (for profit calculations, not shown on generated invoices). false false
taxable boolean Whether this item is subject to tax. false false
taxRateId integer ID of the Tax Rate to apply to this item, if different from the recurrence's default tax rate. false false
sequenceNumber integer Display order of this item on generated invoices. false false
itemType string Type of item (e.g., "Product", "Service", "Labor", "Material", "Fee"). false false
serviceItemId integer ID of the Service Item this invoice recurrence item is associated with, if applicable. false false
notes string Additional notes about this line item (internal use, not shown on generated invoices). false false
createdBy integer ID of the user who created this invoice recurrence item. true false
createdDate datetime Date and time when this invoice recurrence item was created. true false
lastModifiedBy integer ID of the user who last modified this invoice recurrence item. true false
lastModifiedDate datetime Date and time when this invoice recurrence item was last modified. true false
customFields object Custom fields and their values. false false

Invoice Recurrence Item

The invoicerecurrenceitem resource is used to manage Invoice Recurrence Item data within ServiceTrade.

  • Resource URL: /invoicerecurrenceitem
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes
