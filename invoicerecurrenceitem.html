Invoice Recurrence Item

The Invoice Recurrence Item object represents a line item in an Invoice Recurrence template. Each invoice recurrence item defines a product or service that will appear as a line item on automatically generated recurring invoices, including its description, quantity, price, and tax information.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the invoice recurrence item. true false
invoiceRecurrenceId integer ID of the Invoice Recurrence this item belongs to. false true
description string Description of the item, to be displayed on generated invoices. false true
quantity decimal Quantity of the item. false true
unitPrice decimal Price per unit. false true
unitCost decimal Cost per unit (for profit calculations, not shown on generated invoices). false false
taxable boolean Whether this item is subject to tax. false false
taxRateId integer ID of the Tax Rate to apply to this item, if different from the recurrence's default tax rate. false false
sequenceNumber integer Display order of this item on generated invoices. false false
itemType string Type of item (e.g., "Product", "Service", "Labor", "Material", "Fee"). false false
serviceItemId integer ID of the Service Item this invoice recurrence item is associated with, if applicable. false false
notes string Additional notes about this line item (internal use, not shown on generated invoices). false false
createdBy integer ID of the user who created this invoice recurrence item. true false
createdDate datetime Date and time when this invoice recurrence item was created. true false
lastModifiedBy integer ID of the user who last modified this invoice recurrence item. true false
lastModifiedDate datetime Date and time when this invoice recurrence item was last modified. true false
customFields object Custom fields and their values. false false

POST /invoicerecurrences/{invoiceRecurrenceId}/items

Creates a new invoice recurrence item for the specified invoice recurrence.

Request Body

{
    "description": "Emergency Service Coverage",
    "quantity": 1,
    "unitPrice": 75.00,
    "unitCost": 35.00,
    "taxable": true,
    "sequenceNumber": 3,
    "itemType": "Service",
    "serviceItemId": 120,
    "notes": "24/7 emergency service coverage with 2-hour response time",
    "customFields": {
        "departmentCode": "SVC-01",
        "contractLineItemId": "CLN-2022-790"
    }
}

Response

Returns the newly created invoice recurrence item (HTTP 201 Created).

PUT /invoicerecurrenceitems/{id}

Updates an existing invoice recurrence item.

Request Body

{
    "description": "Premium Emergency Service Coverage",
    "quantity": 1,
    "unitPrice": 100.00,
    "taxable": true,
    "notes": "24/7 emergency service coverage with 1-hour response time",
    "customFields": {
        "departmentCode": "SVC-01",
        "contractLineItemId": "CLN-2022-790",
        "serviceLevel": "Premium"
    }
}

Response

Returns the updated invoice recurrence item.

DELETE /invoicerecurrenceitems/{id}

Deletes an invoice recurrence item.

Response

HTTP 204 No Content on successful deletion.

PUT /invoicerecurrences/{invoiceRecurrenceId}/items/reorder

Reorders the line items in an invoice recurrence.

Request Body

{
    "itemOrder": [5002, 5001, 5003]
}

Response

Returns success message and updates the sequenceNumber property of the affected items.

GET /serviceitems/{serviceItemId}/invoicerecurrenceitems

Retrieves all invoice recurrence items associated with a specific service item.

Request

GET /v1.0/serviceitems/118/invoicerecurrenceitems
Authorization: Bearer {access_token}

Response

Returns a collection of invoice recurrence items associated with the specified service item.

POST /serviceitems/{serviceItemId}/invoicerecurrenceitems

Creates invoice recurrence items from a service item across multiple recurrences.

Request Body

{
    "invoiceRecurrenceIds": [1001, 1002, 1003],
    "quantity": 1,
    "unitPrice": 150.00,
    "taxable": true,
    "itemType": "Service"
}

Response

Returns an array of the created invoice recurrence items.
