Tag

The Tag object represents a label or keyword that can be associated with various entities in the system to categorize and filter them. Tags provide a flexible way to organize data across different object types and can be applied to jobs, customers, locations, assets, and other entities. This allows for custom categorization beyond the standard fields and properties.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the tag. true false
name string Name of the tag. false true
description string Description of the tag. false false
color string Color code (hex or named color) for visual representation of the tag. false false
isActive boolean Whether the tag is active and available for use. false false
isSystem boolean Whether this is a system-defined tag that cannot be modified or deleted. true false
categoryId integer ID of the category this tag belongs to, if any. false false
allowedEntityTypes array Array of entity types that this tag can be applied to (e.g., ["job", "customer", "asset"]). false false
createdBy integer ID of the user who created this tag. true false
createdDate datetime Date and time when this tag was created. true false
lastModifiedBy integer ID of the user who last modified this tag. true false
lastModifiedDate datetime Date and time when this tag was last modified. true false
useCount integer Number of entities this tag is associated with. true false

Tag

The tag resource is used to manage tags and their associations with other entities.

  • Resource URL: /tag
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /tag 200
GET /tag/123 200
GET /tag/123 404 tag not found
POST /tag 200 tag created
POST /tag 400 invalid data
PUT /tag/123 200 tag updated
PUT /tag/123 400 invalid data
PUT /tag/123 404 tag not found
DELETE /tag/123 204 tag deleted
DELETE /tag/123 404 tag not found
DELETE /tag/123 403 cannot delete system tag

Returned Elements for /tag/[tagId]

Name Type Value
id integer tag entity ID
uri string resource identifier for the tag
name string name of the tag
description string description of the tag
color string color code for the tag
isActive boolean whether the tag is active
isSystem boolean whether this is a system tag
category object category information for this tag
useCount integer number of entities using this tag
