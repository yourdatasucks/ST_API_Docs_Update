Invoice

The Invoice object represents a billing document sent to customers for services rendered or products delivered. Invoices track amounts owed, payment status, and line items. The Invoice API enables creating, retrieving, and managing invoices within ServiceTrade.

Properties

Invoice

The invoice resource is used to manage Invoice data within ServiceTrade.

  • Resource URL: /invoice
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /invoice 200
GET /invoice/123 200
GET /invoice/123 404 invoice not found
POST /invoice 200 invoice created
POST /invoice 400 invalid data
PUT /invoice/123 200 invoice updated
PUT /invoice/123 400 invalid data
PUT /invoice/123 404 invoice not found
DELETE /invoice/123 204 invoice deleted
DELETE /invoice/123 404 invoice not found

Returned Elements for /invoice/[invoiceId]

Name Type Value
id integer invoice entity ID
uri string resource identifier for the invoice
name string name of the invoice
