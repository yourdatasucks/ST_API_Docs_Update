Invoice

The Invoice object represents a billing document sent to customers for services rendered or products delivered. Invoices track amounts owed, payment status, and line items. The Invoice API enables creating, retrieving, and managing invoices within ServiceTrade.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the invoice. true false
number string Invoice number, typically displayed to customers. false false
customerId integer ID of the Customer being billed. false true
jobId integer ID of the Job this invoice is related to, if applicable. false false
status string Status of the invoice (e.g., "Draft", "Sent", "Paid", "Overdue", "Void"). false false
date date Date the invoice was issued. false true
dueDate date Date payment is due. false false
subtotal decimal Sum of all line items before tax and discounts. true false
discountAmount decimal Total discount applied to the invoice. false false
discountType string Type of discount (e.g., "Percentage", "Fixed"). false false
discountPercentage decimal Percentage discount, if applicable. false false
taxAmount decimal Total tax applied to the invoice. true false
taxRate decimal Tax rate applied to taxable items. false false
taxGroupId integer ID of the TaxGroup used for this invoice. false false
total decimal Total amount due (subtotal - discounts + taxes). true false
amountPaid decimal Amount already paid against this invoice. true false
balance decimal Remaining balance to be paid (total - amountPaid). true false
currency string Currency code (e.g., "USD", "EUR", "GBP"). false false
notes string Additional notes displayed on the invoice. false false
termsAndConditions string Terms and conditions displayed on the invoice. false false
paymentTermsId integer ID of the Payment Terms for this invoice. false false
billingAddress object Billing address for the invoice. false false
shippingAddress object Shipping address, if applicable. false false
items array Array of Invoice Item objects. false false
payments array Array of Payment objects linked to this invoice. true false
attachments array Array of Attachment objects related to this invoice. false false
createdBy integer ID of the user who created the invoice. true false
createdDate datetime Date and time the invoice was created. true false
lastModifiedBy integer ID of the user who last modified the invoice. true false
lastModifiedDate datetime Date and time the invoice was last modified. true false
sentDate datetime Date and time the invoice was sent to the customer. true false
paidDate datetime Date and time the invoice was fully paid. true false
voidedDate datetime Date and time the invoice was voided, if applicable. true false
invoiceRecurrenceId integer ID of the InvoiceRecurrence that generated this invoice, if applicable. true false
externalId string Reference to this invoice in an external system. false false
externalSyncStatus string Status of synchronization with external systems. true false
customFields object Custom fields and their values. false false

Address Object Properties

Both billingAddress and shippingAddress have the following properties:

Property Type Description
name string Name for the address (recipient or company name).
street1 string First line of street address.
street2 string Second line of street address.
city string City name.
state string State, province, or region.
zip string Postal or ZIP code.
country string Country name or code.
phone string Contact phone number.
email string Contact email address.

PUT /invoices/{id}

Updates an existing invoice. Limited to certain fields depending on invoice status.

Request Body

{
    "notes": "Thank you for your business! Please reference your PO# when submitting payment.",
    "termsAndConditions": "Payment due within 30 days. Late payments subject to a 2.0% monthly finance charge.",
    "dueDate": "2023-08-31",
    "customFields": {
        "purchaseOrderNumber": "PO-12345-REV",
        "department": "Facilities",
        "contractNumber": "CONT-789"
    }
}

Response

Returns the updated invoice.

DELETE /invoices/{id}

Deletes a draft invoice. Only invoices in "Draft" status can be deleted.

Response

HTTP 204 No Content on successful deletion.

POST /invoices/{id}/void

Voids an invoice. This cannot be undone and is generally preferred over deletion for record-keeping.

Request Body

{
    "reason": "Customer requested cancellation of services",
    "notify": false
}

Response

Returns the updated invoice with status changed to "Void".

POST /invoices/{id}/send

Sends an invoice to the customer via email.

Request Body

{
    "recipients": ["accounting@acmecorp.com", "manager@acmecorp.com"],
    "cc": ["sales@servicetrade.com"],
    "bcc": ["records@servicetrade.com"],
    "subject": "Invoice #INV-2023-0789 from ServiceTrade",
    "message": "Please find attached your invoice for recent fire alarm services. Thank you for your business!",
    "attachAdditionalDocuments": true
}

Response

Returns the updated invoice with sentDate and status updated.

GET /invoices/{id}/pdf

Generates and returns a PDF version of the invoice.

Request

GET /v1.0/invoices/12345/pdf
Authorization: Bearer {access_token}

Response

Returns the invoice PDF document for download.

POST /invoices/{id}/payments

Records a payment against an invoice.

Request Body

{
    "amount": 2418.75,
    "date": "2023-08-10",
    "method": "Check",
    "reference": "Check #12345",
    "notes": "Payment received in full",
    "depositAccountId": 789
}

Response

Returns the created Payment object and updates the invoice status if fully paid.

GET /invoices/{id}/payments

Retrieves all payments made against an invoice.

Request

GET /v1.0/invoices/12345/payments
Authorization: Bearer {access_token}

Response

Returns a collection of Payment objects linked to the invoice.

POST /invoices/{id}/attachments

Adds an attachment to an invoice.

Request

A multipart/form-data request containing the file to attach.

Response

Returns the created Attachment object.

GET /invoices/{id}/attachments

Retrieves all attachments for an invoice.

Request

GET /v1.0/invoices/12345/attachments
Authorization: Bearer {access_token}

Response

Returns a collection of Attachment objects linked to the invoice.
