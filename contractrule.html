Contract Rule

The Contract Rule object represents specific terms, conditions, or service level agreements (SLAs) within a Contract. Rules define the specific obligations and requirements such as service frequency, response times, coverage hours, and other contractual terms.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the contract rule. true false
contractId integer ID of the parent Contract. false true
type string Type of rule (e.g., "ServiceFrequency", "ResponseTime", "CoverageHours", "PriceEscalation"). false true
name string Name or title of the rule. false true
description string Detailed description of the rule. false false
isActive boolean Whether this rule is currently active within the contract. false false
startDate date Date when the rule becomes effective (if different from contract start date). false false
endDate date Date when the rule expires (if different from contract end date). false false
serviceTypeIds array Array of service type IDs this rule applies to. false false
assetIds array Array of Asset IDs this rule applies to. false false
locationIds array Array of Location IDs this rule applies to. false false
priority string Priority level (e.g., "High", "Medium", "Low") if applicable. false false
parameters object Type-specific parameters for the rule (structure varies by rule type). false true
notes string Additional notes about the rule. false false
createdDate datetime Date the rule was created. true false
createdBy integer ID of the user who created the rule. true false
lastModifiedDate datetime Date the rule was last modified. true false
lastModifiedBy integer ID of the user who last modified the rule. true false

Rule Parameters by Type

The parameters object structure varies based on the rule type:

ServiceFrequency Parameters

Property Type Description
frequency string Frequency of service (e.g., "Weekly", "Monthly", "Quarterly", "Annually").
interval integer Interval value for the frequency (e.g., 2 for bi-weekly when frequency is "Weekly").
minimumVisits integer Minimum number of service visits required per term.
preferredDays array Array of preferred days for service (e.g., ["Monday", "Wednesday"]).
preferredTimeRange string Preferred time range for service (e.g., "Morning", "Afternoon").

ResponseTime Parameters

Property Type Description
responseTimeHours number Maximum response time in hours.
severity string Severity level this response time applies to (e.g., "Emergency", "Critical", "Normal").
businessHoursOnly boolean Whether response time applies only during business hours.
penalty decimal Financial penalty for missing the response time target.

CoverageHours Parameters

Property Type Description
coverage string Coverage type (e.g., "24x7", "8x5", "12x7").
businessHoursStart string Business hours start time (e.g., "08:00").
businessHoursEnd string Business hours end time (e.g., "17:00").
businessDays array Array of business days (e.g., ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday"]).
holidaysIncluded boolean Whether holidays are included in coverage.
afterHoursRate decimal Hourly rate for services outside of covered hours.

Contract Rule

The contractrule resource is used to manage Contract Rule data within ServiceTrade.

  • Resource URL: /contractrule
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /contractrule 200
GET /contractrule/123 200
GET /contractrule/123 404 contractrule not found
POST /contractrule 200 contractrule created
POST /contractrule 400 invalid data
PUT /contractrule/123 200 contractrule updated
PUT /contractrule/123 400 invalid data
PUT /contractrule/123 404 contractrule not found
DELETE /contractrule/123 204 contractrule deleted
DELETE /contractrule/123 404 contractrule not found

Returned Elements for /contractrule/[contractruleId]
