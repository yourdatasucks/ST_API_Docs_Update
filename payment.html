Payment

The Payment object represents financial transactions received from Customers towards Invoices. Payments can be applied to one or more invoices, and track important information such as payment method, transaction details, and allocation to specific invoices. This resource enables proper accounting, accounts receivable management, and customer payment history tracking.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the payment. true false
referenceNumber string Reference number for the payment (e.g., check number, transaction ID). false false
customerId integer ID of the Customer who made the payment. false true
amount decimal Total payment amount. false true
currency string Currency code (e.g., "USD", "EUR", "GBP"). false false
paymentDate date Date when the payment was made. false true
postDate date Date when the payment was posted to the accounting system. false false
method string Payment method (e.g., "Check", "Credit Card", "ACH", "Wire Transfer", "Cash"). false true
status string Status of the payment (e.g., "Pending", "Completed", "Failed", "Voided"). false true
appliedAmount decimal Amount of the payment that has been applied to invoices. true false
unappliedAmount decimal Amount of the payment that has not yet been applied to invoices. true false
transactionId string External transaction ID for electronic payments. false false
gatewayId string Payment gateway identifier for electronic payments. false false
authorizationCode string Authorization code for credit card transactions. false false
paymentProcessor string Name of the payment processor used (e.g., "Stripe", "PayPal", "Authorize.Net"). false false
cardType string Type of credit card used (e.g., "Visa", "Mastercard", "Amex"). false false
cardLastFour string Last four digits of the credit card number. false false
accountLastFour string Last four digits of the bank account number for ACH transactions. false false
notes string Additional notes about the payment. false false
receiptSent boolean Whether a receipt was sent to the customer. false false
receiptSentDate datetime Date and time when the receipt was sent. true false
receiptRecipients array Array of email addresses the receipt was sent to. false false
contactId integer ID of the Contact who made the payment. false false
locationId integer ID of the Location associated with the payment. false false
paidInvoices array Array of invoice IDs that this payment has been applied to. true false
createdBy integer ID of the user who created this payment record. true false
createdDate datetime Date and time when this payment record was created. true false
lastModifiedBy integer ID of the user who last modified this payment record. true false
lastModifiedDate datetime Date and time when this payment record was last modified. true false
customFields object Custom fields and their values. false false

POST /payments

Creates a new payment record.

Request Body

{
    "referenceNumber": "ACH45678",
    "customerId": 1002,
    "amount": 5750.00,
    "currency": "USD",
    "paymentDate": "2023-07-01",
    "method": "ACH",
    "status": "Completed",
    "transactionId": "ACH-TRAN-99872354",
    "accountLastFour": "4567",
    "notes": "Monthly service payment",
    "contactId": 3015,
    "locationId": 2010,
    "receiptSent": true,
    "receiptRecipients": ["ap@customer.com", "facilities@customer.com"],
    "customFields": {
        "accountingCode": "AR-12345",
        "department": "Service"
    },
    "invoiceAllocations": [
        {
            "invoiceId": 5025,
            "amount": 3500.00
        },
        {
            "invoiceId": 5026,
            "amount": 2250.00
        }
    ]
}

Response

Returns the newly created payment record (HTTP 201 Created).

PUT /payments/{id}

Updates an existing payment record.

Request Body

{
    "referenceNumber": "ACH45678-R",
    "postDate": "2023-07-02",
    "notes": "Monthly service payment - corrected reference number",
    "receiptSent": true,
    "receiptRecipients": ["ap@customer.com", "facilities@customer.com", "accounting@customer.com"],
    "customFields": {
        "accountingCode": "AR-12345",
        "department": "Service",
        "approvedBy": "Jane Smith"
    }
}

Response

Returns the updated payment record.

DELETE /payments/{id}

Deletes a payment record. This is typically only allowed for payments with "Pending" status.

Response

HTTP 204 No Content on successful deletion.

POST /payments/{id}/void

Voids a payment, reversing any invoice applications.

Request Body

{
    "voidReason": "Payment reversal requested by customer",
    "voidDate": "2023-07-05",
    "notes": "Customer reported incorrect payment amount, will resubmit"
}

Response

Returns the voided payment record with updated status.

GET /customers/{customerId}/payments

Retrieves all payments for a specific customer.

Request

GET /v1.0/customers/1001/payments
Authorization: Bearer {access_token}

Response

Returns a collection of payments made by the specified customer.

GET /invoices/{invoiceId}/payments

Retrieves all payments applied to a specific invoice.

Request

GET /v1.0/invoices/5001/payments
Authorization: Bearer {access_token}

Response

Returns a collection of payments applied to the specified invoice.

POST /payments/{id}/apply

Applies a payment to one or more invoices.

Request Body

{
    "allocations": [
        {
            "invoiceId": 5030,
            "amount": 1200.00
        },
        {
            "invoiceId": 5031,
            "amount": 800.00
        }
    ]
}

Response

Returns the updated payment record with the new allocations.

POST /payments/{id}/unapply

Removes the application of a payment from one or more invoices.

Request Body

{
    "invoiceIds": [5030, 5031]
}

Response

Returns the updated payment record with the allocations removed.

POST /payments/{id}/send-receipt

Sends a receipt for a payment to one or more recipients.

Request Body

{
    "recipients": ["customer@example.com", "accounting@example.com"],
    "subject": "Payment Receipt - $3,250.00",
    "message": "Thank you for your payment. Please find your receipt attached.",
    "includePaymentDetails": true,
    "includeInvoiceDetails": true
}

Response

Returns information about the sent receipt.
