Payment

The Payment object represents financial transactions received from Customers towards Invoices. Payments can be applied to one or more invoices, and track important information such as payment method, transaction details, and allocation to specific invoices. This resource enables proper accounting, accounts receivable management, and customer payment history tracking.

Payment

The payment resource is used to manage Payment data within ServiceTrade.

  • Resource URL: /payment
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /payment 200
GET /payment/123 200
GET /payment/123 404 payment not found
POST /payment 200 payment created
POST /payment 400 invalid data
PUT /payment/123 200 payment updated
PUT /payment/123 400 invalid data
PUT /payment/123 404 payment not found
DELETE /payment/123 204 payment deleted
DELETE /payment/123 404 payment not found

Returned Elements for /payment/[paymentId]

Name Type Value
id integer payment entity ID
uri string resource identifier for the payment
name string name of the payment
