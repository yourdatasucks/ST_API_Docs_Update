Webhook

The Webhook object represents an integration point that allows external systems to receive real-time notifications about events occurring within ServiceTrade. Webhooks enable automated workflows by sending HTTP requests to specified endpoints when triggered by system events like job creation, status changes, or invoice processing. This allows for seamless integration with third-party systems without requiring constant polling of the ServiceTrade API.

Webhook

The webhook resource is used to create and manage webhook integrations that notify external systems about events in ServiceTrade.

  • Resource URL: /webhook
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /webhook 200
GET /webhook/101 200
GET /webhook/101 404 webhook not found
POST /webhook 200 webhook created
POST /webhook 400 invalid data
PUT /webhook/101 200 webhook updated
PUT /webhook/101 400 invalid data
PUT /webhook/101 404 webhook not found
DELETE /webhook/101 204 webhook deleted
DELETE /webhook/101 404 webhook not found
