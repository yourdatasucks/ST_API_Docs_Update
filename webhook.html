Webhook

The Webhook object represents an integration point that allows external systems to receive real-time notifications about events occurring within ServiceTrade. Webhooks enable automated workflows by sending HTTP requests to specified endpoints when triggered by system events like job creation, status changes, or invoice processing. This allows for seamless integration with third-party systems without requiring constant polling of the ServiceTrade API.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the webhook. true false
name string Name of the webhook. false true
url string Target URL where webhook notifications will be sent. false true
description string Description of the webhook's purpose. false false
isActive boolean Whether the webhook is currently active. false false
events array Array of event types this webhook subscribes to. false true
secret string Secret key used to sign webhook payloads for verification. false false
format string Format of the webhook payload (e.g., "JSON", "XML"). false false
contentType string Content type of the webhook payload (e.g., "application/json"). false false
headers object Custom HTTP headers to include with webhook requests. false false
filters object Filters to apply to events before sending notifications. false false
customPayload boolean Whether to use a custom payload format instead of the default. false false
payloadTemplate string Template for customizing the webhook payload format. false false
retryEnabled boolean Whether to retry failed webhook deliveries. false false
retryCount integer Maximum number of retry attempts for failed deliveries. false false
retryInterval integer Interval in seconds between retry attempts. false false
successResponseCodes array HTTP response codes considered successful (default: [200]). false false
lastDeliveryStatus string Status of the most recent webhook delivery attempt. true false
lastDeliveryTime datetime Timestamp of the most recent webhook delivery attempt. true false
lastResponseCode integer HTTP response code from the most recent delivery attempt. true false
lastResponseBody string Response body from the most recent delivery attempt. true false
successCount integer Count of successful webhook deliveries. true false
failureCount integer Count of failed webhook deliveries. true false
createdBy integer ID of the user who created this webhook. true false
createdDate datetime Date and time when this webhook was created. true false
lastModifiedBy integer ID of the user who last modified this webhook. true false
lastModifiedDate datetime Date and time when this webhook was last modified. true false

POST /webhooks

Creates a new webhook.

Request Body

{
    "name": "Schedule Change Notification",
    "url": "https://dispatch.example.com/api/schedule-updates",
    "description": "Notifies dispatch system of schedule changes and appointments",
    "isActive": true,
    "events": ["appointment.created", "appointment.updated", "appointment.canceled"],
    "format": "JSON",
    "contentType": "application/json",
    "headers": {
        "X-API-Key": "dispatcher-api-key-12345",
        "X-Source": "ServiceTrade"
    },
    "filters": {
        "appointment.type": ["Installation", "Service Call"]
    },
    "retryEnabled": true,
    "retryCount": 3,
    "retryInterval": 300
}

Response

Returns the newly created webhook (HTTP 201 Created).

    "retryCount": 5,
    "retryInterval": 180
}

Response

Returns the updated webhook.

DELETE /webhooks/{id}

Deletes a webhook.

Response

HTTP 204 No Content on successful deletion.

POST /webhooks/{id}/deactivate

Deactivates a webhook without deleting it.

Response

Returns the deactivated webhook with updated status.

POST /webhooks/{id}/activate

Activates a previously deactivated webhook.

Response

Returns the activated webhook with updated status.

Webhook Security

Webhook requests include a signature header (X-Webhook-Signature) that allows you to verify the authenticity of the webhook. The signature is generated using HMAC-SHA256 with your webhook secret:

// Example signature verification in Node.js
const crypto = require('crypto');

function verifyWebhookSignature(payload, signature, secret) {
    const expectedSignature = crypto
        .createHmac('sha256', secret)
        .update(JSON.stringify(payload))
        .digest('hex');
    
    return crypto.timingSafeEqual(
        Buffer.from(signature.replace('sha256=', '')),
        Buffer.from(expectedSignature)
    );
}

// In your webhook handler:
const isValid = verifyWebhookSignature(
    req.body,
    req.headers['x-webhook-signature'],
    webhookSecret
);

if (!isValid) {
    return res.status(401).send('Invalid signature');
}
