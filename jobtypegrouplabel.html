Job Type Group Label

The Job Type Group Label object represents a categorization mechanism for organizing jobs by type in ServiceTrade. It allows for grouping and classifying jobs into categories like "Preventative Maintenance", "Inspection", "Emergency Service", etc., providing a way to filter and report on jobs by these categorizations.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the job type group label. true false
name string Name of the job type group label. false true
description string Description of the job type group label. false false
isDefault boolean Whether this is a default job type group label. true false
isSystem boolean Whether this is a system-defined job type group label. true false
createdBy integer ID of the user who created the job type group label. true false
createdDate datetime Date and time when the job type group label was created. true false
lastModifiedBy integer ID of the user who last modified the job type group label. true false
lastModifiedDate datetime Date and time when the job type group label was last modified. true false
color string Color code (hex) associated with this job type group label. false false
icon string Icon identifier associated with this job type group label. false false
isActive boolean Whether this job type group label is active. false false
jobTypeIds array Array of job type IDs associated with this group label. false false
jobCount integer Number of jobs associated with this job type group label. true false
sequence integer Display order for the job type group label. false false

POST /job-type-group-labels

Creates a new job type group label.

Request Body

{
    "name": "Custom Installation",
    "description": "Custom equipment installations",
    "color": "#9C27B0",
    "icon": "tools",
    "isActive": true,
    "jobTypeIds": [2010, 2011, 2012],
    "sequence": 4
}

Response

Returns the newly created job type group label (HTTP 201 Created).

PUT /job-type-group-labels/{id}

Updates an existing job type group label.

Request Body

{
    "name": "Custom Installation & Setup",
    "description": "Custom equipment installations and initial setup",
    "color": "#9C27B0",
    "icon": "tools",
    "isActive": true,
    "jobTypeIds": [2010, 2011, 2012, 2013],
    "sequence": 4
}

Response

Returns the updated job type group label.

DELETE /job-type-group-labels/{id}

Deletes a job type group label. System-defined labels cannot be deleted.

Response

HTTP 204 No Content on successful deletion.

POST /job-type-group-labels/{id}/job-types

Associates job types with a job type group label.

Request Body

{
    "jobTypeIds": [2005, 2006, 2007]
}

Response

Returns success message and updates the job type group label.

DELETE /job-type-group-labels/{id}/job-types/{jobTypeId}

Removes a job type association from a job type group label.

Response

HTTP 204 No Content on successful removal of the association.

PUT /job-type-group-labels/reorder

Reorders job type group labels.

Request Body

{
    "order": [1003, 1001, 1002, 1004]
}

Response

Returns success message and updates the sequence property of the affected labels.

POST /job-type-group-labels/default/{id}

Sets a job type group label as the default.

Response

Returns the updated job type group label with isDefault set to true.
