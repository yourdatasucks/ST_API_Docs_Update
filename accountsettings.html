Account Settings

The Account Settings resource allows for managing various settings related to an account. These settings often dictate feature availability and behavior across the platform.

Properties

Account Settings are typically presented as a collection of key-value pairs. The specific keys and their possible values will vary depending on the feature they control. Examples might include:

  • feature_assets_enabled: boolean (true/false) - Controls if the Assets feature is active.
  • default_currency: string (e.g., "USD", "EUR") - Sets the default currency for financial transactions.
  • notification_preferences: object - Contains sub-settings for various notification types.

Consult the specific API documentation for a comprehensive list of available account settings.

Endpoints

GET /account/settings

Retrieves all current account settings for the authenticated account.

Request

GET /v1.0/account/settings
Authorization: Bearer {access_token}

Response

{
    "feature_assets_enabled": true,
    "default_currency": "USD",
    "session_timeout_minutes": 60,
    "email_notifications": {
        "new_lead_assigned": true,
        "task_completed": false
    }
    // ... other settings
}

PUT /account/settings

Updates one or more account settings. Only include the settings you wish to change in the request body.

Request Body

{
    "feature_assets_enabled": false,
    "session_timeout_minutes": 120
}

Response

Returns the updated account settings object (HTTP 200 OK).

{
    "feature_assets_enabled": false,
    "default_currency": "USD",
    "session_timeout_minutes": 120,
    "email_notifications": {
        "new_lead_assigned": true,
        "task_completed": false
    }
    // ... other settings reflecting the update
}

Note: Access to modify account settings typically requires administrative privileges.
