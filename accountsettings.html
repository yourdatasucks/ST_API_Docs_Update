Account Settings

The Account Settings resource allows for managing various settings related to an account. These settings often dictate feature availability and behavior across the platform.

Properties

Account Settings are typically presented as a collection of key-value pairs. The specific keys and their possible values will vary depending on the feature they control. Examples might include:

  • feature_assets_enabled: boolean (true/false) - Controls if the Assets feature is active.
  • default_currency: string (e.g., "USD", "EUR") - Sets the default currency for financial transactions.
  • notification_preferences: object - Contains sub-settings for various notification types.

Consult the specific API documentation for a comprehensive list of available account settings.

Account Settings

The accountsettings resource is used to manage Account Settings data within ServiceTrade.

  • Resource URL: /accountsettings
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /accountsettings 200
GET /accountsettings/123 200
GET /accountsettings/123 404 accountsettings not found
POST /accountsettings 200 accountsettings created
POST /accountsettings 400 invalid data
PUT /accountsettings/123 200 accountsettings updated
PUT /accountsettings/123 400 invalid data
PUT /accountsettings/123 404 accountsettings not found
DELETE /accountsettings/123 204 accountsettings deleted
DELETE /accountsettings/123 404 accountsettings not found

Returned Elements for /accountsettings/[accountsettingsId]

Name Type Value
id integer accountsettings entity ID
uri string resource identifier for the accountsettings
name string name of the accountsettings
