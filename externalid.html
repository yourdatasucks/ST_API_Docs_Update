ExternalId

The ExternalId object manages mappings between ServiceTrade entity IDs and identifiers from external systems. This facilitates integration with third-party applications by maintaining these ID relationships and providing lookup capabilities.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the external ID mapping. true false
externalSystemId integer ID of the External System this mapping belongs to. false true
entityType string Type of entity being mapped (e.g., "Customer", "Location", "Job"). false true
entityId integer ID of the ServiceTrade entity. false true
externalId string ID of the entity in the external system. false true
externalType string Optional type or category within the external system. false false
isPrimary boolean Whether this is the primary external ID for the entity (when multiple mappings exist). false false
metadata object Additional metadata about this mapping. false false
lastSyncDate datetime Date when this mapping was last synchronized. false false
status string Status of the mapping (e.g., "Active", "Archived"). false false
createdDate datetime Date the mapping was created. true false
createdBy integer ID of the user who created the mapping. true false
lastModifiedDate datetime Date the mapping was last modified. true false
lastModifiedBy integer ID of the user who last modified the mapping. true false

Endpoints

GET /externalids

Retrieves a list of external ID mappings. Supports filtering by externalSystemId, entityType, entityId, externalId, etc.

Request

GET /v1.0/externalids?externalSystemId=123&entityType=Customer
Authorization: Bearer {access_token}

Response

{
    "items": [
        {
            "id": 456,
            "externalSystemId": 123,
            "entityType": "Customer",
            "entityId": 789,
            "externalId": "CUST-456",
            "externalType": "Account",
            "isPrimary": true,
            "metadata": {
                "syncSource": "QuickBooks",
                "accountType": "Commercial",
                "migrationDate": "2023-01-15"
            },
            "lastSyncDate": "2023-08-10T15:30:00Z",
            "status": "Active",
            "createdDate": "2023-01-15T10:45:00Z",
            "createdBy": 101,
            "lastModifiedDate": "2023-08-10T15:30:00Z",
            "lastModifiedBy": 102
        },
        // Additional external IDs...
    ],
    "totalResults": 1,
    "itemsPerPage": 50,
    "startIndex": 1
}

GET /externalids/{id}

Retrieves a specific external ID mapping by ID.

Request

GET /v1.0/externalids/456
Authorization: Bearer {access_token}

Response

Returns the external ID mapping with the specified ID.

GET /externalids/lookup/byEntityId

Looks up external IDs by ServiceTrade entity ID.

Request

GET /v1.0/externalids/lookup/byEntityId?externalSystemId=123&entityType=Customer&entityId=789
Authorization: Bearer {access_token}

Response

Returns external ID mappings that match the specified criteria.

GET /externalids/lookup/byExternalId

Looks up ServiceTrade entity IDs by external ID.

Request

GET /v1.0/externalids/lookup/byExternalId?externalSystemId=123&entityType=Customer&externalId=CUST-456
Authorization: Bearer {access_token}

Response

Returns external ID mappings that match the specified criteria.

POST /externalids

Creates a new external ID mapping.

Request Body

{
    "externalSystemId": 123,
    "entityType": "Invoice",
    "entityId": 1001,
    "externalId": "INV-2023-0042",
    "externalType": "Invoice",
    "isPrimary": true,
    "metadata": {
        "syncSource": "QuickBooks",
        "invoiceSync": "outbound",
        "quickBooksClass": "ServiceDept"
    }
}

Response

Returns the newly created external ID mapping (HTTP 201 Created).

PUT /externalids/{id}

Updates an existing external ID mapping.

Request Body

{
    "externalId": "INV-2023-0042-REV",
    "lastSyncDate": "2023-08-20T14:15:00Z",
    "metadata": {
        "syncSource": "QuickBooks",
        "invoiceSync": "outbound",
        "quickBooksClass": "ServiceDept",
        "revisionReason": "Customer number change"
    }
}

Response

Returns the updated external ID mapping.

DELETE /externalids/{id}

Deletes an external ID mapping.

Response

HTTP 204 No Content on successful deletion.

POST /externalids/batch

Creates multiple external ID mappings in a single request.

Request Body

{
    "externalSystemId": 123,
    "mappings": [
        {
            "entityType": "Customer",
            "entityId": 1002,
            "externalId": "CUST-789",
            "externalType": "Account",
            "isPrimary": true
        },
        {
            "entityType": "Location",
            "entityId": 2001,
            "externalId": "LOC-1234",
            "externalType": "JobSite",
            "isPrimary": true
        },
        {
            "entityType": "Contact",
            "entityId": 3001,
            "externalId": "CONTACT-5678",
            "externalType": "Person",
            "isPrimary": true
        }
    ]
}

Response

Returns an array of the newly created external ID mappings.

PUT /externalids/bulk/update

Updates multiple external ID mappings in a single request.

Request Body

{
    "ids": [456, 457, 458],
    "updates": {
        "lastSyncDate": "2023-08-20T14:15:00Z",
        "status": "Active"
    }
}

Response

Returns a summary of the update operation.

DELETE /externalids/bulk/delete

Deletes multiple external ID mappings in a single request.

Request Body

{
    "ids": [456, 457, 458]
}

Response

HTTP 204 No Content on successful deletion.

POST /externalids/import

Imports a batch of external ID mappings from a file.

Request

Multipart form data with file and import parameters.

Response

Returns a summary of the import operation.

GET /externalids/export

Exports external ID mappings to a file.

Request

GET /v1.0/externalids/export?externalSystemId=123&format=csv
Authorization: Bearer {access_token}

Response

Returns a file download or a URL to download the exported file.

GET /externalsystems/{id}/externalids

Retrieves all external ID mappings for a specific external system.

Request

GET /v1.0/externalsystems/123/externalids?entityType=Customer
Authorization: Bearer {access_token}

Response

Returns a collection of external ID mappings for the specified external system.

POST /externalids/lookup/bulk

Performs a bulk lookup of entity IDs or external IDs.

Request Body

{
    "externalSystemId": 123,
    "entityType": "Customer",
    "lookupDirection": "toExternalId",
    "ids": [789, 790, 791, 792]
}

Response

{
    "results": {
        "789": "CUST-456",
        "790": "CUST-457",
        "791": "CUST-458",
        "792": null
    },
    "missingMappings": [792]
}
