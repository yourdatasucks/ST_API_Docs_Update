Quote Item

The Quote Item object represents individual items that are part of a quote. Quote items can include labor, materials, services, and other billable elements that contribute to the total quote amount.

Properties

Property Type Description Read-Only Required
id integer The unique identifier for the Quote Item. true false
quoteId integer The ID of the quote this item belongs to. false true
description string Description of the item. false true
quantity number Quantity of units. false true
unitPrice number Price per unit. false true
subtotal number Calculated subtotal (quantity × unitPrice). true false
taxable boolean Indicates if the item is taxable. false false
sortOrder integer Order in which the item appears in the quote. false false
category string Category classification of the item. false false
createdBy integer ID of the user who created this item. true false
createdDate datetime Date and time when this item was created. true false
lastModifiedBy integer ID of the user who last modified this item. true false
lastModifiedDate datetime Date and time when this item was last modified. true false

Quote Item

The quote item resource is used to manage individual items within quotes.

  • Resource URL: /quoteitem
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /quoteitem 200
GET /quoteitem/123 200
GET /quoteitem/123 404 quote item not found
POST /quoteitem 201 quote item created
POST /quoteitem 400 invalid data
PUT /quoteitem/123 200 quote item updated
PUT /quoteitem/123 400 invalid data
PUT /quoteitem/123 404 quote item not found
DELETE /quoteitem/123 204 quote item deleted
DELETE /quoteitem/123 404 quote item not found

Returned Elements for /quoteitem/[quoteItemId]

Name Type Value
id integer quote item entity ID
uri string resource identifier for the quote item
quote object parent quote reference
description string description of the item
quantity number quantity of units
unitPrice number price per unit
subtotal number calculated subtotal (quantity × unitPrice)
taxable boolean indicates if the item is taxable
sortOrder integer item position in the quote
category string category classification
createdBy object user who created the item
createdDate datetime creation timestamp
lastModifiedBy object user who last modified the item
lastModifiedDate datetime last modification timestamp
