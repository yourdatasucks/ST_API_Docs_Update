Schedule

The Schedule object represents time allocations for technicians and other resources within ServiceTrade. It includes appointments, job allocations, time blocks for service calls, travel time, and other scheduled activities. The schedule system allows for effective resource management, ensuring that technicians and equipment are assigned efficiently while avoiding conflicts. The Schedule API enables integration with external calendar systems, dispatch tools, and workforce management platforms.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the schedule entry. true false

duration integer Duration in minutes of the scheduled activity. true false
allDay boolean Whether the scheduled item spans an entire day. false false
resourceId integer ID of the resource being scheduled (typically a technician/user ID). false true
resourceType string Type of resource being scheduled (e.g., "User", "Equipment", "Vehicle"). false true
jobId integer ID of the associated job, if applicable. false false
locationId integer ID of the location where the activity will take place. false false
customerId integer ID of the customer associated with the scheduled activity. false false
status string Status of the schedule (e.g., "Confirmed", "Tentative", "Canceled", "Completed"). false false
priority string Priority level (e.g., "High", "Medium", "Low"). false false
recurrence object Recurrence pattern information for recurring schedules. false false
isRecurring boolean Whether this is a recurring schedule entry. false false
parentScheduleId integer For recurring instances, the ID of the parent schedule template. false false

isPrivate boolean Whether the schedule entry is private to the resource. false false
notes string Additional notes or instructions for the scheduled activity. false false

estimatedServiceTime integer Estimated time in minutes to complete the service work. false false
notifications array Array of notification settings for this schedule. false false

createdDate datetime Date and time when this schedule entry was created. true false
lastModifiedBy integer ID of the user who last modified this schedule entry. true false
lastModifiedDate datetime Date and time when this schedule entry was last modified. true false
customFields object Custom fields and their values. false false
