Schedule

The Schedule object represents time allocations for technicians and other resources within ServiceTrade. It includes appointments, job allocations, time blocks for service calls, travel time, and other scheduled activities. The schedule system allows for effective resource management, ensuring that technicians and equipment are assigned efficiently while avoiding conflicts. The Schedule API enables integration with external calendar systems, dispatch tools, and workforce management platforms.

Schedule

The schedule resource is used to manage Schedule data within ServiceTrade.

  • Resource URL: /schedule
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /schedule 200
GET /schedule/123 200
GET /schedule/123 404 schedule not found
POST /schedule 200 schedule created
POST /schedule 400 invalid data
PUT /schedule/123 200 schedule updated
PUT /schedule/123 400 invalid data
PUT /schedule/123 404 schedule not found
DELETE /schedule/123 204 schedule deleted
DELETE /schedule/123 404 schedule not found

Returned Elements for /schedule/[scheduleId]

Name Type Value
id integer schedule entity ID
