Customer

The Customer object represents an organization or individual that purchases services or products. Customers are typically associated with Companies and can have multiple locations, contacts, and service history.

Customer

The customer resource is used to manage Customer data within ServiceTrade.

  • Resource URL: /customer
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /customer 200
GET /customer/123 200
GET /customer/123 404 customer not found
POST /customer 200 customer created
POST /customer 400 invalid data
PUT /customer/123 200 customer updated
PUT /customer/123 400 invalid data
PUT /customer/123 404 customer not found
DELETE /customer/123 204 customer deleted
DELETE /customer/123 404 customer not found

Returned Elements for /customer/[customerId]

Name Type Value
id integer customer entity ID
uri string resource identifier for the customer
name string name of the customer
