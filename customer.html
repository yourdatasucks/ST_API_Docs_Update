Customer

The Customer object represents an organization or individual that purchases services or products. Customers are typically associated with Companies and can have multiple locations, contacts, and service history.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the customer. true false
companyId integer ID of the associated Company. false true
customerNumber string Customer reference number or identifier in your system. false false
type string Type of customer (e.g., "Commercial", "Residential", "Industrial", "Government"). false false
status string Status of the customer (e.g., "Active", "Inactive", "Prospect", "Former"). false false
accountManagerId integer ID of the user who manages this customer account. false false
salesRepId integer ID of the sales representative associated with this customer. false false
primaryLocationId integer ID of the primary Location for this customer. false false
primaryContactId integer ID of the primary Contact for this customer. false false
billingContactId integer ID of the billing Contact for this customer. false false
billingLocationId integer ID of the billing Location for this customer. false false
notes string Additional notes about the customer. false false
source string Customer acquisition source (e.g., "Referral", "Website", "Trade Show"). false false
industry string Industry the customer operates in. false false
segment string Market segment the customer belongs to. false false
size string Size category of the customer (e.g., "Small", "Medium", "Enterprise"). false false
annualRevenue decimal Annual revenue of the customer organization. false false
employeeCount integer Number of employees in the customer organization. false false
website string Customer's website URL. false false
taxExempt boolean Whether the customer is exempt from taxes. false false
taxExemptionNumber string Tax exemption certificate number if tax exempt. false false
creditLimit decimal Customer's approved credit limit. false false
paymentTerms string Payment terms for the customer (e.g., "Net 30", "Net 60"). false false
preferredPaymentMethod string Customer's preferred payment method. false false
customFields object Custom field values for the customer. false false
tags array Array of tags associated with the customer. false false
customerSince date Date when the customer relationship began. false false
lastServiceDate date Date of the most recent service provided to the customer. true false
lifetime object Lifetime statistics for the customer relationship. true false
createdDate datetime Date the customer record was created. true false
createdBy integer ID of the user who created the customer record. true false
lastModifiedDate datetime Date the customer record was last modified. true false
lastModifiedBy integer ID of the user who last modified the customer record. true false

Lifetime Object Properties

Property Type Description
revenue decimal Total revenue generated by the customer.
jobCount integer Total number of jobs completed for the customer.
quoteCount integer Total number of quotes provided to the customer.
quoteAcceptanceRate decimal Percentage of quotes accepted by the customer.
averageResponseTime decimal Average response time to customer service requests in hours.
contractValue decimal Total value of all contracts with the customer.

POST /customers

Creates a new customer.

Request Body

{
    "companyId": 457,
    "customerNumber": "CUST-002",
    "type": "Industrial",
    "status": "Active",
    "accountManagerId": 201,
    "salesRepId": 203,
    "primaryLocationId": 302,
    "primaryContactId": 403,
    "billingContactId": 404,
    "billingLocationId": 302,
    "notes": "New manufacturing facility, high service volume expected.",
    "source": "Trade Show",
    "industry": "Manufacturing",
    "segment": "Enterprise",
    "size": "Large",
    "website": "https://acmemanufacturing.example.com",
    "taxExempt": true,
    "taxExemptionNumber": "TX-67890-MFG",
    "paymentTerms": "Net 45",
    "customerSince": "2023-08-01",
    "tags": ["Manufacturing", "Enterprise", "New Customer"]
}

Response

Returns the newly created customer object (HTTP 201 Created).

PUT /customers/{id}

Updates an existing customer.

Request Body

{
    "status": "Active",
    "accountManagerId": 204,
    "primaryContactId": 405,
    "notes": "Customer has expanded operations. Account transferred to enterprise account manager.",
    "creditLimit": 75000.00,
    "paymentTerms": "Net 60"
}

Response

Returns the updated customer object.

DELETE /customers/{id}

Deletes a customer. This is typically a soft delete that changes the status rather than removing the record.

Response

HTTP 204 No Content on successful deletion/deactivation.

POST /customers/{id}/merge

Merges another customer record into this customer, consolidating history and relationships.

Request Body

{
    "sourceCustomerId": 124,
    "mergeOptions": {
        "mergeContacts": true,
        "mergeLocations": true,
        "mergeAssets": true,
        "mergeContracts": true,
        "retainSourceHistory": true
    },
    "notes": "Duplicate customer record created during system migration."
}

Response

Returns the updated customer object with merged data.
