Deficiency

The Deficiency object represents a problem, issue, or non-compliance identified during an inspection or assessment of assets, equipment, or facilities. Deficiencies can be tracked, prioritized, and resolved through repair jobs or maintenance activities.

Deficiency

The deficiency resource is used to manage Deficiency data within ServiceTrade.

  • Resource URL: /deficiency
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /deficiency 200
GET /deficiency/123 200
GET /deficiency/123 404 deficiency not found
POST /deficiency 200 deficiency created
POST /deficiency 400 invalid data
PUT /deficiency/123 200 deficiency updated
PUT /deficiency/123 400 invalid data
PUT /deficiency/123 404 deficiency not found
DELETE /deficiency/123 204 deficiency deleted
DELETE /deficiency/123 404 deficiency not found

Returned Elements for /deficiency/[deficiencyId]

Name Type Value
id integer deficiency entity ID
uri string resource identifier for the deficiency
name string name of the deficiency
