Deficiency

The Deficiency object represents a problem, issue, or non-compliance identified during an inspection or assessment of assets, equipment, or facilities. Deficiencies can be tracked, prioritized, and resolved through repair jobs or maintenance activities.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the deficiency. true false
reportId integer ID of the parent Deficiency Report. false true
assetId integer ID of the Asset with the deficiency. false false
locationId integer ID of the Location where the deficiency was found. false false
title string Short title or name for the deficiency. false true
description string Detailed description of the deficiency. false true
severity string Severity level of the deficiency (e.g., "Critical", "Major", "Minor", "Cosmetic"). false false
priority string Priority for resolution (e.g., "High", "Medium", "Low"). false false
status string Current status of the deficiency (e.g., "Open", "In Progress", "Resolved", "Waived"). false true
category string Category or type of deficiency (e.g., "Mechanical", "Electrical", "Structural", "Safety"). false false
subCategory string Sub-category for more specific classification. false false
code string Reference code or identifier for compliance or standard reference. false false
identifiedDate date Date when the deficiency was identified. false true
identifiedBy integer ID of the user who identified the deficiency. false false
dueDate date Target date for resolving the deficiency. false false
estimatedCost decimal Estimated cost to fix the deficiency. false false
estimatedHours decimal Estimated labor hours to fix the deficiency. false false
resolutionNotes string Notes about how the deficiency was resolved or should be resolved. false false
resolvedDate date Date when the deficiency was resolved. false false
resolvedBy integer ID of the user who resolved the deficiency. false false
waiveReason string Reason for waiving the deficiency if not resolved. false false
waivedBy integer ID of the user who approved waiving the deficiency. false false
waivedDate date Date when the deficiency was waived. false false
jobId integer ID of the Job created to address this deficiency. false false
quoteId integer ID of the Quote associated with this deficiency. false false
imageUrls array Array of image URLs documenting the deficiency. false false
attachmentIds array Array of Attachment IDs related to this deficiency. false false
customFields object Custom field values for the deficiency. false false
tags array Array of tags associated with the deficiency. false false
createdDate datetime Date the deficiency record was created. true false
createdBy integer ID of the user who created the deficiency record. true false
lastModifiedDate datetime Date the deficiency record was last modified. true false
lastModifiedBy integer ID of the user who last modified the deficiency record. true false

POST /deficiencies

Creates a new deficiency.

Request Body

{
    "reportId": 123,
    "assetId": 790,
    "locationId": 201,
    "title": "Corroded Electrical Panel",
    "description": "Main electrical panel shows significant corrosion on the exterior housing and some rust on internal components. Potential safety hazard.",
    "severity": "Critical",
    "priority": "High",
    "status": "Open",
    "category": "Electrical",
    "subCategory": "Panel",
    "code": "E-PNL-003",
    "identifiedDate": "2023-07-15",
    "identifiedBy": 302,
    "dueDate": "2023-07-25",
    "estimatedCost": 3500.00,
    "estimatedHours": 8.0,
    "imageUrls": [
        "https://example.com/images/deficiency/temp-e1.jpg",
        "https://example.com/images/deficiency/temp-e2.jpg"
    ],
    "tags": ["Electrical", "Safety", "Corrosion"]
}

Response

Returns the newly created deficiency object (HTTP 201 Created).

PUT /deficiencies/{id}

Updates an existing deficiency.

Request Body

{
    "status": "In Progress",
    "priority": "Critical",
    "dueDate": "2023-07-20",
    "estimatedCost": 4200.00,
    "jobId": 567,
    "resolutionNotes": "Technician dispatched for emergency replacement of electrical panel."
}

Response

Returns the updated deficiency object.

DELETE /deficiencies/{id}

Deletes a deficiency.

Response

HTTP 204 No Content on successful deletion.

GET /deficiencyreports/{id}/deficiencies

Retrieves all deficiencies for a specific deficiency report. See Deficiency Report for details.

POST /deficiencies/{id}/resolve

Marks a deficiency as resolved.

Request Body

{
    "resolvedDate": "2023-07-28",
    "resolvedBy": 401,
    "resolutionNotes": "Replaced damaged condenser coil with new unit. Tested operation and confirmed proper functioning.",
    "actualCost": 1375.50,
    "actualHours": 5.5,
    "attachmentIds": [503]
}

Response

Returns the updated deficiency object with resolved status.

POST /deficiencies/{id}/waive

Waives a deficiency (marks it as not requiring resolution).

Request Body

{
    "waiveReason": "Equipment scheduled for full replacement within 30 days. Temporary repair not cost-effective.",
    "waivedBy": 305,
    "waivedDate": "2023-07-20",
    "attachmentIds": [504]
}

Response

Returns the updated deficiency object with waived status.

POST /deficiencies/{id}/createjob

Creates a job to address the deficiency.

Request Body

{
    "jobTitle": "Repair Damaged HVAC Condenser Coil",
    "jobDescription": "Replace damaged condenser coil on RTU-03. Repair bent fins where possible.",
    "scheduledDate": "2023-07-25",
    "priority": "High",
    "assignedTechnicianIds": [501, 502],
    "estimatedDuration": 4.5,
    "notes": "Bring replacement coil and fin comb toolkit."
}

Response

Returns an object containing both the deficiency (with updated jobId) and the newly created job.

POST /deficiencies/{id}/createquote

Creates a quote for addressing the deficiency.

Request Body

{
    "quoteTitle": "Quote for HVAC Condenser Coil Replacement",
    "quoteDescription": "Replacement of damaged condenser coil on RTU-03 including parts and labor.",
    "expirationDate": "2023-08-15",
    "items": [
        {
            "description": "Replacement condenser coil - 3 ton capacity",
            "quantity": 1,
            "unitPrice": 850.00,
            "taxable": true
        },
        {
            "description": "Labor - HVAC Technician",
            "quantity": 4.5,
            "unitPrice": 95.00,
            "taxable": false
        }
    ],
    "notes": "Quote includes removal and proper disposal of old coil."
}

Response

Returns an object containing both the deficiency (with updated quoteId) and the newly created quote.

GET /deficiencies/{id}/attachments

Retrieves attachments associated with a specific deficiency.

Request

GET /v1.0/deficiencies/456/attachments
Authorization: Bearer {access_token}

Response

Returns a collection of Attachments associated with this deficiency.

POST /deficiencies/{id}/attachments

Adds an attachment to a deficiency.

Request

Multipart form data with file and metadata.

Response

Returns the created Attachment object and updates the deficiency's attachmentIds.
