Asset Definition

The Asset Definition object is part of the Assets feature, which must be enabled by an Administrator in Account Settings > Assets.

The Asset Definition object represents the type of an Asset. For example, if an Asset is an "Apple MacBook Pro 16 Inch", its Asset Definition would be "Laptop". When creating or editing an Asset Definition, you can define Custom Fields specific to that Asset Definition. These Asset Definition Custom Fields can then be populated on any Assets that use this Asset Definition.

In order to create Asset Definitions, you must have the Administer Asset Definitions permission. To view and use Asset Definitions (e.g. when creating an Asset), you must have the View Asset Definitions permission.

Properties

Property Type Description Read-Only Required
Id integer The unique identifier for the Asset Definition. true false
Name string The name of the Asset Definition. false true
IsActive boolean Indicates if the Asset Definition is active. Inactive Asset Definitions cannot be used when creating new Assets. false false
CreateDate datetime The date the Asset Definition was created. true false
CreatedBy integer The User ID of the user who created the Asset Definition. true false
LastModifiedDate datetime The date the Asset Definition was last modified. true false
LastModifiedBy integer The User ID of the user who last modified the Asset Definition. true false
CustomFields array An array of Custom Fields that are defined for this Asset Definition. These are not the values of the custom fields for a specific asset, but the definitions of the fields themselves. false false

POST /assetdefinitions

Creates a new Asset Definition.

Request Body

{
            "Name": "Projector",
            "IsActive": true,
            "CustomFields": [ // Optional: Define custom fields during creation
                {
                    "FieldName": "Lumens",
                    "FieldType": "Number",
                    "IsRequired": false
                }
            ]
        }

Response

Returns the newly created Asset Definition object (HTTP 201 Created).

            "Id": 3,

PUT /assetdefinitions/{id}

Updates an existing Asset Definition.

Request Body

{
            "Name": "High-Performance Laptop", // Change name
            "IsActive": false, // Deactivate
            "CustomFields": [ // Update custom fields (can add, modify, or remove)
                // To modify an existing custom field, include its Id
                {
                    "Id": 55, // Assuming this was "Screen Size"
                    "FieldName": "Display Size (inches)",
                    "FieldType": "Number"
                },
                // To add a new custom field, omit the Id
                {
                    "FieldName": "Processor",
                    "FieldType": "Text"
                }
                // To remove a custom field, you might need a separate mechanism or
                // pass a specific instruction if the API supports it, or simply omit it
                // if the PUT replaces the entire CustomFields array.
                // (API behavior for list updates varies)
            ]
        }

Response

Returns the updated Asset Definition object.

DELETE /assetdefinitions/{id}

Deletes an Asset Definition. This is typically a soft delete if Assets are using this definition, or it might be disallowed if in use. Check API specific documentation on deletion constraints.

Request

DELETE /v1.0/assetdefinitions/{id}
        Authorization: Bearer {access_token}

Response

HTTP 204 No Content on successful deletion.
