Clock In/Out

The Clock object represents time tracking records for users clocking in and out of work, jobs, or tasks. This API is used to track labor time for payroll, job costing, and performance metrics.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the clock entry. true false
userId integer ID of the user who clocked in/out. false true
type string Type of entry ("In" or "Out"). false true
timestamp datetime Date and time when the clock action was performed. false true
jobId integer ID of the job associated with the time entry, if applicable. false false
taskId integer ID of the task associated with the time entry, if applicable. false false
serviceItemId integer ID of the service item associated with the time entry, if applicable. false false
locationId integer ID of the location where the clock action was performed. false false
gpsLatitude decimal GPS latitude at the time of clock action. false false
gpsLongitude decimal GPS longitude at the time of clock action. false false
gpsAccuracy decimal GPS accuracy in meters at the time of clock action. false false
deviceId string ID of the device used for the clock action. false false
ipAddress string IP address from which the clock action was performed. true false
notes string Optional notes or comments related to the clock action. false false
isEdited boolean Whether this entry has been manually edited. true false
editNotes string Notes explaining any edits made to the entry. false false
editedBy integer ID of the user who edited this entry. true false
editedDate datetime Date and time when this entry was last edited. true false
createdDate datetime Date the entry was created in the system. true false

Clock In/Out

The clock resource is used to manage Clock In/Out data within ServiceTrade.

  • Resource URL: /clock
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /clock 200
GET /clock/123 200
GET /clock/123 404 clock not found
POST /clock 200 clock created
POST /clock 400 invalid data
PUT /clock/123 200 clock updated
PUT /clock/123 400 invalid data
PUT /clock/123 404 clock not found
DELETE /clock/123 204 clock deleted
DELETE /clock/123 404 clock not found

Returned Elements for /clock/[clockId]

Name Type Value
id integer clock entity ID
uri string resource identifier for the clock
name string name of the clock
