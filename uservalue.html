User Value

The User Value object represents custom data fields associated with user accounts. These customizable fields allow for storing additional user information that isn't covered by standard user properties. User Values can include certifications, skills, training dates, license numbers, equipment qualifications, or any other user-specific attributes relevant to the organization's operational needs. This extensibility enables businesses to adapt the user management system to their specific requirements without modifying the core system.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the user value. true false
userId integer ID of the user this value is associated with. false true
name string Name/key of the custom field. false true
value string Value stored in the custom field. false true
dataType string Type of data (e.g., "string", "number", "date", "boolean"). false true
category string Category for grouping related user values. false false
isPublic boolean Whether the value is visible to regular users (not just admins). false false
createdDate datetime Date and time when the user value was created. true false
modifiedDate datetime Date and time when the user value was last modified. true false
expirationDate datetime Optional date when this value expires (e.g., for certifications). false false

Endpoints
