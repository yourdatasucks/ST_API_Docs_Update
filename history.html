History

The History object represents a record of changes made to entities within ServiceTrade. History entries track modifications, providing an audit trail of who changed what and when. This enables change tracking, compliance reporting, and historical analysis of entity evolution over time.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the history record. true false
entityType string Type of entity that was changed (e.g., "Job", "Customer", "Invoice"). true false
entityId integer ID of the entity that was changed. true false
timestamp datetime Date and time when the change occurred. true false
userId integer ID of the user who made the change. true false
userName string Name of the user who made the change. true false
action string Type of action performed (e.g., "Create", "Update", "Delete", "Status Change"). true false
field string Name of the field that was changed. true false
oldValue any Previous value of the field before the change. true false
newValue any New value of the field after the change. true false
changes array Array of field changes when multiple fields were modified in a single operation. true false
ipAddress string IP address from which the change was made. true false
userAgent string User agent information of the client that made the change. true false
source string Source of the change (e.g., "Web App", "Mobile App", "API", "System"). true false
notes string Additional notes or comments about the change. true false
relatedEntities array References to other entities affected by or related to this change. true false
isSystem boolean Whether the change was made by the system automatically rather than a user. true false

Change Object Properties

Each item in the changes array contains the following properties:

Property Type Description
field string Name of the field that was changed.
oldValue any Previous value of the field before the change.
newValue any New value of the field after the change.
displayName string Human-readable name of the field.

RelatedEntity Object Properties

Each item in the relatedEntities array contains the following properties:

Property Type Description
entityType string Type of the related entity.
entityId integer ID of the related entity.
relationship string Description of how this entity relates to the changed entity.

History

The history resource is used to manage History data within ServiceTrade.

  • Resource URL: /history
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /history 200
GET /history/123 200
GET /history/123 404 history not found
POST /history 200 history created
POST /history 400 invalid data
PUT /history/123 200 history updated
PUT /history/123 400 invalid data
PUT /history/123 404 history not found
DELETE /history/123 204 history deleted
DELETE /history/123 404 history not found

Returned Elements for /history/[historyId]

Name Type Value
id integer history entity ID
uri string resource identifier for the history
name string name of the history
