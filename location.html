Location

The Location object represents a physical site or address where services are performed, assets are located, or jobs are scheduled. Locations are typically associated with a Customer and serve as the destination for service jobs, the location of installed assets, and the place where technicians perform work. Each location contains address information, contact details, and other site-specific properties.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the location. true false
customerId integer ID of the Customer this location belongs to. false true
name string Name of the location. false true
address1 string First line of the street address. false true
address2 string Second line of the street address. false false
city string City of the location. false true
state string State/province of the location. false true
postalCode string Postal/ZIP code of the location. false true
country string Country of the location. false false
latitude decimal Latitude coordinate of the location. false false
longitude decimal Longitude coordinate of the location. false false
phone string Primary phone number for the location. false false
email string Primary email address for the location. false false
status string Status of the location (e.g., "Active", "Inactive"). false false
timezone string Timezone of the location in IANA time zone database format. false false
notes string General notes about the location. false false
directions string Directions to the location. false false
accessInformation string Information about accessing the location (e.g., gate codes, building access). false false
contactIds array Array of Contact IDs associated with this location. true false
assetCount integer Number of Assets at this location. true false
region string Region or territory this location belongs to. false false
locationType string Type of location (e.g., "Commercial", "Residential", "Industrial"). false false
squareFootage integer Square footage of the location. false false
numberOfFloors integer Number of floors at the location. false false
yearBuilt integer Year the location was built. false false
createdBy integer ID of the user who created this location. true false
createdDate datetime Date and time when this location was created. true false
lastModifiedBy integer ID of the user who last modified this location. true false
lastModifiedDate datetime Date and time when this location was last modified. true false
customFields object Custom fields and their values. false false

POST /locations

Creates a new location.

Request Body

{
    "customerId": 1001,
    "name": "Retail Store #123",
    "address1": "789 Shopping Center Rd",
    "city": "Chapel Hill",
    "state": "NC",
    "postalCode": "27514",
    "country": "US",
    "phone": "919-555-3000",
    "email": "store123@example.com",
    "status": "Active",
    "timezone": "America/New_York",
    "notes": "Small retail location in University Mall",
    "accessInformation": "Enter through rear service entrance before/after business hours.",
    "region": "Triangle",
    "locationType": "Commercial",
    "squareFootage": 2500,
    "numberOfFloors": 1,
    "yearBuilt": 1998,
    "customFields": {
        "storeNumber": "123",
        "retailCategory": "B",
        "operatingHours": "10AM-9PM M-Sat, 12PM-6PM Sun"
    }
}

Response

Returns the newly created location (HTTP 201 Created).

        "storeNumber": "123",
        "retailCategory": "A",
        "operatingHours": "10AM-9PM M-Sat, 12PM-6PM Sun",
        "renovationDate": "2023-05-15"
    }

Response

Returns the updated location.

DELETE /locations/{id}

Deletes a location. This is typically handled as a soft delete by setting the status to "Inactive".

Response

HTTP 204 No Content on successful deletion.

GET /customers/{customerId}/locations

Retrieves all locations for a specific customer.

Request

GET /v1.0/customers/1001/locations
Authorization: Bearer {access_token}

Response

Returns a collection of locations belonging to the specified customer.

POST /locations/{id}/deactivate

Deactivates a location (sets status to "Inactive").

Response

Returns the updated location with status set to "Inactive".

POST /locations/{id}/activate

Activates a location (sets status to "Active").

Response

Returns the updated location with status set to "Active".

GET /locations/{id}/assets

Retrieves all assets at a specific location.

Request

GET /v1.0/locations/2001/assets
Authorization: Bearer {access_token}

Response

Returns a collection of assets at the specified location.

GET /locations/{id}/jobs

Retrieves all jobs for a specific location.

Request

GET /v1.0/locations/2001/jobs?status=Scheduled
Authorization: Bearer {access_token}

Response

Returns a collection of jobs for the specified location.

GET /locations/{id}/contacts

Retrieves all contacts associated with a specific location.

Request

GET /v1.0/locations/2001/contacts
Authorization: Bearer {access_token}

Response

Returns a collection of contacts associated with the specified location.

POST /locations/{id}/contacts

Associates existing contacts with a location.

Request Body

{
    "contactIds": [3005, 3006]
}

Response

Returns a success message and updates the location's contact list.

DELETE /locations/{id}/contacts/{contactId}

Removes a contact association from a location.

Response

HTTP 204 No Content on successful removal of the association.

GET /locations/geocode

Geocodes a location's address to get latitude and longitude coordinates.

Request

GET /v1.0/locations/geocode?id=2004
Authorization: Bearer {access_token}

Response

Returns the updated location with latitude and longitude populated.

GET /locations/nearby

Finds locations within a specified distance of geographic coordinates.

Request

GET /v1.0/locations/nearby?latitude=35.7796&longitude=-78.6382&radius=10&unit=miles
Authorization: Bearer {access_token}

Response

Returns a collection of locations within the specified radius, sorted by distance.

GET /locations/export

Exports location data to a CSV or Excel file.

Request

GET /v1.0/locations/export?format=xlsx&customerId=1001
Authorization: Bearer {access_token}

Response

Returns a file download containing the requested location data.

POST /locations/import

Imports locations from a CSV or Excel file.

Request

A multipart/form-data request containing the file to import and optional parameters.

Response

Returns information about the import process including success count, error count, and any import issues.
