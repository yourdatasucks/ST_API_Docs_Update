Location

The Location object represents a physical site or address where services are performed, assets are located, or jobs are scheduled. Locations are typically associated with a Customer and serve as the destination for service jobs, the location of installed assets, and the place where technicians perform work. Each location contains address information, contact details, and other site-specific properties.

Location

The location resource is used to manage Location data within ServiceTrade.

  • Resource URL: /location
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /location 200
GET /location/123 200
GET /location/123 404 location not found
POST /location 200 location created
POST /location 400 invalid data
PUT /location/123 200 location updated
PUT /location/123 400 invalid data
PUT /location/123 404 location not found
DELETE /location/123 204 location deleted
DELETE /location/123 404 location not found

Returned Elements for /location/[locationId]

Name Type Value
id integer location entity ID
uri string resource identifier for the location
name string name of the location
