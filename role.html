Role

The Role object represents a set of permissions and access rights within ServiceTrade. Roles define what actions a User can perform within the system and what data they can access. Roles can be assigned to multiple users and are customizable to support various business needs, organizational structures, and security requirements. By assigning specific roles to users, administrators can control access to sensitive information and functionality in a granular way.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the role. true false
name string Name of the role. false true
description string Description of the role's purpose and scope. false false
isActive boolean Whether the role is currently active in the system. false false
isSystem boolean Whether this is a system-defined role that cannot be modified or deleted. true false
permissions array Array of permissions assigned to this role. false true
userCount integer Number of users assigned to this role. true false
scope string Scope of the role (e.g., "Global", "Region", "Branch", "Department"). false false
parentRoleId integer ID of the parent role if this is a derivative role. false false
createdBy integer ID of the user who created this role. true false
createdDate datetime Date and time when this role was created. true false
lastModifiedBy integer ID of the user who last modified this role. true false
lastModifiedDate datetime Date and time when this role was last modified. true false
customFields object Custom fields and their values. false false

DELETE /roles/{id}

Deletes a role. This is only allowed for custom roles that are not assigned to any users.

Response

HTTP 204 No Content on successful deletion.

POST /roles/{id}/deactivate

Deactivates a role without deleting it. Users with this role will lose the associated permissions.

Response

Returns the deactivated role with updated status.

POST /roles/{id}/activate

Activates a previously deactivated role.

Response

Returns the activated role with updated status.

GET /roles/{id}/users

Retrieves a list of users assigned to a specific role.

Request

GET /v1.0/roles/3/users
Authorization: Bearer {access_token}

Response

Returns a collection of users assigned to the specified role.

POST /roles/{id}/assign

Assigns a role to one or more users.

Request Body

{
    "userIds": [101, 102, 103]
}

Response

Returns information about the role assignments.

POST /roles/{id}/unassign

Removes a role from one or more users.

Request Body

{
    "userIds": [101, 102]
}

Response

Returns information about the role removals.
