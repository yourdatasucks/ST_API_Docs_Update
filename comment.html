Comment

The Comment object represents user-generated comments or notes that can be attached to various entities in the system, such as jobs, tasks, quotes, invoices, and other objects. Comments support communication and documentation of discussions related to any supported entity.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the comment. true false
text string The content of the comment. May contain simple HTML formatting. false true
entityId integer ID of the entity this comment is attached to. false true
entityType string Type of entity this comment is attached to (e.g., "Job", "Task", "Quote", "Invoice"). false true
userId integer ID of the user who created the comment. true false
userName string Display name of the user who created the comment. true false
parentCommentId integer ID of the parent comment if this is a reply to another comment. false false
isInternal boolean Whether this comment is visible only to internal users (not to customers). false false
pinned boolean Whether this comment is pinned to the top of the comments list. false false
visibility string Visibility scope, e.g., "Public", "Internal", "Customer", "Technicians". false false
hasAttachments boolean Whether this comment has file attachments. true false
attachments array Array of attachment objects associated with this comment. true false
mentions array Array of user IDs mentioned in this comment. false false
isEdited boolean Whether this comment has been edited after creation. true false
lastEditedDate datetime Date and time when this comment was last edited. true false
createdDate datetime Date and time when the comment was created. true false
lastModifiedDate datetime Date and time when the comment was last modified. true false

Comment

The comment resource is used to manage Comment data within ServiceTrade.

  • Resource URL: /comment
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /comment 200
GET /comment/123 200
GET /comment/123 404 comment not found
POST /comment 200 comment created
POST /comment 400 invalid data
PUT /comment/123 200 comment updated
PUT /comment/123 400 invalid data
PUT /comment/123 404 comment not found
DELETE /comment/123 204 comment deleted
DELETE /comment/123 404 comment not found

Returned Elements for /comment/[commentId]

Name Type Value
id integer comment entity ID
uri string resource identifier for the comment
name string name of the comment
