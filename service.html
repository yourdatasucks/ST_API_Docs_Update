Service

The Service object represents a specific type of work or service offered by a company to its customers. Services define standardized offerings that can be added to Jobs, Quotes, and Invoices. Each service typically includes standard pricing, description, time estimates, and other attributes that help maintain consistency in service delivery and financial operations. Services may be grouped into service lines or categories for organizational and reporting purposes.

Service

The service resource is used to manage Service data within ServiceTrade.

  • Resource URL: /service
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /service 200
GET /service/123 200
GET /service/123 404 service not found
POST /service 200 service created
POST /service 400 invalid data
PUT /service/123 200 service updated
PUT /service/123 400 invalid data
PUT /service/123 404 service not found
DELETE /service/123 204 service deleted
DELETE /service/123 404 service not found

Returned Elements for /service/[serviceId]

Name Type Value
id integer service entity ID
uri string resource identifier for the service
name string name of the service
