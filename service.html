Service

The Service object represents a specific type of work or service offered by a company to its customers. Services define standardized offerings that can be added to Jobs, Quotes, and Invoices. Each service typically includes standard pricing, description, time estimates, and other attributes that help maintain consistency in service delivery and financial operations. Services may be grouped into service lines or categories for organizational and reporting purposes.

POST /services/import

Imports services from a file or external system.

Request Body

{
    "source": "CSV",
    "data": "base64-encoded-csv-content",
    "mappings": {
        "name": "ServiceName",
        "description": "Description",
        "code": "ServiceCode",
        "category": "Category",
        "defaultRate": "Rate"
    },
    "updateExisting": true,
    "identifyBy": "code"
}

Response

Returns information about the imported services.

POST /services/export

Exports services to a file.

Request Body

{
    "format": "CSV",
    "filter": {
        "categories": ["HVAC", "Plumbing"],
        "isActive": true
    },
    "fields": [
        "id",
        "name",
        "description",
        "code",
        "category",
        "defaultRate",
        "estimatedDuration"
    ]
}

Response

Returns a download URL for the exported services.
