Task

The Task object represents a specific action or activity that needs to be completed as part of a job or service. Tasks are used to track individual work items, assign responsibilities, and organize the workflow for service delivery. They can be grouped into task lists and may have dependencies on other tasks, due dates, and assignees.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the task. true false
name string Name of the task. false true
description string Detailed description of the task. false false
taskListId integer ID of the task list this task belongs to. false true
sequence integer Order of the task within its task list. false false
isRequired boolean Whether completion of this task is mandatory. false false
isActive boolean Whether the task is active. false false
taskType string Type of task (e.g., "standard", "inspection", "form"). false false
estimatedDuration integer Estimated time in minutes to complete the task. false false
dependencies array Array of task IDs that must be completed before this task. false false
formId integer ID of the form to use if this is a form-type task. false false
createdBy integer ID of the user who created this task. true false
createdDate datetime Date and time when this task was created. true false
lastModifiedBy integer ID of the user who last modified this task. true false
lastModifiedDate datetime Date and time when this task was last modified. true false
customFields object Custom fields and their values for this task. false false

Task

The task resource is used to manage task definitions that can be included in task lists and assigned to job instances.

  • Resource URL: /task
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /task 200
GET /task/123 200
GET /task/123 404 task not found
POST /task 200 task created
POST /task 400 invalid data
PUT /task/123 200 task updated
PUT /task/123 400 invalid data
PUT /task/123 404 task not found
DELETE /task/123 204 task deleted
DELETE /task/123 404 task not found
DELETE /task/123 409 task is in use
