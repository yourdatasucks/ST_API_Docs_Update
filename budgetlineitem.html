Budget Line Item

The Budget Line Item object represents an individual expense or cost entry within a Budget Category. Budget Line Items are the most granular level of financial planning in a budget structure.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the budget line item. true false
budgetId integer ID of the parent Budget. false true
categoryId integer ID of the parent Budget Category. false true
referenceNumber string Reference number that this line item is known by. false false
name string Name or description of the line item. false true
description string Detailed description of the line item. false false
cost decimal Unit cost of the line item. false true
quantity decimal Quantity of units for this line item. false true
unit string Unit of measure (e.g., "hours", "pieces", "sq ft"). false false
total decimal Total cost for this line item (cost × quantity). true false
usedAmount decimal Amount used/spent from this line item budget. true false
remainingAmount decimal Amount remaining in this line item budget. true false
orderIndex integer Display order for the line item within the category. false false
libItemId integer ID of the library item this line item is based on, if applicable. false false
serviceItemId integer ID of the service item this line item is associated with, if applicable. false false
createdDate datetime Date the budget line item was created. true false
createdBy integer ID of the user who created the budget line item. true false
lastModifiedDate datetime Date the budget line item was last modified. true false
lastModifiedBy integer ID of the user who last modified the budget line item. true false

POST /budgetlineitems

Creates a new budget line item within a budget category.

Request Body

{
    "budgetId": 123,
    "categoryId": 201,
    "name": "Interior Finishes",
    "referenceNumber": "BLI-005",
    "description": "Interior paint, trim, and finishes",
    "cost": 15000.00,
    "quantity": 1,
    "unit": "job",
    "orderIndex": 5
}

Response

Returns the newly created budget line item object (HTTP 201 Created).

PUT /budgetlineitems/{id}

Updates an existing budget line item.

Request Body

{
    "name": "Interior Finishes - Premium",
    "description": "Interior paint, trim, and premium finishes",
    "cost": 18500.00,
    "quantity": 1
}

Response

Returns the updated budget line item object.

DELETE /budgetlineitems/{id}

Deletes a budget line item. This may be disallowed if the parent budget is in certain statuses or if there are transactions against this line item.

Response

HTTP 204 No Content on successful deletion.

GET /budgetlineitems/{id}/transactions

Retrieves all financial transactions associated with this budget line item.

Request

GET /v1.0/budgetlineitems/301/transactions
Authorization: Bearer {access_token}

Response

Returns a collection of financial transactions related to this line item.
