Message

The Message object represents communications between users within ServiceTrade, between users and customers, or system-generated notifications. Messages can be attached to various entities such as Jobs, Quotes, or Invoices, enabling contextual communication about specific records. The messaging system supports both internal communications and external customer-facing communications.

Message

The message resource is used to manage Message data within ServiceTrade.

  • Resource URL: /message
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /message 200
GET /message/123 200
GET /message/123 404 message not found
POST /message 200 message created
POST /message 400 invalid data
PUT /message/123 200 message updated
PUT /message/123 400 invalid data
PUT /message/123 404 message not found
DELETE /message/123 204 message deleted
DELETE /message/123 404 message not found

Returned Elements for /message/[messageId]

Name Type Value
id integer message entity ID
uri string resource identifier for the message
name string name of the message
