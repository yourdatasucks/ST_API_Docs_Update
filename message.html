Message

The Message object represents communications between users within ServiceTrade, between users and customers, or system-generated notifications. Messages can be attached to various entities such as Jobs, Quotes, or Invoices, enabling contextual communication about specific records. The messaging system supports both internal communications and external customer-facing communications.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the message. true false
subject string Subject line of the message. false true
body string Body content of the message. May contain HTML formatting. false true
senderId integer ID of the User who sent the message. true false
senderName string Name of the sender. true false
senderEmail string Email address of the sender. true false
recipientIds array Array of recipient user IDs. false true
recipientEmails array Array of recipient email addresses. false false
sentDate datetime Date and time when the message was sent. true false
type string Type of message (e.g., "Internal", "Customer", "System", "Notification"). false true
priority string Priority level of the message (e.g., "Low", "Normal", "High", "Urgent"). false false
status string Status of the message (e.g., "Draft", "Sent", "Delivered", "Read"). true false
entityType string Type of entity this message is related to (e.g., "Job", "Quote", "Invoice"). false false
entityId integer ID of the entity this message is related to. false false
threadId integer ID of the message thread this message belongs to. true false
parentMessageId integer ID of the parent message if this is a reply. false false
attachmentIds array Array of Attachment IDs associated with this message. false false
isInternal boolean Whether this message is internal only (not visible to customers). false false
deliveryChannels array Array of delivery channels used (e.g., "Email", "SMS", "In-App", "Push"). false false
deliveryStatus object Object containing delivery status for each recipient and channel. true false
tags array Array of tags associated with this message. false false
createdBy integer ID of the user who created this message. true false
createdDate datetime Date and time when this message was created. true false
lastModifiedBy integer ID of the user who last modified this message. true false
lastModifiedDate datetime Date and time when this message was last modified. true false
customFields object Custom fields and their values. false false

POST /messages

Creates a new message.

Request Body

{
    "subject": "Equipment Recommendation",
    "body": "
Based on our inspection, I recommend replacing the aging cooling tower within the next 6 months. I've attached a preliminary quote for your review.
Let me know if you have any questions.
",
    "recipientIds": [105, 106],
    "recipientEmails": ["facility.manager@customer.com", "operations@customer.com"],
    "type": "Customer",
    "priority": "Normal",
    "entityType": "Job",
    "entityId": 3005,
    "attachmentIds": [9001],
    "isInternal": false,
    "deliveryChannels": ["Email", "In-App"],
    "tags": ["Equipment", "Recommendation", "Quote"]
}

Response

Returns the newly created message (HTTP 201 Created).

PUT /messages/{id}

Updates an existing message. This is typically only allowed for messages with "Draft" status.

Request Body

{
    "subject": "Equipment Recommendation Update",
    "body": "
Based on our inspection, I recommend replacing the aging cooling tower within the next 6 months. I've attached a detailed quote and timeline for your review.
Please let me know if you have any questions or would like to discuss this further.
",
    "priority": "High",
    "attachmentIds": [9001, 9002]
}

Response

Returns the updated message.

DELETE /messages/{id}

Deletes a message. This is typically only allowed for messages with "Draft" status or by administrators.

Response

HTTP 204 No Content on successful deletion.

POST /messages/{id}/send

Sends a message that was previously saved as a draft.

Request Body

{
    "deliveryChannels": ["Email", "In-App"]
}

Response

Returns the sent message with updated status.

POST /messages/{id}/reply

Creates a reply to an existing message.

Request Body

{
    "body": "
Thanks for the recommendation. We'll review the quote and get back to you next week after our budget meeting.
",
    "recipientIds": [102],
    "attachmentIds": [],
    "isInternal": false,
    "deliveryChannels": ["Email", "In-App"]
}

Response

Returns the newly created reply message.

POST /messages/{id}/forward

Forwards an existing message to new recipients.

Request Body

{
    "recipientIds": [104, 107],
    "recipientEmails": ["maintenance.manager@example.com"],
    "body": "
FYI - Please review this equipment recommendation and provide your input.
",
    "attachmentIds": [9001, 9002, 9003],
    "isInternal": true,
    "deliveryChannels": ["Email", "In-App"]
}

Response

Returns the newly created forwarded message.

GET /messages/threads/{threadId}

Retrieves all messages in a specific thread.

Request

GET /v1.0/messages/threads/4001
Authorization: Bearer {access_token}

Response

Returns a collection of messages belonging to the specified thread.

POST /messages/{id}/mark-read

Marks a message as read for the current user.

Response

Returns the updated message with read status.

POST /messages/{id}/mark-unread

Marks a message as unread for the current user.

Response

Returns the updated message with unread status.

GET /entities/{entityType}/{entityId}/messages

Retrieves messages related to a specific entity.

Request

GET /v1.0/entities/Job/3001/messages
Authorization: Bearer {access_token}

Response

Returns a collection of messages related to the specified entity.

POST /messages/batch

Creates multiple messages in a single request.

Request Body

{
    "messages": [
        {
            "subject": "Preventive Maintenance Reminder",
            "body": "
This is a reminder that your quarterly preventive maintenance is scheduled for next Monday.
",
            "recipientIds": [201, 202],
            "type": "Customer",
            "entityType": "Job",
            "entityId": 3010,
            "deliveryChannels": ["Email"]
        },
        {
            "subject": "Service Agreement Renewal",
            "body": "
Your service agreement is up for renewal next month. I've attached the renewal quote for your review.
",
            "recipientIds": [201],
            "type": "Customer",
            "entityType": "Quote",
            "entityId": 2015,
            "attachmentIds": [9010],
            "deliveryChannels": ["Email"]
        }
    ]
}

Response

Returns an array of the created messages.

POST /messages/notify

Sends a notification message to multiple recipients based on criteria.

Request Body

{
    "template": "job_scheduled",
    "parameters": {
        "jobId": 3020,
        "scheduledDate": "2023-07-15",
        "scheduledTime": "10:00 AM"
    },
    "recipientFilter": {
        "roles": ["Technician", "Dispatcher"],
        "regions": ["Northeast"],
        "assigned": true
    },
    "deliveryChannels": ["Email", "SMS", "In-App"]
}

Response

Returns information about the sent notifications.

GET /message-templates

Retrieves a list of available message templates.

Request

GET /v1.0/message-templates?type=Customer
Authorization: Bearer {access_token}

Response

Returns a collection of message templates matching the specified criteria.

POST /messages/from-template

Creates a message using a template.

Request Body

{
    "templateId": 101,
    "parameters": {
        "customerName": "ABC Corporation",
        "jobNumber": "JOB-2023-0456",
        "scheduledDate": "July 15, 2023",
        "contactName": "John Smith"
    },
    "recipientIds": [201],
    "entityType": "Job",
    "entityId": 3020,
    "deliveryChannels": ["Email"]
}

Response

Returns the created message based on the template.
