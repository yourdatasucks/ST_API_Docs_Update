Import

The Import object represents a data import operation in ServiceTrade. It tracks the status, progress, and results of importing data from external sources such as CSV files, spreadsheets, or third-party systems. The Import API enables bulk creation and updating of entities within ServiceTrade.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the import operation. true false
name string Name or description of the import operation. false true
type string Type of import (e.g., "Customer", "Location", "Asset", "Job", "Contact"). false true
status string Current status of the import (e.g., "Pending", "Processing", "Completed", "Failed", "Cancelled"). true false
source string Source of the import data (e.g., "CSV", "Excel", "API", "ExternalSystem"). false true
sourceFile string Name of the source file, if applicable. false false
sourceFileUrl string URL to the source file, if applicable. true false
externalSystemId integer ID of the external system, if the import is from an external system. false false
userId integer ID of the user who initiated the import. true false
createdDate datetime Date and time when the import was created. true false
startDate datetime Date and time when the import processing began. true false
completedDate datetime Date and time when the import was completed. true false
options object Import configuration options. false false
fieldMapping object Mapping between source fields and destination fields. false false
totalRecords integer Total number of records in the import. true false
processedRecords integer Number of records processed so far. true false
successCount integer Number of records successfully imported. true false
errorCount integer Number of records that failed to import. true false
warningCount integer Number of records imported with warnings. true false
progressPercentage integer Current progress as a percentage. true false
errors array Array of error details for failed records. true false
warnings array Array of warning details for records with warnings. true false
resultsUrl string URL to download the import results. true false
errorReportUrl string URL to download a report of errors and warnings. true false
templateUrl string URL to download a template for this import type. true false
notes string Additional notes about the import. false false

Import Options Object Properties

The options object contains configuration settings for the import:

Property Type Description
updateExisting boolean Whether to update existing records if found.
createMissing boolean Whether to create new records if not found.
identifierField string Field used to identify existing records (e.g., "id", "externalId", "email").
skipHeaderRow boolean Whether to skip the first row (header) in the import file.
delimiter string Character used as delimiter in CSV files (e.g., ",", ";", "\\t").
dateFormat string Format of date values in the import (e.g., "MM/DD/YYYY", "YYYY-MM-DD").
batchSize integer Number of records to process in each batch.
stopOnError boolean Whether to stop the import if errors are encountered.
errorThreshold integer Maximum number of errors before the import is aborted.
notifyOnCompletion boolean Whether to send notification when import is complete.
notificationEmails array Email addresses to notify on completion.

Error Object Properties

Each item in the errors array contains the following properties:

Property Type Description
rowNumber integer Row number in the import file where the error occurred.
message string Error message describing the issue.
field string Field where the error occurred, if applicable.
value string Value that caused the error, if applicable.
recordData object Data from the record that failed to import.

Import

The import resource is used to manage Import data within ServiceTrade.

  • Resource URL: /import
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /import 200
GET /import/123 200
GET /import/123 404 import not found
POST /import 200 import created
POST /import 400 invalid data
PUT /import/123 200 import updated
PUT /import/123 400 invalid data
PUT /import/123 404 import not found
DELETE /import/123 204 import deleted
DELETE /import/123 404 import not found

Returned Elements for /import/[importId]

Name Type Value
id integer import entity ID
uri string resource identifier for the import
name string name of the import
