Heartbeat

The Heartbeat object represents a monitoring signal sent periodically from a client application or device to indicate its active status and health. Heartbeats are used to track connectivity, monitor application status, and detect when systems go offline.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the heartbeat record. true false
clientId string Identifier for the client application or device sending the heartbeat. false true
type string Type of the heartbeat (e.g., "Application", "Device", "Mobile", "Integration"). false true
timestamp datetime Date and time when the heartbeat was received. true false
status string Status of the client (e.g., "Active", "Idle", "Warning", "Error"). false false
deviceInfo object Information about the device or application sending the heartbeat. false false
metrics object Performance metrics and statistics from the client. false false
logs array Recent log entries or events from the client. false false
location object Geographic location of the client when the heartbeat was sent. false false
userId integer ID of the user associated with this client, if applicable. false false
ipAddress string IP address of the client. true false
version string Version of the client application or device. false false
expectedInterval integer Expected time interval between heartbeats in seconds. false false
lastSeen datetime Date and time when the client was last seen. true false
isOnline boolean Whether the client is currently considered online. true false
notes string Additional information or notes about the heartbeat. false false

DeviceInfo Object Properties

Property Type Description
deviceType string Type of device (e.g., "Smartphone", "Tablet", "Desktop", "IoT Device").
os string Operating system of the device.
osVersion string Version of the operating system.
browser string Browser used, if applicable.
browserVersion string Version of the browser, if applicable.
manufacturer string Manufacturer of the device.
model string Model of the device.
uniqueId string Unique identifier for the device.

Metrics Object Properties

Property Type Description
batteryLevel number Battery level as a percentage (0-100).
memoryUsage number Memory usage as a percentage (0-100).
cpuUsage number CPU usage as a percentage (0-100).
networkSpeed number Network speed in Mbps.
diskSpace number Available disk space in MB.
temperature number Device temperature in Celsius.
signalStrength number Signal strength for wireless devices (-100 to 0 dBm).
custom object Custom metrics specific to the application or device.

GET /heartbeats/{id}

Retrieves a specific heartbeat record by ID.

Request

GET /v1.0/heartbeats/987654
Authorization: Bearer {access_token}

Response

Returns the heartbeat record with the specified ID.

GET /heartbeats/client/{clientId}

Retrieves heartbeat records for a specific client.

Request

GET /v1.0/heartbeats/client/mobile-app-6789
Authorization: Bearer {access_token}

Response

Returns a collection of heartbeat records for the specified client.

GET /heartbeats/client/{clientId}/latest

Retrieves the most recent heartbeat for a specific client.

Request

GET /v1.0/heartbeats/client/mobile-app-6789/latest
Authorization: Bearer {access_token}

Response

Returns the most recent heartbeat record for the specified client.

GET /heartbeats/user/{userId}

Request

Authorization: Bearer {access_token}

Response

Deletes a specific heartbeat record.

Response

HTTP 204 No Content on successful deletion.

POST /heartbeats/register

Registers a new client for heartbeat monitoring.

Request Body

{
    "clientId": "field-app-9876",
    "type": "Mobile",
    "deviceInfo": {
        "deviceType": "Tablet",
        "os": "iOS",
        "osVersion": "16.5",
        "manufacturer": "Apple",
        "model": "iPad Pro"
    },
    "userId": 12347,
    "expectedInterval": 300,
    "alertThreshold": 900,
    "notifyOnOffline": true,
    "notifyContacts": ["admin@example.com", "support@example.com"]
}

Response

Returns the registration details for the client.

DELETE /heartbeats/client/{clientId}

Deletes all heartbeat records for a specific client.

Response
