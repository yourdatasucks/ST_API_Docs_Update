Heartbeat

The Heartbeat object represents a monitoring signal sent periodically from a client application or device to indicate its active status and health. Heartbeats are used to track connectivity, monitor application status, and detect when systems go offline.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the heartbeat record. true false
clientId string Identifier for the client application or device sending the heartbeat. false true
type string Type of the heartbeat (e.g., "Application", "Device", "Mobile", "Integration"). false true
timestamp datetime Date and time when the heartbeat was received. true false
status string Status of the client (e.g., "Active", "Idle", "Warning", "Error"). false false
deviceInfo object Information about the device or application sending the heartbeat. false false
metrics object Performance metrics and statistics from the client. false false
logs array Recent log entries or events from the client. false false
location object Geographic location of the client when the heartbeat was sent. false false
userId integer ID of the user associated with this client, if applicable. false false
ipAddress string IP address of the client. true false
version string Version of the client application or device. false false
expectedInterval integer Expected time interval between heartbeats in seconds. false false
lastSeen datetime Date and time when the client was last seen. true false
isOnline boolean Whether the client is currently considered online. true false
notes string Additional information or notes about the heartbeat. false false

DeviceInfo Object Properties

Property Type Description
deviceType string Type of device (e.g., "Smartphone", "Tablet", "Desktop", "IoT Device").

Metrics Object Properties

Property Type Description
batteryLevel number Battery level as a percentage (0-100).

Heartbeat

The heartbeat resource is used to manage Heartbeat data within ServiceTrade.

  • Resource URL: /heartbeat
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /heartbeat 200
GET /heartbeat/123 200
GET /heartbeat/123 404 heartbeat not found
POST /heartbeat 200 heartbeat created
POST /heartbeat 400 invalid data
PUT /heartbeat/123 200 heartbeat updated
PUT /heartbeat/123 400 invalid data
PUT /heartbeat/123 404 heartbeat not found
DELETE /heartbeat/123 204 heartbeat deleted
DELETE /heartbeat/123 404 heartbeat not found

Returned Elements for /heartbeat/[heartbeatId]

Name Type Value
id integer heartbeat entity ID
uri string resource identifier for the heartbeat
name string name of the heartbeat
