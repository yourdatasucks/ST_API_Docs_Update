User Group Label

The User Group Label object represents a tag or categorization that can be applied to users for organizational purposes. These labels help with filtering, grouping, and managing users based on common attributes such as departments, skills, certifications, geographical regions, or any other business-specific categorization. User Group Labels facilitate efficient team management and resource allocation by enabling administrators to create logical groupings of users.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the user group label. true false
name string Name of the user group label. false true
description string Description of the user group label and its purpose. false false
color string Color code (hex) used for visual representation of the label. false false
createdDate datetime Date and time when the label was created. true false
modifiedDate datetime Date and time when the label was last modified. true false
isActive boolean Whether the label is currently active and available for use. false false
userCount integer Number of users currently associated with this label. true false
