Contract

The Contract object represents a formal agreement between a service provider and a customer for recurring services or maintenance. Contracts typically include details about services covered, pricing, term length, and renewal terms.

Contract

The contract resource is used to manage Contract data within ServiceTrade.

  • Resource URL: /contract
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /contract 200
GET /contract/123 200
GET /contract/123 404 contract not found
POST /contract 200 contract created
POST /contract 400 invalid data
PUT /contract/123 200 contract updated
PUT /contract/123 400 invalid data
PUT /contract/123 404 contract not found
DELETE /contract/123 204 contract deleted
DELETE /contract/123 404 contract not found

Returned Elements for /contract/[contractId]

Name Type Value
id integer contract entity ID
uri string resource identifier for the contract
name string name of the contract
