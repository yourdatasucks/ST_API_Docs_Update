Contract

The Contract object represents a formal agreement between a service provider and a customer for recurring services or maintenance. Contracts typically include details about services covered, pricing, term length, and renewal terms.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the contract. true false
number string Contract reference number or identifier. false false
name string Name or title of the contract. false true
description string Detailed description of the contract and its terms. false false
companyId integer ID of the customer Company this contract is with. false true
locationIds array Array of Location IDs covered by this contract. false false
type string Type of contract (e.g., "Service", "Maintenance", "Support"). false false
status string Status of the contract (e.g., "Draft", "Active", "Expired", "Canceled"). false true
startDate date Date when the contract becomes effective. false true
endDate date Date when the contract expires. false true
term integer Length of the contract term in months. false false
autoRenew boolean Whether the contract automatically renews at the end of the term. false false
renewalTerm integer Length of renewal term in months, if different from initial term. false false
cancellationNoticeDays integer Number of days notice required for cancellation. false false
totalValue decimal Total monetary value of the contract. false false
recurringAmount decimal Recurring payment amount. false false
billingFrequency string Frequency of billing (e.g., "Monthly", "Quarterly", "Annually"). false false
nextBillingDate date Date of the next scheduled billing. false false
primaryContactId integer ID of the primary Contact for this contract. false false
salesRepId integer ID of the sales representative who sold the contract. false false
accountManagerId integer ID of the account manager responsible for this contract. false false
notificationDays integer Days before expiration to send renewal notification. false false
contractDocumentUrl string URL to the digital contract document. false false
signedDate date Date the contract was signed by all parties. false false
notes string Additional notes about the contract. false false
assetIds array Array of Asset IDs covered by this contract. false false
customFields object Custom field values for the contract. false false
tags array Array of tags associated with the contract. false false
createdDate datetime Date the contract record was created. true false
createdBy integer ID of the user who created the contract record. true false
lastModifiedDate datetime Date the contract record was last modified. true false
lastModifiedBy integer ID of the user who last modified the contract record. true false

POST /contracts

Creates a new contract.

Request Body

{
    "name": "Fire Safety System Maintenance",
    "description": "Annual maintenance and inspection of all fire safety systems",
    "companyId": 123,
    "locationIds": [203],
    "type": "Maintenance",
    "status": "Draft",
    "startDate": "2023-09-01",
    "endDate": "2024-08-31",
    "term": 12,
    "autoRenew": true,
    "cancellationNoticeDays": 60,
    "totalValue": 6000.00,
    "recurringAmount": 500.00,
    "billingFrequency": "Monthly",
    "primaryContactId": 302,
    "salesRepId": 201,
    "assetIds": [601, 602, 603],
    "tags": ["Fire Safety", "Annual Inspection"]
}

Response

Returns the newly created contract object (HTTP 201 Created).

PUT /contracts/{id}

Updates an existing contract.

Request Body

{
    "name": "Fire Safety System Maintenance - Premium",
    "description": "Comprehensive annual maintenance and inspection of all fire safety systems with priority service",
    "status": "Active",
    "recurringAmount": 600.00,
    "accountManagerId": 203,
    "notes": "Customer upgraded to premium service level with 24/7 emergency response"
}

Response

Returns the updated contract object.

DELETE /contracts/{id}

Deletes a contract. This may be disallowed for active contracts or contracts with associated records.

Response

HTTP 204 No Content on successful deletion.

GET /contracts/{id}/rules

Retrieves all contract rules associated with a specific contract.

Request

GET /v1.0/contracts/456/rules
Authorization: Bearer {access_token}

Response

Returns a collection of Contract Rules for this contract.

GET /contracts/{id}/servicerecurrences

Retrieves all service recurrences associated with a specific contract.

Request

GET /v1.0/contracts/456/servicerecurrences
Authorization: Bearer {access_token}

Response

Returns a collection of Service Recurrences for this contract.

GET /contracts/{id}/assets

Retrieves all assets covered by a specific contract.

Request

GET /v1.0/contracts/456/assets
Authorization: Bearer {access_token}

Response

Returns a collection of Assets covered by this contract.

POST /contracts/{id}/renew

Renews an existing contract, creating a new contract term.

Request Body

{
    "renewalStartDate": "2024-01-01",
    "renewalEndDate": "2024-12-31",
    "adjustments": {
        "recurringAmount": 1050.00,
        "notes": "5% price increase from previous term"
    }
}

Response

Returns the renewed contract object.

POST /contracts/{id}/terminate

Terminates an active contract before its end date.

Request Body

{
    "terminationDate": "2023-10-31",
    "terminationReason": "Customer relocated to a region we don't service",
    "earlyTerminationFee": 2000.00,
    "waiveTerminationFee": false,
    "notes": "Approved by regional manager"
}

Response

Returns the updated contract object with terminated status.
