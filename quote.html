Quote

The Quote object represents a proposal or estimate of work to be performed and its associated costs, sent to a Customer for approval. Quotes typically include line items detailing services, products, and pricing information. Once approved, a Quote can be converted to a Job or Invoice. Quotes serve as a key document in the pre-sales process, enabling service providers to communicate scope, pricing, and terms to customers before work begins.

Quote

The quote resource is used to manage Quote data within ServiceTrade.

  • Resource URL: /quote
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /quote 200
GET /quote/123 200

POST /quote 200 quote created
POST /quote 400 invalid data
PUT /quote/123 200 quote updated
PUT /quote/123 400 invalid data
PUT /quote/123 404 quote not found
DELETE /quote/123 204 quote deleted
DELETE /quote/123 404 quote not found
