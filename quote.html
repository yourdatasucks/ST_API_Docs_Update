Quote

The Quote object represents a proposal or estimate of work to be performed and its associated costs, sent to a Customer for approval. Quotes typically include line items detailing services, products, and pricing information. Once approved, a Quote can be converted to a Job or Invoice. Quotes serve as a key document in the pre-sales process, enabling service providers to communicate scope, pricing, and terms to customers before work begins.

DELETE /quotes/{id}

Deletes a quote. This is typically only allowed for quotes in "Draft" status.

Response

HTTP 204 No Content on successful deletion.

POST /quotes/{id}/send

Sends a quote to the customer, updating its status to "Sent".

Request Body

{
    "recipients": ["jane.smith@customer.com", "facilities@customer.com"],
    "subject": "Quote for Rooftop Unit Replacement",
    "message": "Please find attached our quote for the rooftop unit replacement project we discussed. Let me know if you have any questions.",
    "attachAdditionalDocuments": true,
    "notifyResponsibleUser": true
}

Response

Returns the updated quote with status changed to "Sent" and sending details.

POST /quotes/{id}/approve

Marks a quote as approved by the customer.

Request Body

{
    "approvedBy": "Jane Smith",
    "approvedDate": "2023-07-15",
    "approvalNotes": "Approved via email confirmation.",
    "attachCustomerApproval": true,
    "attachmentId": 4025
}

Response

Returns the updated quote with status changed to "Approved" and approval details.

POST /quotes/{id}/reject

Marks a quote as rejected by the customer.

Request Body

{
    "rejectedBy": "Jane Smith",
    "rejectedDate": "2023-07-15",
    "rejectionReason": "Budget constraints; will reconsider next quarter.",
    "rejectionNotes": "Customer requested a follow-up in September."
}

Response

Returns the updated quote with status changed to "Rejected" and rejection details.

POST /quotes/{id}/convert-to-job

Converts an approved quote to a job.

Request Body

{
    "jobTitle": "Rooftop Unit Replacement",
    "scheduledStartDate": "2023-08-15",
    "scheduledEndDate": "2023-08-18",
    "jobDescription": "Replacement of aging rooftop HVAC unit with new high-efficiency model including energy recovery ventilation.",
    "jobTypeId": 102,
    "priorityId": 2,
    "assignToUserIds": [201, 202, 203],
    "includeAllLineItems": true
}

Response

Returns information about the created job and updated quote.

POST /quotes/{id}/convert-to-invoice

Converts an approved quote directly to an invoice.

Request Body

{
    "invoiceDate": "2023-07-20",
    "dueDate": "2023-08-19",
    "invoiceDescription": "Rooftop Unit Replacement project as approved in Quote Q-2023-045",
    "includeAllLineItems": true,
    "requiresDeposit": true,
    "depositPercentage": 50
}

Response

Returns information about the created invoice and updated quote.
