Warehouse

The Warehouse object represents a physical storage location for inventory, equipment, parts, and supplies used in service operations. Warehouses can include central distribution centers, branch locations, service vehicles, or any other designated storage area. The Warehouse API allows for managing inventory across multiple locations, tracking stock levels, recording transfers between warehouses, and maintaining accurate inventory valuations.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the warehouse. true false
name string Name of the warehouse. false true
code string Short code or identifier for the warehouse. false false
description string Detailed description of the warehouse. false false
type string Type of warehouse (e.g., "Primary", "Branch", "Vehicle", "Customer"). false false
isActive boolean Whether the warehouse is currently active and available for use. false false
address object Physical address of the warehouse. false false
contactName string Name of the primary contact for the warehouse. false false
contactPhone string Phone number of the primary contact. false false
contactEmail string Email address of the primary contact. false false
managerId integer ID of the user who manages this warehouse. false false
parentWarehouseId integer ID of the parent warehouse if this is a subwarehouse. false false
latitude decimal Latitude coordinate of the warehouse location. false false
longitude decimal Longitude coordinate of the warehouse location. false false
businessHours object Operating hours of the warehouse. false false
inventoryCount integer Total count of inventory items in the warehouse. true false
inventoryValue decimal Total value of inventory stored in the warehouse. true false
regionId integer ID of the region this warehouse belongs to. false false
isVirtual boolean Whether this is a virtual warehouse (not a physical location). false false
isTransferEnabled boolean Whether inventory can be transferred to/from this warehouse. false false
assignedVehicleId integer For vehicle warehouses, the ID of the assigned vehicle. false false
assignedUserId integer For vehicle/personal warehouses, the ID of the assigned user. false false
createdBy integer ID of the user who created this warehouse. true false
createdDate datetime Date and time when this warehouse was created. true false
lastModifiedBy integer ID of the user who last modified this warehouse. true false
lastModifiedDate datetime Date and time when this warehouse was last modified. true false
lastInventoryDate datetime Date and time of the last physical inventory count. true false
customFields object Custom fields and their values. false false

DELETE /warehouses/{id}

Deletes a warehouse. This is typically restricted if the warehouse contains inventory.

Response

HTTP 204 No Content on successful deletion.

POST /warehouses/{id}/deactivate

Deactivates a warehouse without deleting it.

Request Body

{
    "reason": "Consolidating inventory to new location",
    "targetWarehouseId": 105,
    "transferInventory": true
}

Response

Returns the deactivated warehouse with updated status.

POST /warehouses/{id}/activate

Activates a previously deactivated warehouse.

Response

Returns the activated warehouse with updated status.

GET /warehouses/{id}/inventory

Retrieves the current inventory in a specific warehouse.

Returns a collection of inventory items in the specified warehouse.
