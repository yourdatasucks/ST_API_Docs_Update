Warehouse

The Warehouse object represents a physical storage location for inventory, equipment, parts, and supplies used in service operations. Warehouses can include central distribution centers, branch locations, service vehicles, or any other designated storage area. The Warehouse API allows for managing inventory across multiple locations, tracking stock levels, recording transfers between warehouses, and maintaining accurate inventory valuations.

Warehouse

The warehouse resource is used to manage inventory storage locations across the organization.

  • Resource URL: /warehouse
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /warehouse 200
GET /warehouse/123 200
GET /warehouse/123 404 warehouse not found
POST /warehouse 200 warehouse created
POST /warehouse 400 invalid data
PUT /warehouse/123 200 warehouse updated
PUT /warehouse/123 400 invalid data
PUT /warehouse/123 404 warehouse not found
DELETE /warehouse/123 204 warehouse deleted
DELETE /warehouse/123 404 warehouse not found
DELETE /warehouse/123 409 warehouse contains inventory

Returned Elements for /warehouse/[warehouseId]

Name Type Value
id integer warehouse entity ID

name string name of warehouse
code string short code for the warehouse

type string type of warehouse
isActive boolean whether the warehouse is active
