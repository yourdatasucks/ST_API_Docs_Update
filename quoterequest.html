Quote Request

The Quote Request object represents a customer's formal request for a price quote on services or products. Quote requests typically precede the creation of an actual quote and may include details about the customer's needs, timeline, and specifications.

Properties

Property Type Description Read-Only Required
id integer The unique identifier for the Quote Request. true false
customerId integer ID of the customer requesting the quote. false true
locationId integer ID of the location where the services will be performed. false false
title string Title or summary of the quote request. false true
description string Detailed description of the requested work or products. false false
status string Current status of the quote request (new, in-progress, quoted, canceled). false true
priority string Priority level of the request (low, medium, high, urgent). false false
requestDate datetime Date and time when the quote was requested. false true
needByDate datetime Date by which the customer needs the quote. false false
assignedToId integer ID of the user assigned to handle this quote request. false false
quoteId integer ID of the quote created from this request, if any. true false
contactId integer ID of the customer contact for this request. false false
createdBy integer ID of the user who created this quote request. true false
createdDate datetime Date and time when this quote request was created. true false
lastModifiedBy integer ID of the user who last modified this quote request. true false
lastModifiedDate datetime Date and time when this quote request was last modified. true false

Quote Request

The quote request resource is used to manage customer requests for quotes.

  • Resource URL: /quoterequest
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /quoterequest 200
GET /quoterequest/123 200
GET /quoterequest/123 404 quote request not found
POST /quoterequest 201 quote request created
POST /quoterequest 400 invalid data
PUT /quoterequest/123 200 quote request updated
PUT /quoterequest/123 400 invalid data
PUT /quoterequest/123 404 quote request not found
DELETE /quoterequest/123 204 quote request deleted
DELETE /quoterequest/123 404 quote request not found

Returned Elements for /quoterequest/[quoteRequestId]

id integer quote request entity ID
