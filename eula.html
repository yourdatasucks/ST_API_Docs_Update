End User License Agreement (EULA)

The EULA object represents an End User License Agreement or other legal agreement that users must accept before using certain features of the system. This API allows retrieving, updating, and tracking acceptance of these agreements.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the EULA. true false
name string Name or title of the agreement. false true
version string Version identifier for the agreement. false true
text string Full text content of the agreement. false true
htmlText string HTML formatted text of the agreement. false false
type string Type of agreement (e.g., "EULA", "Terms of Service", "Privacy Policy"). false false
status string Status of the agreement (e.g., "Draft", "Active", "Archived"). false true
effectiveDate date Date when the agreement becomes effective. false true
expirationDate date Date when the agreement expires (if applicable). false false
applicableUserTypes array Array of user types this agreement applies to (e.g., ["Admin", "Technician", "Customer"]). false false
applicableFeatures array Array of features or modules this agreement applies to. false false
requiredOnSignup boolean Whether this agreement must be accepted during user signup. false false
requiredOnUpdate boolean Whether existing users must accept this agreement when it's updated. false false
documentUrl string URL to a downloadable document version of the agreement. false false
summaryText string Brief summary or key points of the agreement. false false
acceptanceCount integer Number of users who have accepted this agreement. true false
previousVersionId integer ID of the previous version of this agreement, if applicable. false false
createdDate datetime Date the agreement was created. true false
createdBy integer ID of the user who created the agreement. true false
lastModifiedDate datetime Date the agreement was last modified. true false
lastModifiedBy integer ID of the user who last modified the agreement. true false

GET /eulas/{id}

Retrieves a specific EULA by ID.

Request

GET /v1.0/eulas/123
Authorization: Bearer {access_token}

Response

Returns the EULA object with the specified ID.

GET /eulas/current/{type}

Retrieves the current active EULA of a specific type.

Request

GET /v1.0/eulas/current/EULA
Authorization: Bearer {access_token}

Response

Returns the active EULA object of the specified type.

POST /eulas

Creates a new EULA.

Request Body

{
    "name": "ServiceTrade Data Privacy Agreement",
    "version": "1.0.0",
    "text": "SERVICETRADE DATA PRIVACY AGREEMENT\n\nLast Updated: August 1, 2023\n\n1. DATA COLLECTION AND USE\n\nServiceTrade collects and processes certain personal information to provide its services...",
    "htmlText": "<h1>SERVICETRADE DATA PRIVACY AGREEMENT</h1><p>Last Updated: August 1, 2023</p><h2>1. DATA COLLECTION AND USE</h2><p>ServiceTrade collects and processes certain personal information to provide its services...</p>",
    "type": "Privacy Policy",
    "status": "Draft",
    "effectiveDate": "2023-09-01",
    "applicableUserTypes": ["Admin", "Technician", "Office Staff", "Customer"],
    "applicableFeatures": ["Core Platform", "Mobile App", "Customer Portal"],
    "requiredOnSignup": true,
    "requiredOnUpdate": true,
    "summaryText": "Outlines how ServiceTrade collects, uses, and protects user data."
}

Response

Returns the newly created EULA object (HTTP 201 Created).

PUT /eulas/{id}

Updates an existing EULA.

Request Body

{
    "status": "Active",
    "effectiveDate": "2023-08-15",
    "documentUrl": "https://legal.example.com/privacy/servicetrade-privacy-v1.0.0.pdf"
}

Response

Returns the updated EULA object.

DELETE /eulas/{id}

Deletes a EULA. Generally, agreements should be archived rather than deleted.

Response

HTTP 204 No Content on successful deletion.

POST /eulas/{id}/accept

Records a user's acceptance of a EULA.

Request Body

{
    "userId": 789,
    "acceptanceMethod": "Mobile",
    "acceptanceContext": "App Update"
}

Response

Returns the EULA acceptance record.

GET /eulas/pending

Retrieves a list of EULAs that the current user needs to accept.

Request

GET /v1.0/eulas/pending
Authorization: Bearer {access_token}

Response

Returns a collection of EULA objects that require acceptance by the current user.

POST /eulas/{id}/publish

Publishes a draft EULA, changing its status to Active.

Request Body

{
    "effectiveDate": "2023-08-15",
    "notifyUsers": true,
    "notificationText": "We've updated our Privacy Policy. Please review and accept the new terms."
}

Response

Returns the updated EULA object with Active status.

POST /eulas/{id}/archive

Archives an active EULA, changing its status to Archived.

Request Body

{
    "archiveReason": "Superseded by new version",
    "replacementEulaId": 124
}

Response

Returns the updated EULA object with Archived status.

GET /eulas/versions/{name}

Retrieves all versions of a specific named agreement.

Request

GET /v1.0/eulas/versions/ServiceTrade%20Platform%20Terms%20of%20Service
Authorization: Bearer {access_token}

Response

Returns a collection of EULA objects with the specified name.

GET /users/{id}/eula-acceptances

Retrieves a list of EULAs that have been accepted by a specific user.

Request

GET /v1.0/users/789/eula-acceptances
Authorization: Bearer {access_token}

Response

Returns a collection of EULA acceptance records for the specified user.
