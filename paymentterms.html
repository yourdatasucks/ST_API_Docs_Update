Payment Terms

The Payment Terms object defines the conditions and timeframes under which customers are expected to pay for services or products. Payment terms can be associated with Customers, Invoices, Quotes, or Contracts. They typically specify payment due dates, discounts for early payment, late fees, and other payment conditions that affect accounts receivable management.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the payment terms. true false
code string Short code for the payment terms (e.g., "NET30", "2/10NET30"). false true
name string Descriptive name for the payment terms. false true
description string Detailed description of the payment terms. false false
dueInDays integer Number of days after invoice date when payment is due. false true
dueDayOfMonth integer Specific day of the month when payment is due (1-31). false false
discountPercentage decimal Percentage discount for early payment. false false
discountIfPaidByDays integer Number of days after invoice date when discount applies. false false
lateFeePercentage decimal Percentage fee applied for late payments. false false
lateFeeGracePeriod integer Number of days after due date before late fees apply. false false
isDefault boolean Whether these payment terms are the default terms. false false
isActive boolean Whether these payment terms are active. false false
calculationType string Method for calculating due date (e.g., "DaysAfterInvoice", "SpecificDayOfMonth"). false true
termsText string Text to display on invoices and other documents. false false
invoiceMessage string Message to display on invoices regarding payment terms. false false
useBusinessDaysOnly boolean Whether to count only business days when calculating due dates. false false
createdBy integer ID of the user who created these payment terms. true false
createdDate datetime Date and time when these payment terms were created. true false
lastModifiedBy integer ID of the user who last modified these payment terms. true false
lastModifiedDate datetime Date and time when these payment terms were last modified. true false
customFields object Custom fields and their values. false false

POST /payment-terms

Creates a new payment terms record.

Request Body

{
    "code": "DOM30",
    "name": "Due 30th of Month",
    "description": "Payment due on the 30th of the month following invoice date",
    "dueDayOfMonth": 30,
    "calculationType": "SpecificDayOfMonth",
    "lateFeePercentage": 1.5,
    "lateFeeGracePeriod": 5,
    "isDefault": false,
    "isActive": true,
    "termsText": "Terms: Due 30th of Month",
    "invoiceMessage": "Payment is due on the 30th of the month following invoice date.",
    "useBusinessDaysOnly": false,
    "customFields": {
        "accountingCode": "TERMS-005",
        "appliesTo": "Corporate Customers"
    }
}

Response

Returns the newly created payment terms record (HTTP 201 Created).

PUT /payment-terms/{id}

Updates an existing payment terms record.

Request Body

{
    "name": "Due 30th of Month - Corporate",
    "description": "Payment due on the 30th of the month following invoice date, for corporate customers",
    "lateFeePercentage": 2.0,
    "lateFeeGracePeriod": 3,
    "invoiceMessage": "Payment is due on the 30th of the month following invoice date. Late fees may apply to overdue payments.",
    "customFields": {
        "accountingCode": "TERMS-005",
        "appliesTo": "Corporate Customers",
        "approvalRequired": "false"
    }
}

Response

Returns the updated payment terms record.

DELETE /payment-terms/{id}

Deletes a payment terms record. This is typically handled as a soft delete by setting isActive to false.

Response

HTTP 204 No Content on successful deletion.

POST /payment-terms/{id}/set-default

Sets a payment terms record as the default terms. This will automatically unset any previously default terms.

Response

Returns the updated payment terms record with isDefault set to true.

POST /payment-terms/{id}/deactivate

Deactivates a payment terms record (sets isActive to false).

Response

Returns the updated payment terms record with isActive set to false.

POST /payment-terms/{id}/activate

Activates a payment terms record (sets isActive to true).

Response

Returns the updated payment terms record with isActive set to true.

GET /payment-terms/default

Retrieves the default payment terms record.

Request

GET /v1.0/payment-terms/default
Authorization: Bearer {access_token}

Response

Returns the payment terms record with isDefault set to true.

GET /customers/{customerId}/payment-terms

Retrieves the payment terms assigned to a specific customer.

Request

GET /v1.0/customers/1001/payment-terms
Authorization: Bearer {access_token}

Response

Returns the payment terms record assigned to the specified customer.

PUT /customers/{customerId}/payment-terms

Assigns payment terms to a specific customer.

Request Body

{
    "paymentTermsId": 1003,
    "overrideValues": {
        "lateFeePercentage": 1.0,
        "invoiceMessage": "Custom message for this customer regarding payment terms."
    }
}

Response

Returns information about the updated customer payment terms assignment.

GET /invoices/{invoiceId}/payment-terms

Retrieves the payment terms assigned to a specific invoice.

Request

GET /v1.0/invoices/5001/payment-terms
Authorization: Bearer {access_token}

Response

Returns the payment terms record assigned to the specified invoice.

GET /payment-terms/calculate-due-date

Calculates a due date based on payment terms and invoice date.

Request

GET /v1.0/payment-terms/calculate-due-date?paymentTermsId=1003&invoiceDate=2023-07-15
Authorization: Bearer {access_token}

Response

{
    "invoiceDate": "2023-07-15",
    "dueDate": "2023-08-14",
    "discountAvailableUntil": "2023-07-25",
    "discountPercentage": 2.0,
    "lateFeeAppliesAfter": "2023-08-19",
    "lateFeePercentage": 1.5
}

Request Body

        {
            "code": "NET45",
            "name": "Net 45 Days",
            "dueInDays": 45,
            "calculationType": "DaysAfterInvoice",
            "isActive": true
        },
        {
            "code": "NET60",
            "name": "Net 60 Days",
            "dueInDays": 60,
            "calculationType": "DaysAfterInvoice",
            "isActive": true
        }
    ]
}

Response

Returns an array of the created payment terms records.
