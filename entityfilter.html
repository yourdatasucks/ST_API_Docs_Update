Entity Filter

The Entity Filter object represents a saved filter or search condition that can be applied to entities within the system. These filters can be used for reporting, dashboards, views, and other filtering functionalities.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the entity filter. true false
name string Name of the filter, used for display and reference. false true
description string Description of the filter's purpose or criteria. false false
entityType string Type of entity this filter applies to (e.g., "Job", "Invoice", "Customer"). false true
criteria object Filter criteria object defining the conditions entities must meet. false true
isGlobal boolean Whether this filter is available to all users. false false
isDefault boolean Whether this filter is the default for its entity type. false false
isSystemDefined boolean Whether this is a system-defined filter that cannot be modified. true false
ownerType string Type of owner for this filter (e.g., "User", "Role", "System"). false true
ownerId integer ID of the owner (depends on ownerType). false true
sortField string Field to sort results by when this filter is applied. false false
sortDirection string Direction to sort ("asc" or "desc"). false false
itemsPerPage integer Default number of items to show per page when filter is applied. false false
displayColumns array Array of column names to display when this filter is used in list views. false false
usageCount integer Number of times this filter has been used. true false
lastUsedDate datetime Date the filter was last used. true false
createdDate datetime Date the filter was created. true false
createdBy integer ID of the user who created the filter. true false
lastModifiedDate datetime Date the filter was last modified. true false
lastModifiedBy integer ID of the user who last modified the filter. true false

Criteria Object Structure

The criteria object defines the conditions entities must meet to be included in filter results. It has a flexible structure that supports complex queries:

{
    "operator": "and",  // Can be "and" or "or"
    "conditions": [
        {
            "field": "status",
            "operator": "equals",
            "value": "Active"
        },
        {
            "field": "createdDate",
            "operator": "greaterThan",
            "value": "2023-01-01"
        },
        {
            "operator": "or",  // Nested condition group
            "conditions": [
                {
                    "field": "type",
                    "operator": "equals",
                    "value": "Commercial"
                },
                {
                    "field": "type",
                    "operator": "equals",
                    "value": "Industrial"
                }
            ]
        }
    ]
}

Supported Operators

Operator Description Applicable Field Types
equals Field value exactly matches the specified value. All types
notEquals Field value does not match the specified value. All types
contains Field value contains the specified value. String, Array
notContains Field value does not contain the specified value. String, Array
startsWith Field value starts with the specified value. String
endsWith Field value ends with the specified value. String
greaterThan Field value is greater than the specified value. Number, Date
greaterThanOrEqual Field value is greater than or equal to the specified value. Number, Date
lessThan Field value is less than the specified value. Number, Date
lessThanOrEqual Field value is less than or equal to the specified value. Number, Date
between Field value is between two specified values. Number, Date
in Field value is in a list of specified values. All types
notIn Field value is not in a list of specified values. All types
isNull Field value is null or undefined. All types
isNotNull Field value is not null and not undefined. All types
hasLength Array field has a specific number of items. Array
isEmpty Array or string field is empty. String, Array
isNotEmpty Array or string field is not empty. String, Array

Endpoints

GET /entityfilters

Retrieves a list of entity filters. Can be filtered by entityType, ownerType, ownerId, etc.

Request

GET /v1.0/entityfilters?entityType=Job&ownerType=User&ownerId=123
Authorization: Bearer {access_token}

Response

{
    "items": [
        {
            "id": 456,
            "name": "Open Jobs This Month",
            "description": "All open jobs created this month",
            "entityType": "Job",
            "criteria": {
                "operator": "and",
                "conditions": [
                    {
                        "field": "status",
                        "operator": "in",
                        "value": ["Open", "In Progress"]
                    },
                    {
                        "field": "createdDate",
                        "operator": "greaterThanOrEqual",
                        "value": "2023-08-01"
                    }
                ]
            },
            "isGlobal": false,
            "isDefault": false,
            "isSystemDefined": false,
            "ownerType": "User",
            "ownerId": 123,
            "sortField": "createdDate",
            "sortDirection": "desc",
            "itemsPerPage": 25,
            "displayColumns": ["id", "title", "customer", "location", "status", "createdDate"],
            "usageCount": 15,
            "lastUsedDate": "2023-08-15T13:45:00Z",
            "createdDate": "2023-08-01T09:30:00Z",

}

GET /entityfilters/{id}

Retrieves a specific entity filter by ID.

Request

GET /v1.0/entityfilters/456
Authorization: Bearer {access_token}

Response

Returns the entity filter object with the specified ID.

GET /entityfilters/defaults

Retrieves the default entity filters for all entity types.

Request

GET /v1.0/entityfilters/defaults
Authorization: Bearer {access_token}

Response

Returns a collection of default entity filter objects.

GET /entityfilters/defaults/{entityType}

Retrieves the default entity filter for a specific entity type.

Request

GET /v1.0/entityfilters/defaults/Job
Authorization: Bearer {access_token}

Response

Returns the default entity filter object for the specified entity type.

POST /entityfilters

Creates a new entity filter.

Request Body

{
    "name": "High Value Customers",
    "description": "Customers with lifetime value over $100,000",
    "entityType": "Customer",
    "criteria": {
        "operator": "and",
        "conditions": [
            {
                "field": "lifetime.revenue",
                "operator": "greaterThan",
                "value": 100000
            },
            {
                "field": "status",
                "operator": "equals",
                "value": "Active"
            }
        ]
    },
    "isGlobal": true,
    "ownerType": "User",
    "ownerId": 123,
    "sortField": "lifetime.revenue",
    "sortDirection": "desc",
    "displayColumns": ["id", "name", "industry", "lifetime.revenue", "lifetime.jobCount"]
}

Response

Returns the newly created entity filter object (HTTP 201 Created).

PUT /entityfilters/{id}

Updates an existing entity filter.

Request Body

{
    "name": "Very High Value Customers",
    "criteria": {
        "operator": "and",
        "conditions": [
            {
                "field": "lifetime.revenue",
                "operator": "greaterThan",
                "value": 250000
            },
            {
                "field": "status",
                "operator": "equals",
                "value": "Active"
            }
        ]
    },
    "isGlobal": true
}

Response

Returns the updated entity filter object.

DELETE /entityfilters/{id}

Deletes an entity filter.

Response

HTTP 204 No Content on successful deletion.

POST /entityfilters/{id}/setdefault

Sets an entity filter as the default for its entity type.

Response

Returns the updated entity filter object with isDefault set to true.

POST /entityfilters/{id}/clone

Creates a copy of an existing entity filter.

Request Body

{
    "name": "High Value Industrial Customers",
    "ownerType": "User",
    "ownerId": 124
}

Response

Returns the newly created entity filter object based on the cloned filter.

POST /entityfilters/{id}/apply

Applies an entity filter and returns the matching entities.

Request Body

{
    "page": 1,
    "itemsPerPage": 25,
    "sortField": "name",
    "sortDirection": "asc",
    "additionalCriteria": {
        "operator": "and",
        "conditions": [
            {
                "field": "industry",
                "operator": "equals",
                "value": "Healthcare"
            }
        ]
    }
}

Response

Returns entities matching the filter criteria, with pagination information.

GET /entityfilters/system/{entityType}

Retrieves system-defined filters for a specific entity type.

Request

GET /v1.0/entityfilters/system/Job
Authorization: Bearer {access_token}

Response

Returns a collection of system-defined entity filter objects for the specified entity type.
