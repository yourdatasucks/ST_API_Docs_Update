Budget Category

The Budget Category object represents a grouping of related line items within a Budget. Examples of budget categories might include "Labor", "Materials", "Equipment", etc. Budget Categories help organize budget line items for better financial tracking and reporting.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the budget category. true false
budgetId integer ID of the parent Budget. false true
referenceNumber string Reference number that this budget category is known by. false false
name string Name of the budget category. false true
description string Description of the budget category. false false
cost decimal Total cost allocated for this category (sum of line items). true false
usedAmount decimal Amount used/spent from this category budget (calculated). true false
remainingAmount decimal Amount remaining in this category budget (calculated). true false
orderIndex integer Display order for the category within the budget. false false
libItemType string Type of library item this category represents, if applicable. false false
createdDate datetime Date the budget category was created. true false
createdBy integer ID of the user who created the budget category. true false
lastModifiedDate datetime Date the budget category was last modified. true false
lastModifiedBy integer ID of the user who last modified the budget category. true false

Budget Category

The budgetcategory resource is used to manage Budget Category data within ServiceTrade.

  • Resource URL: /budgetcategory
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /budgetcategory 200
GET /budgetcategory/123 200
GET /budgetcategory/123 404 budgetcategory not found
POST /budgetcategory 200 budgetcategory created
POST /budgetcategory 400 invalid data
PUT /budgetcategory/123 200 budgetcategory updated
PUT /budgetcategory/123 400 invalid data
PUT /budgetcategory/123 404 budgetcategory not found
DELETE /budgetcategory/123 204 budgetcategory deleted
DELETE /budgetcategory/123 404 budgetcategory not found
