Job Item

The Job Item object represents a line item on a Job in ServiceTrade. Job items typically describe the services performed, materials used, or products sold as part of a job, along with quantities, prices, and other billing information. These items can later be included on Invoices generated from the job.

Job Item

The jobitem resource is used to manage Job Item data within ServiceTrade.

  • Resource URL: /jobitem
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /jobitem 200
GET /jobitem/123 200
GET /jobitem/123 404 jobitem not found
POST /jobitem 200 jobitem created
POST /jobitem 400 invalid data
PUT /jobitem/123 200 jobitem updated
PUT /jobitem/123 400 invalid data
PUT /jobitem/123 404 jobitem not found
DELETE /jobitem/123 204 jobitem deleted
DELETE /jobitem/123 404 jobitem not found

Returned Elements for /jobitem/[jobitemId]

Name Type Value
id integer jobitem entity ID
uri string resource identifier for the jobitem
name string name of the jobitem
