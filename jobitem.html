Job Item

The Job Item object represents a line item on a Job in ServiceTrade. Job items typically describe the services performed, materials used, or products sold as part of a job, along with quantities, prices, and other billing information. These items can later be included on Invoices generated from the job.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the job item. true false
jobId integer ID of the Job this item belongs to. false true
description string Description of the item. false true
quantity decimal Quantity of the item. false true
unitPrice decimal Price per unit. false true
unitCost decimal Cost per unit. false false
extendedPrice decimal Total price (quantity * unitPrice). true false
extendedCost decimal Total cost (quantity * unitCost). true false
margin decimal Profit margin percentage. true false
taxable boolean Whether this item is subject to tax. false false
taxRateId integer ID of the Tax Rate to apply to this item. false false
itemType string Type of item (e.g., "Service", "Material", "Labor", "Fee", "Product"). false false
sequenceNumber integer Display order of this item on jobs and invoices. false false
serviceItemId integer ID of the Service Item this job item is associated with, if applicable. false false
notes string Additional notes about this line item. false false
assetId integer ID of the Asset this job item is associated with, if applicable. false false
invoiceItemIds array Array of Invoice Item IDs this job item has been invoiced to. true false
quoteItemId integer ID of the Quote Item this job item originated from, if applicable. false false
isInvoiced boolean Whether this item has been fully invoiced. true false
invoicedQuantity decimal Quantity of this item that has been invoiced. true false
remainingQuantity decimal Quantity of this item that remains to be invoiced. true false
createdBy integer ID of the user who created this job item. true false
createdDate datetime Date and time when this job item was created. true false
lastModifiedBy integer ID of the user who last modified this job item. true false
lastModifiedDate datetime Date and time when this job item was last modified. true false
customFields object Custom fields and their values. false false

POST /jobs/{jobId}/items

Creates a new job item for the specified job.

Request Body

{
    "description": "Replacement of Faulty Smoke Detector",
    "quantity": 1,
    "unitPrice": 125.00,
    "unitCost": 45.00,
    "taxable": true,
    "itemType": "Material",
    "sequenceNumber": 3,
    "serviceItemId": 502,
    "notes": "Replaced faulty smoke detector in east hallway 3rd floor",
    "assetId": 3010,
    "customFields": {
        "department": "Fire Alarm",
        "serviceCode": "FA-REP-SD",
        "partNumber": "SD-345-T"
    }
}

Response

Returns the newly created job item (HTTP 201 Created).

PUT /jobitems/{id}

Updates an existing job item.

Request Body

{
    "description": "Replacement of Faulty Smoke Detector - Addressable",
    "quantity": 1,
    "unitPrice": 150.00,
    "unitCost": 65.00,
    "taxable": true,
    "notes": "Replaced faulty smoke detector in east hallway 3rd floor with addressable model",
    "customFields": {
        "department": "Fire Alarm",
        "serviceCode": "FA-REP-SD",
        "partNumber": "SD-355-ADR"
    }
}

Response

Returns the updated job item.

DELETE /jobitems/{id}

Deletes a job item. This is typically only allowed for items that have not been invoiced.

Response

HTTP 204 No Content on successful deletion.

    "items": [

            "description": "Labor - Technician",
            "quantity": 2.5,
            "unitPrice": 95.00,
            "unitCost": 45.00,
            "taxable": true,

            "sequenceNumber": 4
        },
        {
            "description": "Labor - Helper",
            "quantity": 2.5,
            "unitPrice": 65.00,
            "unitCost": 30.00,
            "taxable": true,
            "itemType": "Labor",
            "sequenceNumber": 5
        },
        {
            "description": "Travel Charge",
            "quantity": 1,
            "unitPrice": 75.00,
            "unitCost": 35.00,
            "taxable": false,
            "itemType": "Fee",

PUT /jobs/{jobId}/items/reorder

Reorders the line items in a job.

Request Body

{
    "itemOrder": [7002, 7001, 7003, 7004, 7005, 7006]
}

Response

Returns success message and updates the sequenceNumber property of the affected items.

POST /jobs/{jobId}/items/from-service-items

Creates job items from service items.

Request Body

{
    "serviceItemIds": [501, 502, 503],
    "quantities": {
        "501": 1,
        "502": 2,
        "503": 1
    },
    "overrides": {
        "501": {
            "description": "Custom description for service item 501",
            "unitPrice": 1600.00
        }
    }
}

Response

Returns an array of the created job items.

POST /jobs/{jobId}/items/from-quote

Creates job items from a quote.

Request Body

{
    "quoteId": 9001,
    "includeAll": true,
    "quoteItemIds": []
}

Response

Returns an array of the created job items.
