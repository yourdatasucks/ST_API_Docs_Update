User

The User object represents an individual who has access to the ServiceTrade system. Users can be technicians, office staff, managers, administrators, or other personnel. Each user has specific permissions defined by their assigned Roles, determining what actions they can perform and what data they can access. User accounts contain personal information, contact details, credentials, preferences, and system-specific settings required for authentication and proper system operation.

User

The user resource is used to manage User data within ServiceTrade.

  • Resource URL: /user
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /user 200
GET /user/123 200
GET /user/123 404 user not found
POST /user 200 user created
POST /user 400 invalid data
PUT /user/123 200 user updated
PUT /user/123 400 invalid data
PUT /user/123 404 user not found
DELETE /user/123 204 user deleted
DELETE /user/123 404 user not found

Returned Elements for /user/[userId]

Name Type Value
id integer user entity ID
uri string resource identifier for the user
name string name of the user
