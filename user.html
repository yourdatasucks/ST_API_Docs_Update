User

The User object represents an individual who has access to the ServiceTrade system. Users can be technicians, office staff, managers, administrators, or other personnel. Each user has specific permissions defined by their assigned Roles, determining what actions they can perform and what data they can access. User accounts contain personal information, contact details, credentials, preferences, and system-specific settings required for authentication and proper system operation.

DELETE /users/{id}

Deletes a user. This operation is typically restricted and may be disallowed or replaced with deactivation.

Response

HTTP 204 No Content on successful deletion.

POST /users/{id}/deactivate

Deactivates a user without deleting their account.

Request Body

{
    "reason": "Employee no longer with company",
    "revokeAllTokens": true
}

Response

Returns the deactivated user with updated status.

POST /users/{id}/activate

Activates a previously deactivated user.

Response

Returns the activated user with updated status.

POST /users/{id}/resetPassword
