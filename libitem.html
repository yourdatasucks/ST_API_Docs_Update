Library Item

The Library Item (LibItem) object represents a reusable item or template in ServiceTrade's content library. Library items can include standardized service descriptions, parts, labor rates, equipment specifications, or other content that can be reused across quotes, jobs, and invoices. The library provides consistency and efficiency by allowing users to quickly add pre-configured items to various transactions.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the library item. true false
name string Name of the library item. false true
description string Detailed description of the library item. false false
type string Type of library item (e.g., "Service", "Material", "Labor", "Equipment", "Text"). false true
category string Category the library item belongs to. false false
subcategory string Subcategory the library item belongs to. false false
unitPrice decimal Default price per unit for this library item. false false
unitCost decimal Default cost per unit for this library item. false false
defaultQuantity decimal Default quantity to use when adding this library item. false false
unit string Unit of measure (e.g., "Each", "Hour", "Foot", "Pound"). false false
taxable boolean Whether this library item is taxable by default. false false
tags array Array of tags associated with this library item. false false
manufacturerId integer ID of the manufacturer for this library item, if applicable. false false
manufacturer string Name of the manufacturer. false false
modelNumber string Model number for this library item, if applicable. false false
partNumber string Part number for this library item, if applicable. false false
sku string Stock keeping unit identifier. false false
isActive boolean Whether this library item is active and available for use. false false
serviceLineId integer ID of the Service Line this item is associated with, if applicable. false false
warehouseId integer ID of the Warehouse this item is stored in, if applicable. false false
inventoryCount decimal Current inventory count for this library item, if tracked. false false
reorderPoint decimal Inventory level at which to reorder this item. false false
reorderQuantity decimal Recommended quantity to reorder when inventory reaches reorder point. false false
createdBy integer ID of the user who created this library item. true false
createdDate datetime Date and time when this library item was created. true false
lastModifiedBy integer ID of the user who last modified this library item. true false
lastModifiedDate datetime Date and time when this library item was last modified. true false
customFields object Custom fields and their values. false false

POST /libitems

Creates a new library item.

Request Body

{
    "name": "Smoke Detector Replacement",
    "description": "Replacement of conventional smoke detector including testing.",
    "type": "Material",
    "category": "Fire Alarm",
    "subcategory": "Devices",
    "unitPrice": 85.00,
    "unitCost": 35.00,
    "defaultQuantity": 1,
    "unit": "Each",
    "taxable": true,
    "tags": ["Smoke Detector", "Fire Alarm", "Replacement"],
    "manufacturer": "Simplex",
    "modelNumber": "4098-9714",
    "partNumber": "SIM-4098-9714",
    "sku": "SD-0001",
    "isActive": true,
    "serviceLineId": 501,
    "warehouseId": 201,
    "inventoryCount": 25,
    "reorderPoint": 10,
    "reorderQuantity": 20,
    "customFields": {
        "location": "Shelf B-12",
        "warrantPeriod": "1 year",
        "compatiblePanels": "4100ES, 4010ES"
    }
}

Response

Returns the newly created library item (HTTP 201 Created).

    "description": "Replacement of addressable smoke detector including programming and testing.",

    "customFields": {
        "location": "Shelf B-14",
        "warrantPeriod": "1 year",
        "compatiblePanels": "4100ES, 4010ES, 4007ES"

}

Response

Returns the updated library item.

DELETE /libitems/{id}

Deletes a library item. This is typically handled as a soft delete by setting isActive to false.

Response

HTTP 204 No Content on successful deletion.

POST /libitems/{id}/deactivate

Deactivates a library item (sets isActive to false).

Response

Returns the updated library item with isActive set to false.

POST /libitems/{id}/activate

Activates a library item (sets isActive to true).

Response

Returns the updated library item with isActive set to true.

PUT /libitems/{id}/inventory

Updates the inventory information for a library item.

Request Body

{
    "inventoryCount": 22,
    "warehouseId": 201,
    "reorderPoint": 10,
    "reorderQuantity": 20,
    "adjustmentReason": "Inventory count adjustment"
}

Response

Returns the updated library item.

GET /libitems/low-inventory

Retrieves a list of library items with inventory at or below reorder point.

Request

GET /v1.0/libitems/low-inventory
Authorization: Bearer {access_token}

Response

Returns a collection of library items with low inventory.

POST /libitems/import

Imports library items from a CSV or Excel file.

Request

A multipart/form-data request containing the file to import.

Response

Returns information about the import process including success count, error count, and any import issues.

GET /libitems/export

Exports library items to a CSV or Excel file.

Request

GET /v1.0/libitems/export?format=xlsx&type=Material
Authorization: Bearer {access_token}

Response

Returns a file download containing the requested library items.
