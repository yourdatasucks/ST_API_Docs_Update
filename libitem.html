Library Item

The Library Item (LibItem) object represents a reusable item or template in ServiceTrade's content library. Library items can include standardized service descriptions, parts, labor rates, equipment specifications, or other content that can be reused across quotes, jobs, and invoices. The library provides consistency and efficiency by allowing users to quickly add pre-configured items to various transactions.

Library Item

The libitem resource is used to manage Library Item data within ServiceTrade.

  • Resource URL: /libitem
  • Available Verbs: GET, POST, PUT, DELETE
  • Authentication Required: yes

Response Codes

Verb Example URL Code Reason
GET /libitem 200
GET /libitem/123 200
GET /libitem/123 404 libitem not found
POST /libitem 200 libitem created
POST /libitem 400 invalid data
PUT /libitem/123 200 libitem updated
PUT /libitem/123 400 invalid data
PUT /libitem/123 404 libitem not found
DELETE /libitem/123 204 libitem deleted
DELETE /libitem/123 404 libitem not found

Returned Elements for /libitem/[libitemId]

Name Type Value
