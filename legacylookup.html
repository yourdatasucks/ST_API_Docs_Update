Legacy Lookup

The Legacy Lookup object facilitates the mapping between legacy system identifiers and ServiceTrade entities during data migrations. It provides a way to reference and locate entities in ServiceTrade using identifiers from a previous system, enabling smooth transitions from legacy systems while maintaining historical data relationships.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the legacy lookup record. true false
legacySystem string Name of the legacy system that the identifier comes from. false true
legacyId string Identifier from the legacy system. false true
entityType string Type of entity in ServiceTrade (e.g., "Customer", "Location", "Job", "Asset"). false true
entityId integer ID of the entity in ServiceTrade. false true
additionalData object Optional additional data or metadata from the legacy system. false false
createdBy integer ID of the user who created the legacy lookup record. true false
createdDate datetime Date and time when the legacy lookup record was created. true false
lastModifiedBy integer ID of the user who last modified the legacy lookup record. true false
lastModifiedDate datetime Date and time when the legacy lookup record was last modified. true false
migrationBatchId string Identifier for the migration batch this record was part of. false false
migrationDate datetime Date and time when the migration occurred. false false
notes string Additional notes about this legacy lookup record. false false

POST /legacy-lookups

Creates a new legacy lookup record.

Request Body

{
    "legacySystem": "OldERP",
    "legacyId": "LOC-005",
    "entityType": "Location",
    "entityId": 2005,
    "additionalData": {
        "legacyAddress": "500 Old Main St, Suite 400",
        "legacyContactName": "John Smith",
        "legacyZone": "East"
    },
    "migrationBatchId": "BATCH-2023-07",
    "migrationDate": "2023-07-01T12:00:00Z",
    "notes": "Location data migrated from OldERP system."
}

Response

Returns the newly created legacy lookup record (HTTP 201 Created).

PUT /legacy-lookups/{id}

Updates an existing legacy lookup record.

Request Body

{
    "entityId": 2006,
    "additionalData": {
        "legacyAddress": "500 Old Main St, Suite 400",
        "legacyContactName": "Jane Smith",
        "legacyZone": "East"
    },
    "notes": "Location data migrated from OldERP system. Updated entityId after location merge."
}

Response

Returns the updated legacy lookup record.

DELETE /legacy-lookups/{id}

Deletes a legacy lookup record.

Response

HTTP 204 No Content on successful deletion.
