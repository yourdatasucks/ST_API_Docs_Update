Change Order Line Item

The Change Order Line Item object represents individual items or services that are being added, removed, or modified as part of a Change Order. Line items provide detailed breakdown of the changes and their associated costs.

Properties

Property Type Description Read-Only Required
id integer Unique identifier for the change order line item. true false
changeOrderId integer ID of the parent Change Order. false true
description string Detailed description of the line item. false true
type string Type of change (e.g., "Add", "Remove", "Modify"). false true
quantity decimal Quantity of the item or service. false true
unit string Unit of measure (e.g., "hours", "pieces", "sq ft"). false false
unitPrice decimal Price per unit. false true
markupPercentage decimal Percentage markup applied to this line item. false false
markupAmount decimal Monetary amount of markup (calculated). true false
total decimal Total cost for this line item (quantity × unitPrice + markup). true false
taxable boolean Whether this line item is subject to tax. false false
taxRate decimal Tax rate applied to this line item. false false
taxAmount decimal Amount of tax applied to this line item (calculated). true false
originalItemId integer ID of the original item being modified (if this is a modification). false false
originalItemType string Type of the original item (e.g., "QuoteItem", "JobItem", "ServiceItem"). false false
serviceItemId integer ID of the associated service item, if applicable. false false
orderIndex integer Display order for the line item within the change order. false false
createdDate datetime Date the line item was created. true false
createdBy integer ID of the user who created the line item. true false
lastModifiedDate datetime Date the line item was last modified. true false
lastModifiedBy integer ID of the user who last modified the line item. true false

POST /changeorderlineitems

Creates a new change order line item.

Request Body

{
    "changeOrderId": 789,
    "description": "Upgrade electrical fixtures",
    "type": "Add",
    "quantity": 5,
    "unit": "each",
    "unitPrice": 120.00,
    "markupPercentage": 10,
    "taxable": true,
    "taxRate": 8.0,
    "orderIndex": 4
}

Response

Returns the newly created change order line item object (HTTP 201 Created).

PUT /changeorderlineitems/{id}

Updates an existing change order line item.

Request Body

{
    "description": "Upgrade premium electrical fixtures",
    "quantity": 6,
    "unitPrice": 135.00
}

Response

Returns the updated change order line item object.

DELETE /changeorderlineitems/{id}

Deletes a change order line item. This may be disallowed if the parent change order is in certain statuses.

Response

HTTP 204 No Content on successful deletion.
