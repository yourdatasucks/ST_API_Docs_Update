Asset

The Asset object represents a tangible or intangible item that is tracked, often for a customer or internal use. This could be equipment, software licenses, machinery, etc. Assets usually have an Asset Definition that describes their type.

The Assets feature must be enabled by an Administrator in Account Settings > Assets.

Properties

Property Type Description Read-Only Required
Id integer Unique identifier for the Asset. true N/A
Name string A descriptive name for the Asset (e.g., "Main Office Server", "Excavator #102"). false true
AssetDefinitionId integer The ID of the Asset Definition that classifies this asset. false true
SerialNumber string The serial number of the asset, if applicable. false false
LocationId integer ID of the Location where this asset is primarily situated (if applicable). false false
CustomerId integer ID of the Customer (Company/Account) that owns or is associated with this asset. false false
Status string Current status of the asset (e.g., "Active", "In Repair", "Decommissioned", "Sold"). false false
PurchaseDate date The date the asset was purchased. false false
WarrantyExpiryDate date The date the asset's warranty expires. false false
CustomFields object A key-value pair object containing values for custom fields defined by the asset's Asset Definition. For example: {"Screen Size": "27", "RAM": "16GB"}. false false
CreateDate datetime Date the asset record was created. true N/A
LastModifiedDate datetime Date the asset record was last modified. true N/A

Endpoints

GET /assets

Retrieves a list of assets. Supports filtering by AssetDefinitionId, CustomerId, Status, etc.

Request

GET /v1.0/assets?AssetDefinitionId=1&Status=Active
Authorization: Bearer {access_token}

Response

{
    "items": [
        {
            "Id": 501,
            "Name": "Reception Desk iMac 27-inch",
            "AssetDefinitionId": 1, // Assuming 1 is "Desktop Computer"
            "SerialNumber": "C02XG0JYFVH6",
            "Status": "Active",
            "CustomFields": {"RAM": "16GB", "Storage": "1TB SSD"},
            // ... other properties
        }
    ],
    // ... pagination info
}

POST /assets

Creates a new asset.

Request Body

{
    "Name": "Conference Room Projector",
    "AssetDefinitionId": 3, // Assuming 3 is "Projector"
    "SerialNumber": "PJ789123",
    "Status": "Active",
    "CustomFields": {"Lumens": "3500"}
}

Response

Returns the newly created asset object (HTTP 201 Created).

GET /assets/{id}

Retrieves a specific asset by its ID.

PUT /assets/{id}

Updates an existing asset.

DELETE /assets/{id}

Deletes an asset. This might be a soft delete or be disallowed if the asset is referenced elsewhere (e.g., in service history).
